# 在全市“数据要素×”行动暨公共数据资源授权运营工作推进会议上的讲话

**（2026年11月2日）**

同志们：

今天召开全市“数据要素×”行动暨公共数据资源授权运营工作推进会议，主要任务是深入贯彻党中央、国务院关于加快构建数据基础制度、更好发挥数据要素作用的决策部署，全面落实省委、省政府关于“十五五”时期数字政府建设的具体要求，认真总结前一阶段工作成效，正视存在的突出问题，对下一阶段重点任务进行再动员、再部署、再落实。刚才，市数据局汇报了工作进展，几个部门作了交流发言，讲得都很好。下面，结合全市实际，我讲三点意见。

一、认清形势，切实增强做好“数据要素×”行动的责任感紧迫感

数据作为新型生产要素，正在深刻改变生产方式、生活方式和治理方式。抓好这项工作，是抢占数字经济制高点的战略需要，是激发市场主体活力的关键一招，也是提升城市治理效能的重要抓手。市委市政府高度重视数据要素工作，上半年在数据资源供给、场景开放、要素流通等方面取得明显成效。一是底数摸得更清。完成全市公共数据资源目录全域梳理，编目入库数据项同比增长42%，率先实现全市一级部门数据目录全覆盖。二是场景落得更实。累计开放数据应用场景186个，其中在医疗健康、交通出行、生态环境、城市治理等重点领域建成上线场景73个。三是流通机制更活。公共数据授权运营平台完成与省级平台对接，首批授权运营主体挂牌6家，季度数据产品交易额突破2100万元。四是不敢想的现在敢想、不能干的正在能干，全市数据要素市场化改革从“无路可走”转向“有路可跑”。

但在看到成绩的同时，我们必须清醒认识到差距和不足。一是“有数据、难开发”的问题仍然存在。相当一部分数据仍以原始表、静态报表形式沉淀，缺少标准化整理和可复用加工，数据供给“量大质弱”，开发成本居高不下。二是“有点、缺场景”的问题仍然突出。场景开放多集中在示范样板、样板间多、可复制少，与企业生产经营、群众日常生活的真实痛点结合不紧，场景牵引作用尚未充分释放。三是“有制度、难落地”的问题仍然存在。数据授权运营收益分配、定价机制、责任边界等关键环节规则不够精细，操作中无据可依、各地尺度不一，企业参与意愿不强。四是“有热情、缺能力”的问题仍然存在。部分单位对数据合规不懂、对产品经营不会、对风险防控不熟，专业人才和运营能力严重不足。全体同志们必须正视这些问题，拿出真招实招，动真碰硬推动解决。

二、聚焦重点，全力推动重点任务落地见效

下一阶段是“十五五”开局起步的关键阶段，任务艰巨、要求具体。全市上下要坚持目标导向、问题导向、结果导向，突出“四个攻坚”，确保各项任务落到实处。

第一，突出场景牵引攻坚，打开数据赋能实体经济的新空间。要围绕企业需求做深做细场景文章，年内再建100个以上高质量应用场景，其中面向中小微企业的场景不少于40个。聚焦沈阳产业基础，围绕高端装备、机器人、新材料、汽车及零部件、农产品加工五大重点产业链，年内发布“一链一场景”专属清单各不低于10个。聚焦群众关切，年内上线不少于30个“场景+服务”融合类应用，让数据多跑路、群众少跑腿。要建立场景清单化管理和季度评估机制，对评估不合格的坚决调整退出，绝不允许“只挂名字、不见实效”。

第二，突出授权运营攻坚，走通要素流通的价值实现路径。要加快公共数据资源授权运营体系建设，年内授权运营主体达到20家以上，授权运营数据产品达到150个以上，全年数据产品交易额突破1.2亿元。要研究制定公共数据资源授权运营收益分配指导性意见，明确基准定价、成本监审和争议处理规则，年内出台价格形成、收益分配、监督管理三项制度。要用好省级平台通道，推动与省内14个地市的数据流通互联互通，力争年内实现“一次授权、多地调用”。要严守不设禁区、不打折扣的红线，做到“数据可用不可见、可用不可控”。

第三，突出供给能力攻坚，夯实数据基础支撑底座。要持续推进数据资源目录标准化、规范化，年内完成全市200个高频公共数据项的标准化改造，建立数据元、数据集、数据服务三级规范体系。要加快公共数据资源授权运营技术底座建设，年内改造提升数据加工、隐私计算、可信执行环境三类关键能力，新建数据加工工坊不少于10个。要推动数据流通基础设施建设，升级全市数据流通节点性能，跨域交换时延压降至50毫秒以内。要落实数据分类分级保护要求，年内完成全市重要数据目录识别备案，实现重要数据识别“全覆盖、应备尽备”。

第四，突出安全治理攻坚，守牢数据要素流通底线。要坚持发展与安全并重，一手抓数据供给、一手抓风险防控。要健全数据安全责任体系，落实数据处理者安全管理制度，年内对重点数据处理主体开展合规检查不少于500家次，违规问题整改到位率100%。要强化个人信息保护，对涉及个人信息的场景严格落实最小必要原则，年内开展专项评估不少于30个。要完善数据安全监测预警和应急处置机制，建立7×24小时监测值守制度，全年不发生重大数据安全事件。要严肃查处违规共享、违规授权、违规使用行为，发现一起、查处一起，绝不姑息迁就。

三、强化保障，确保各项任务落实到位

蓝图已经绘就，关键在于落实。全市上下要闻风而动、抓紧实施，确保按期交账。

一要压实责任链条。市数据局要履行好牵头统筹职责，制定任务分工台账，逐项明确责任单位、责任人、时间节点和验收标准；各部门主要负责同志要亲自抓、亲自管，确保分管领域任务有人抓、有人管。要健全“年初建账、季度对账、年底交账”工作机制，重点指标进展滞后2个单位的，要说明原因并限期赶上。

二要健全协同机制。打破部门壁垒，建立跨部门数据共享联席会议制度，涉事单位要主动补位、协同联动，不得以“数据涉密”“不便共享”为由推诿塞责。要建立需求响应机制，企业提出的场景需求，2个工作日内答复，1个月内形成初步方案。

三要强化要素支撑。加大财政投入和人才引育力度，年内引进和培养数据开发、场景运营、合规风控三类专业人才不少于500名。探索建立数据产品开发专项基金，为优质场景和优质数据产品提供“低成本试错”支持。要加强与高校、科研院所合作，共建实训基地不少于5个。

四要严格作风纪律。不搞形式主义，不做表面文章，所有任务必须落到具体项目、具体场景、具体数据产品上。要强化督查考核，把数据要素工作纳入部门绩效考核，考核结果与干部使用、评先评优挂钩。要严守纪律红线，绝不允许借公共数据授权运营之名搞利益输送、寻租设卡，一经查实严肃追责问责。

同志们，数据要素时代已经到来，机遇稍纵即逝。全市上下要进一步解放思想、改革创新、锐意进取，以钉钉子精神抓落实，以大概率思维谋长远，把每一项任务落到具体的人、具体的项目、具体的数字上，用数据要素赋能千行百业，让沈阳在新一轮数字化转型中赢得主动、赢得未来，共同开创全市数字政府建设和数据要素市场化改革新局面！
