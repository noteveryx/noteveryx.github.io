# 在全市经济运行分析暨四季度工作部署会议上的讲话
（方正小标宋简体风格）

**（2026年9月23日）**

同志们：

今天我们召开全市经济运行分析暨四季度工作部署会议，主要任务是深入贯彻落实党中央、国务院关于经济工作的重大决策部署，全面研判当前经济形势，安排部署四季度经济工作，动员全市上下振奋精神、真抓实干，坚决打好全年经济社会发展收官战。刚才，市发改委通报了前三季度经济运行情况，市统计局、工信局、商务局、财政局分别作了补充发言，讲得很好，问题找得透，措施定得实。下面，我讲三点意见。

## 一、清醒认识形势，切实增强做好四季度经济工作的责任感紧迫感

今年以来，全市上下深入贯彻习近平经济思想，全面落实党中央决策部署和省委、省政府工作要求，锚定全面振兴新突破三年行动目标，全力以赴稳增长、强动能、优结构、惠民生，经济运行总体平稳、稳中有进。前三季度，全市地区生产总值同比增长5.6%，高于全国、全省平均水平0.8个和0.4个百分点；规上工业增加值同比增长7.2%，装备制造业、原材料工业增加值分别增长9.4%和4.1%；固定资产投资同比增长6.8%，其中高技术产业投资增长18.6%；社会消费品零售总额同比增长5.2%，外贸进出口总额同比增长8.4%；一般公共预算收入同比增长4.7%；城镇新增就业8.6万人，居民消费价格指数同比上涨0.3%。这些成绩来之不易，是全市广大干部群众团结拼搏、攻坚克难的结果，必须充分肯定。

同时，必须清醒看到，当前经济运行仍面临不少困难和挑战。从外部环境看，国际环境复杂多变，地缘政治冲突频发，外部需求不确定性增加，产业链供应链安全面临冲击。从国内环境看，有效需求不足、部分行业产能过剩、社会预期偏弱等老问题与新矛盾交织，经济回升向好的基础仍需巩固。从我市情况看，主要存在"四个突出问题"：一是工业增长后劲不足，重点行业拉动效应减弱，1—8月汽车及零部件产业产值同比下降1.8%，建材行业产值下降3.2%；二是投资结构亟待优化，房地产投资持续低迷，民间投资增速放缓，部分项目推进缓慢，1—8月房地产开发投资同比下降8.6%；三是消费市场恢复不均衡，住宿餐饮、文化旅游等接触性服务业尚未恢复到疫情前水平，汽车、家电等大宗消费潜力释放不充分；四是风险隐患不容忽视，部分中小企业经营困难，财政收支矛盾突出，重点领域风险防范化解任务繁重。对此，必须高度重视，切实增强忧患意识、风险意识、底线思维，以更硬的举措、更实的作风、更强的担当，全力以赴做好四季度经济工作。

## 二、聚焦重点发力，坚决完成全年目标任务

四季度是全年经济工作的收官季、决胜季，各项任务艰巨繁重。必须紧盯全年目标不动摇，聚焦重点领域和关键环节精准发力，狠抓政策落实、项目推进、消费提振、风险防范，努力把短板补起来、把速度提起来、把质量搞上去，确保全年地区生产总值增长6%以上、规上工业增加值增长7%以上、固定资产投资增长7%以上、社会消费品零售总额增长5.5%以上、一般公共预算收入增长4%以上。

第一，全力推动工业经济稳增长。要强化重点企业运行监测，"一企一策"帮助企业纾困解难，落实好国家减税降费、社保缓缴、融资支持等惠企政策，确保规上工业企业稳定运行。要加快推动传统产业转型升级，实施"千项技改、千企转型"工程，年内完成技改投资300亿元以上。要培育壮大战略性新兴产业，重点发展新能源汽车、生物医药、新材料、智能装备制造、新一代信息技术等产业，力争战略性新兴产业产值占规上工业比重提高到28%以上。要全力推动"链长制"走深走实，聚焦24条重点产业链，开展产业链供应链对接活动60场以上，全力打通产业链供应链堵点断点。

第二，持续扩大有效投资。要抢抓国家政策窗口期，紧盯国家部委专项债券、特别国债、产业基金等政策走向，超前谋划储备项目，做深做实项目前期工作，确保更多项目纳入国家盘子。要加快推进重大项目建设，盯紧抓牢投资500万元以上重点项目，强化项目"赛马"机制，严格落实"五化"工作法，推动项目早开工、早建设、早投产。要全力激活民间投资，落实好促进民间投资13条政策措施，规范实施政府和社会资本合作新机制，撬动更多民间资本参与重大项目建设，力争全年民间投资增长8%以上。

第三，加快释放消费潜力。要扎实开展"消费提振年"行动，紧扣节假日消费、新消费、品质消费三个关键节点，组织开展汽车、家电、家居、餐饮、文旅等系列促消费活动100场以上。要大力发展数字消费、绿色消费、健康消费，培育首店经济、夜间经济、直播电商、即时零售等新型消费业态。要加快推动文旅消费恢复，精心办好秋季旅游节、冰雪节、庙会等特色活动，打造更多精品文旅产品，让商旅文体融合消费成为新增长点。要稳定住房消费，扎实做好保交楼工作，因城施策优化住房限购、信贷、公积金等政策，推动房地产市场平稳健康发展。

第四，更大力度稳外贸稳外资。要主动对接高标准国际经贸规则，深耕RCEP、《区域全面经济伙伴关系协定》等自贸协定市场，组织企业参加广交会、进博会、服贸会、消博会等100项国际展会，全力开拓国际市场，新增外贸订单50亿元以上。要加快培育外贸新动能，做大做强跨境电商、市场采购贸易、海外仓等新业态，推动外贸转型升级。要加大稳外资力度，落实准入前国民待遇加负面清单管理制度，进一步放宽外资准入，吸引更多外资投向先进制造业、现代服务业。

第五，统筹推进区域协调发展和乡村振兴。要深入实施区域协调发展战略，加快沈阳现代化都市圈建设，推动基础设施互联互通、产业发展协同协作、生态环境共保共治。要全面落实乡村振兴责任制，扛稳粮食安全重任，全年粮食产量稳定在80亿斤以上。要巩固拓展脱贫攻坚成果同乡村振兴有效衔接，坚决守住不发生规模性返贫底线。要大力发展县域经济，加快推进"一县一业""一镇一品"，推动更多项目、资金、技术、人才向县域倾斜，不断缩小城乡发展差距。

## 三、强化责任担当，确保各项部署落地见效

经济工作千头万绪，关键在落实，根本靠作风。各级党委、政府和广大党员干部要切实把思想和行动统一到党中央对经济形势的科学判断和决策部署上来，统一到省委、省政府和市委工作要求上来，进一步提振精神、强化担当、改进作风、狠抓落实，确保各项决策部署不折不扣落到实处、见到实效。

第一，要压紧压实责任。各地区、各部门主要负责同志要切实履行第一责任人职责，亲力亲为抓经济、扑下身子抓落实，分管领导要靠前指挥、统筹协调，做到守土有责、守土负责、守土尽责。要健全完善经济运行分析研判机制，定期调度、精准分析、及时预警，确保经济运行保持在合理区间。要严格督导考核，把四季度经济工作成效纳入年度绩效考核体系，强化考核结果运用，营造比学赶超、争先进位的浓厚氛围。

第二，要强化协同联动。各级发改、工信、商务、财政、统计、金融、税务等部门要各司其职、密切协作，加强政策协调、工作协同、信息共享，形成工作合力。各区县（市）要加强与市直部门对接联动，主动承接政策、项目、资金，形成上下贯通、左右协同的工作格局。各行业协会、商会、企业联合会要充分发挥桥梁纽带作用，及时反映企业诉求，帮助企业解决实际困难。

第三，要守牢风险底线。要切实防范化解重点领域风险，扎实做好政府债务、金融、房地产等领域风险防范化解工作，严守不发生系统性风险底线。要高度重视安全生产工作，深入开展安全生产治本攻坚三年行动，紧盯燃气、消防、矿山、危化品、道路交通、建筑施工、森林防火等重点领域，坚决防范遏制重特大安全事故发生。要全力做好信访维稳工作，妥善解决群众合理诉求，及时排查化解矛盾纠纷，维护社会大局和谐稳定。

第四，要切实改进作风。要深入贯彻中央八项规定及实施细则精神，持之以纠治"四风"特别是形式主义、官僚主义，切实为基层减负松绑。要大兴调查研究之风，深入基层、深入企业、深入项目一线，摸实情、办实事、解难题。要发扬"马上就办、真抓实干"的工作作风，说了算、定了干、干就干好，确保件件有着落、事事有回音。要坚守廉洁自律底线，严格遵守党纪国法，做到忠诚干净担当。

同志们，做好四季度经济工作，任务艰巨、责任重大。让我们更加紧密地团结在以习近平同志为核心的党中央周围，深入贯彻落实党中央、国务院决策部署和省委、省政府工作要求，坚定信心、保持定力，真抓实干、勇毅前行，坚决完成全年经济社会发展各项目标任务，为推进沈阳全面振兴全方位振兴实现新突破作出新的更大贡献！
