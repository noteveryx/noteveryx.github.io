# 申论每日一练 — 2026年10月21日

## 给定材料

民以食为天，食以安为先。2026年第三季度，全国食品安全监督抽检总体合格率稳定在99.2%以上。但高数据背后，问题仍不容忽视。

一是源头治理不严。食品小作坊、小经营店、小摊点"三小"主体占全国食品经营主体总数62%，无证经营、超范围经营问题时有发生。某省抽查14.6万家餐饮单位，索证索票不完整率达18%，进货查验记录"补记""代记"现象普遍。

二是过程追溯不畅。农产品批发市场食用农产品承诺达标合格率为92.1%，但承诺达标公示牌扫码溯源率不足3%；冷链食品运输环节温控记录仍以手工登记为主，数据不联网、不可追溯，出了问题"各说各话"。

三是基层监管能力不足。某地基层监管所人均监管食品生产经营主体超过300家，快速检测设备配备率不足四成，检验人才严重短缺。某县查办网络食品违法线索，因缺少专业鉴定手段，立案率不足受理量的18%。

四是执法处罚存在"以罚代管"。一些地方重罚款轻整改，罚完即止、屡罚不改，同一问题反复出现；处罚结果未公开曝光，威慑力打折。

五是社会共治尚未形成合力。行业协会自律作用虚化，"企业自我约束"停留在纸面；消费者投诉举报办理满意度仅76%，"发现问题—解决问题"的闭环尚未打通，社会监督力量未被充分激活。

对照经验：东部滨海市以"四个最严"深化改革，建成"一品一码"全环节溯源平台，13.6万家餐饮单位扫码率提升至94%；推行冷链温控数据联网监控，实行视频与物联网双备份；设立吹哨人举报奖励制度，最高奖励20万元；组建23支食品安全技术专家志愿服务队，快检车实现乡镇全覆盖；推动"阳光工厂"、明厨亮灶线上开放；推行食品安全责任保险，赔付金额同比增长37%；建立"三个不得"责任清单（不得瞒报漏报、不得以罚代管、不得降格处罚），食品抽检合格率连续三年位居全省前列。

## 参考答案

### 第一题：概括问题与对策建议

**一、主要问题**

1. 源头治理不严。"三小"主体占比高，无证经营、超范围经营问题突出，索证索票不完整、进货查验记录流于形式。
2. 过程追溯不畅。承诺达标公示扫码率不足3%，冷链温控记录手工登记、数据不联网，追溯链条断裂。
3. 基层监管能力不足。监管力量与主体数量严重不匹配，检测设备缺乏、鉴定人才短缺，线索成案率低。
4. 执法方式粗放。以罚代管、重罚轻改，处罚结果不公开，同一问题反复发生。
5. 社会共治乏力。行业自律虚化，企业主体责任未压实，消费者参与和监督渠道不畅，共治格局未形成。

**二、对策建议**

1. 严把源头准入。深化"三小"整治与证照规范化，落实进货查验与索证索票制度，压实企业主体责任。
2. 健全全程追溯。推广"一品一码"全环节溯源和冷链温控联网监管，让数据可查、过程可控、责任可追。
3. 提升监管效能。增加基层一线人员与快检设备配置，健全技术专家志愿服务和快检车下乡机制，破解"人少事多、不会查"难题。
4. 严格规范执法。完善"三个不得"责任清单，实行处罚与整改"双罚联动"，公开曝光典型案例，防止"查完即止"。
5. 构建共治格局。落实吹哨人举报奖励，畅通投诉举报"接诉即办"，发挥行业自律与媒体监督作用，倒逼企业诚信经营。

### 第二题：议论文

# 以"四个最严"织密责任网，让"舌尖上的安全"成为最实在的民生获得感

民以食为天，食以安为先。习近平总书记强调，食品安全是最大的民生问题。99.2%的抽检合格率背后，63万家"三小"主体仍是监管盲区，不足3%的扫码溯源率提示追溯链条仍有断点，人均监管300家主体暴露基层力量短板——这些事实警示我们，食品安全防线并非天然牢固，唯有以最严的标准、最严的监管、最严的处罚、最严的共治，才能让人民放心消费。

立"最严的标准"，让每一道门槛都可度量。标准是食品安全的第一道防线。当前索证索票不完整率高达18%，根源在于部分标准停留在文件里、悬挂在墙面上。应当以国家标准为基准，结合过敏原标识、添加剂使用、冷链温控等新兴风险点，制定可量化、可操作、可追溯的细则，把抽象条款细化为操作手册，把"应当"细化为"必须"。同时加快标准更新速度，与新技术新业态同步，避免标准滞后于产业，让准入门槛真正硬起来、准起来。

织"最严的监管"，让每一个环节都看得见。过程追溯不畅是最大的监管漏洞。应当借鉴"一品一码"经验，以数字化手段打通产地、流通、消费全链条，将承诺达标公示、冷链温控记录、加工制作工序全部纳入平台监管，视频与物联网双备份校验，让数据可查、过程可控、责任可追。监管力量要向基层下沉，通过技术专家志愿服务队、快检车进乡镇，把检测能力送到田间地头、街头巷尾，破解"看得见的管不着、管得着的看不见"困局。

亮"最严的处罚"，让每一次违规都付出代价。以罚代管是最容易养痈贻疾的执法方式。必须完善"三个不得"责任清单，处罚与整改双罚联动、罚款与信用惩戒同步推进，对屡罚不改的从重处罚，对主动报告、立即改正的从轻裁量，形成"放过一马、祸害一方"的不良导向。同时晒出处罚结果、公示典型案例，让违法者无处遁形，让守法者安心经营。

聚"最严的共治"，让每一方力量都成为防线。食品安全没有旁观者。要用好吹哨人举报奖励制度，激励内部人员吹哨；畅通"接诉即办"闭环，让消费者诉求直达执法一线；推动"阳光工厂"、明厨亮灶线上开放，让厨房走进直播间；发挥行业协会自律和新闻媒体监督作用，落实食品安全责任保险，让守信者获得补偿、失信者付出代价，构建政府监管、企业自律、社会监督、公众参与的共治格局。

从"小作坊"到"大平台"，从"抽检合格"到"全过程放心"，考验的是治理理念的转换。标准要立在最严处、监管要织在密处、处罚要落在实处、共治要聚在合力处，才能真正让人民群众从"担心吃什么"到"放心吃什么"，让"舌尖上的安全"成为最实在的民生获得感——这既是执政为民的初心所指，更是中国式现代化的应有之义。
