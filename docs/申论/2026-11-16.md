# 申论每日一练 — 2026年11月16日

## 给定材料

见义勇为是中华民族的传统美德，也是社会治理的重要资源。近年来各地不断健全权益保障机制，但一些地方仍存在"认定慢、保障弱、维权难"问题。某市近三年受理申报217起、认定89起，认定率不足四成；"制止违法犯罪"与"互殴""民事纠纷"边界模糊，同一行为在不同区县结论不一；申报需跑6个部门、交11份材料，平均办结超90天。一位救助晕倒老人的市民因按压致其肋骨骨裂，被家属索赔12万元，虽判决不担责，却耗时19个月、花费律师费4万余元。另一位救人致残的村民医疗费自付28万元，仅获慰问金2万元，康复无着落。调查显示，83%的受访学生不知如何申报，近半数担心"救人反被讹"。

与之相对，东部滨海市出台认定"三张清单"，明确应当认定、可以认定和不予认定的情形，7个工作日办结、全市互认；将医疗救治、伤残鉴定、长期补助、子女入学、住房保障集成为"一件事"办理；建立法律援助绿色通道，见义勇为引发的民事诉讼免收诉讼费并可由基金垫付律师费；对诬告讹诈者依法追责、公开澄清正名；发放"好人礼遇卡"，享受免费公交、体检、景区游览和就医优先。三年来该市申报量增长2.1倍，认定率升至86%，群众安全感满意度达96.3%。

## 参考答案

### 第一题：概括问题与对策建议

主要问题：一是认定标准模糊。行为边界不清，各地结论不一，申报环节多、周期长，认定率偏低。二是权益保障碎片化。多为一次性慰问，医疗、伤残、康复、子女入学缺乏制度衔接。三是法律救济成本高。救人者被索赔后举证难、耗时久、花费重，"赢了官司也寒了心"。四是诬告讹诈成本低。讹人者鲜被追责，负面示范效应明显。五是社会氛围不浓。申报渠道知晓率低，宣传集中于表彰节点，群众"想救不敢救"。

对策建议：一是统一认定标尺。制定应当认定、可以认定、不予认定三张清单，压缩办理时限，实行跨区域互认。二是集成权益保障。将医疗救治、伤残鉴定、长期补助、子女入学、住房保障打包办理，建立长期照护机制。三是畅通法律救济。开通法律援助绿色通道，明确紧急救助免责规则，减免诉讼费并由基金垫付律师费。四是严惩诬告讹诈。依法追责并纳入信用惩戒，及时公开澄清正名。五是浓厚向善氛围。发放礼遇卡，壮大义勇基金，推动宣传进校园、进社区。

### 第二题：议论文

**为善意撑腰 让正气充盈**

习近平总书记指出，见义勇为行为是光荣的，见义勇为精神是不朽的。一个社会的文明程度，不只写在经济总量里，更写在陌生人遇险时有人伸手的一瞬间。然而现实中，"认定慢、保障弱、维权难"消解着英雄的底气，也让旁观者心生迟疑。弘扬见义勇为精神，不能只靠道德感召，必须用制度刚性为善意撑腰。

以标准之"明"，让义勇之举认得准。认定是权益保障的第一道关口，标准模糊就会让英雄在门口徘徊。某市三年申报217起、认定仅89起，同一行为在不同区县结论不一，暴露的正是规则粗疏。东部滨海市以"三张清单"划清应当认定、可以认定、不予认定的界限，7个工作日办结、全市互认，认定率跃升至86%。善行需要一把可度量的尺子，把模糊地带变成清晰条款，把多头跑动变成一窗受理，让每一份挺身而出都被及时看见。

以保障之"实"，让挺身而出无后顾。英雄流血又流泪，是最伤人心的场景。救人致残自付28万元医疗费、仅得2万元慰问金，这样的账单警示保障不能停留在节日慰问和一次性奖励上。滨海市把医疗救治、伤残鉴定、长期补助、子女入学、住房保障集成为"一件事"，让保障跟着人走、跟着需求走。权益保障应当从"给一笔钱"转向"兜一生底"，建立动态跟踪、长期照护、家庭帮扶的全周期机制，让救人者在康复路上不孤单。

以法治之"刚"，让诬告讹诈付代价。善意最怕被反咬一口。救人被索赔12万元、耗时19个月、花费4万元律师费，即便胜诉，付出的心力也难以弥补。倘若讹人者毫发无损，救人者独自举证，"不敢救"就会成为理性选择。必须明确紧急救助的免责规则，让法律为善行划定边界；开通法律援助绿色通道，减免诉讼费、由基金垫付律师费，把维权成本降下来；对诬告讹诈者依法追责、公开澄清正名，把违法成本提上去。

以礼遇之"暖"，让崇德向善成风尚。制度托底之外，还需情感认同。83%的学生不知如何申报，近半数群众担心"救人反被讹"，说明宣传不能只在表彰大会的聚光灯下。滨海市发放"好人礼遇卡"，免费乘公交、免费体检、景区优待、就医优先，让英雄在日常细节里被尊重；义勇基金汇聚社会力量，让褒奖可持续。当礼遇可感、故事可亲、渠道可知，见义勇为就会从少数人的壮举变成多数人的习惯。

"见义不为，无勇也。"一个民族的精神高度，往往由关键时刻的凡人义举标注。用清晰的标准确权，用实在的保障兜底，用刚性的法治护航，用温暖的礼遇褒扬，就能让每一次伸手都有回响，让崇德向善的涓涓细流汇成社会治理的磅礴力量。
