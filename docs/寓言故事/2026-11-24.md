# 2026-11-24 寓言故事 · 杏子沟的果课

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

宣德三年，朝廷把北地杏子沟的果子收作官课。设课之初，规矩很简单：沟里三十七户共种杏千余亩，杏熟时雇人收成，晒成干果，运到边镇换银。县里派了个果课吏，姓庞，五十来岁，最爱一张表，唤作《验果簿》。

这簿子只记两栏：交果多少斤，领课钱多少两。头一年簿上的数字极好看。沟里人欢喜——交得多领得多，秤就搁在衙门口，谁家果子好谁家秤上重，人人心服口服。

第三年，出事了。先坏的是筐。往年交果是一筐一筐抬进仓，庞吏顺手按筐记账，写"户某，交筐三十"。一筐该装多少，簿上没写。头一年筐小，装得实；到第三年，杏子沟家家开始做"高架筐"——筐底垫两根横木，中间架空，底下塞一捆稻草。抬起来轻省，摞起来高，庞吏数筐数一清，五十筐交上去。

官仓满屋子是筐。剥开一看，露水泡过的杏子垫在稻草上。剥到第七筐，底下已经渗出水来。庞吏一趟没细究，只嫌麻烦，在簿上打了个"合格"。

第四年更荒唐。果子干脆不上秤了。有人在筐底压石板，有人在麻袋里灌两斤盐水——湿货压秤。验果簿上斤两节节往上，沟里的真杏子反倒没人好好收。有人干脆在山沟外辟了新园子，只干一件事：把外头买来的干果从自家筐上头过一遍，蹭个"交果"的名头。

庞吏的簿子成了真的果课，晒干的果子反倒没人管了。

到第七年，朝廷查课。杏子沟果课银足额入库，户册齐全，账目挑不出一处错——只是三年之后，边镇干果市价跌了三成，因为再没人做真果了。沟里三十七户走了十九户，山坡上的杏树撂了荒。旧册子翻到最后一页，是庞吏自己的批语：**"课已足额，谨此上报。"**

新来的县丞姓杜。她把《验果簿》翻了三遍，只问一句："簿上记的是筐，还是果子？"

庞吏得意："当然是交到仓里的果子。"

杜县丞摇头："那还是筐。"

她做了三件事。第一件，新到的果与往年陈果分开堆，中间隔一道板，板后站两个人，不许说话，只许记数。第二件，她伸手掂——同样一筐，掂起来轻飘飘的，那就有问题；她拿这一掂去校秤。第三件最狠，她在簿上添了两栏，一栏记"交来的干果斤两"，一栏记"当年出园的鲜果斤两"，两栏写同一户的名。

头一年，两栏对不上的人家最多。有的人交上去的干果比出园鲜果还重，那是灌水塞石头；有的人两栏差不多，那是真货实秤；还有人出园鲜果多、交上去的干果少——果子被中间人吃了，或者晒的时候烂了没敢报。

杜县丞把出成比写在自己案头：十斤鲜果该出六斤干果，谁家出成不足四斤，粮不换果，税照交。她还立了一条：出成比要一年比一年看，不许一家独涨；涨得太漂亮的，来年要查仓库。

第三年，沟里的账终于看得懂了。有人开始把自家仓的翻晒次数记下来，因为出成比高说明果子好、晒得细；有人开始请人修漏雨的晒架，因为烂掉的果子比被人偷的果子更贵。

有人问庞吏："当初簿上不也记了两栏么？交了几筐、领了几两银，这也是两栏啊。"

庞吏脸一红。

杜县丞说："你那两栏数的是筐子，我这头一栏称的是果子。袋子不一样。"

那年杏子沟的果课银，第一次比头一年少了两成。而库里第一次装的全是能吃的果子。

## 这个故事在讲什么

### 概念

**古德哈特定律**（Goodhart's Law）：**当一个度量指标变成了治理或奖惩的目标，它就不再是一个好的度量指标。**

更精确地说，它说的是一种机制性失效，而不是"指标天生不可靠"。一个指标在没被盯着的时候，可以诚实地反映系统状态；一旦它挂上赏罚，人的优化行为就会自动把系统推向"指标好看但目标落空"的状态，而且往往还推得很远。

它常被表述成"当一个测量变成目标，它就不再是一个好的测量"。这句英文原话出自英国经济学家查尔斯·古德哈特 1975 年在一次讲演中的表述，后由玛莉·斯特拉森（Mar Strathern）在 1997 年整理成现在通行的形式。

### 边界：几个容易混的东西

- **与坎贝尔定律（Campbell's Law, 1979）不同。** 坎贝尔说的是"越测量，越可能退化"——测量的副作用是普遍的，只要测就可能扭曲，哪怕没人给它发奖金。古德哈特则更窄更狠：一旦它成了奖惩目标就必然失效。两者常被并列引用，但坎贝尔是"测量的恶"，古德哈特是"把测量当目标"的恶。
- **与委托代理理论（agency theory）不同。** 代理理论关心的是"怎么设计契约让代理人别偷懒"，它默认指标集是给定的、固定的。而古德哈特指出的是：在指标集固定的前提下，代理人的最优反应本身就会让指标失去代表性。所以契约设计只能缓解，不能根治。
- **与多任务理论（Holmstrom & Milgrom 1991）互补而非竞争。** 多任务理论给出的标准解法——同时考核多个维度、让代理人之间互相牵制——正是针对古德哈特。
- **与"代理指标（proxy）用错"不同。** 狭义的"古德哈特化"（Goodharting）指的就是"拿一个指标当决策依据，然后被优化坏"。古德哈特定律是它的上位概念：它给出了失效为什么会发生的原理。
- **与机器学习里的目标函数替代（objective function substitution）是同一件事的两种说法。** 训练损失是代理指标，真实目标是另一回事；强化学习里的"奖励黑客"（reward hacking）是它在算法侧的兄弟。

### 生活中的小例子

- 老师说"每本书读一遍就算一个阅读量"→ 学生拿一本书读五十遍，统计漂亮，阅读没发生。
- 客服主管用"平均通话时长"考核→ 客服学会了三十秒挂断，工单堆积。
- 短视频平台用"完播率"做推荐目标→ 标题党和前三十秒钩子泛滥，长内容被系统性压低。
- 医院考核"平均候诊时间"→ 数字好看了，重症和罕见病人被劝退到别的医院。
- 科研用期刊影响因子当评价指标→ 论文往少数热门期刊挤，冷门但重要的问题没人做。

### 陷阱一：把它读成"指标都是坏的，取消 KPI"

这是最常见的误读。古德哈特说的不是"不要度量"，而是"不要让单个度量垄断奖惩"。杜县丞不但没有取消《验果簿》，她还添了两栏、添了抽样复核、添了逐年比对。度量本身没问题，问题在于**度量被单独供上祭坛，而系统失去其他校验**。正确解法是：多指标 + 过程指标与结果指标结合 + 抽样稽核 + 定期重新校准，而不是取消。

### 陷阱二：以为"指标公开还是保密"决定了它会不会失真

古德哈特定律的驱动力是激励结构，不是透明度。庞吏的簿子全村都看得到，可它照样被架空；一个没人看得到的内部指标，照样会被优化坏。保密最多把造假藏深一点，改变不了"代理人朝指标方向使劲"这件事本身。

### 陷阱三：把它当成道德指控

被优化的不是坏人，是理性人。造高架筐、灌盐水、在山沟外辟园子蹭名头的人，每一个人在当时的情境下都是最优反应。责任在指标设计，不在造筐人的良心。把这件事讲成"下面的人素质差"，就永远找不到解法。

### 古德哈特定律的 N 层用途

1. **组织治理**：绩效体系设计、考核指标设计、防止指标驱动的资源扭曲。
2. **公共政策**：GDP、犯罪率、就诊等待时间、学校升学率的治理效应。
3. **机器学习**：代理损失与真实目标不一致、奖励黑客、分布外泛化失败。
4. **科研评价**：影响因子、引用数作为研究方向的指挥棒。
5. **平台经济**：点击率、停留时长、留存率作为内容与商家的优化目标。
6. **自省工具**：当你自己团队开始优化某个数的时候，就是警报响起的时候。

## 故事里的隐喻，对应着什么

| 故事元素 | 学术对应 |
|---|---|
| 《验果簿》 | 度量指标与考核系统 |
| 庞吏 | 代理人 / 指标治理的执行者 |
| 官课银（赏罚） | 指标与激励的挂钩，是失真的发动机 |
| 交筐三十 | 代理指标（proxy），与真实目标只有松散关联 |
| 高架筐、垫木、塞稻草 | 指标操纵（Goodharting） |
| 筐底压石板、灌盐水 | 代理指标被"直接造假"，比间接优化更粗暴 |
| 山沟外辟新园、买干果过筐 | 指标性生产：为指标而生产，脱离真实价值 |
| 干果市价跌三成 | 真实系统的长期供给能力被侵蚀 |
| "课已足额，谨此上报" | 指标达成 ≠ 目标达成 |
| 走掉十九户、杏树撂荒 | 激励错配的不可逆后果 |
| 新旧果分堆、两人只许记数 | 抽样稽核 / 对抗性验证（防"测量被污染"） |
| 伸手掂一掂 | 定性校验与计量校准 |
| 簿上添"交来干果"与"出园鲜果"两栏 | 多指标 + 结果指标与过程指标交叉验证 |
| 十斤鲜果该出六斤干果的出成比 | 比率型校验指标（对规模、含水量不敏感） |
| 出成比逐年看、不许一家独涨 | 防止"新指标也会被古德哈特"：持续校准与横向比对 |
| 粮不换果、税照交 | 激励相容的负向约束 |
| 果课银少两成、库里全是能吃的果子 | 真实目标达成：账面退步，系统进步 |

## 一句话总结

> 指标一旦挂上奖惩，人就会替你去优化它——而优化的正是指标，不是你真正想要的东西。

这就是古德哈特定律。

## 记忆口诀

- 口诀 1：**指标成了目标，就不再是好指标。**（Strathern 1997）
- 口诀 2：**古德哈特定律是"当目标就失效"，坎贝尔定律是"一测量就退化"——一个讲动机，一个讲副作用。**
- 口诀 3：**代理指标最怕单点供奉：多指标、过程加结果、抽样稽核、逐年校准。**
- 口诀 4：**新的指标也会被古德哈特。** 换指标不是解法，持续校验才是。
- 口诀 5：**指标好看不等于目标达成；指标变差有时正是系统在变好。**（杜县丞少收两成果课银）
