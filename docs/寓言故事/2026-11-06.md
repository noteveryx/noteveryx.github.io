# 2026-11-06 寓言故事 · 两部经

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

石桥村有一部祖传手抄经卷，叫《河图经》。村子背后那道青石岭上有一排石龛，每代抄经人抄完一部，就在自家龛里放一块青砖，砖上刻着代数。龛从岭脚一直排到岭顶，砖一块压一块往上摞。老人说，这就是这部经的家谱。

最早那几块砖磨得看不清字。越往上，抄本上的字越"走样"：有的把"之"写成"乙"，有的把"川"并成两道，有的多出一个点。老人指着岭上说：抄得越久，规矩越乱。

岭上住着一位姓沈的老先生。他不评好坏，只做一件事：拿两本抄本逐字对，凡念出来意思一样的，划一道杠；凡是念出来意思变了的，不划杠，反而画个圈。

他先挑最老的那几代来看。"要紧字"——人名、山名、那些错一个字整段就颠倒的关键字——一百本里几乎不错一处；"不要紧字"却错得五花八门。

老人们不服："那不还是抄错了？"

"要紧字你们为什么不错？"

"谁敢错！念给人听，一听就知道。"

"知道了就改回来，改回来，你们的本子还是那部经。"沈先生说，"不要紧字没人念得出错，你们就没改。它就一路错下去了。"

这话被岭下一个收抄本的外地人听见了。他做买卖不看品相，只数"不一样的地方"有多少。他从三家抽屜各抽一本，一页页对，翻完拨算筹。

"这两家差十一个地方。那两家差二十四个。"

老人们围上来："你凭啥说十一个就是十代？"

他把三本摊开，指着那些多一笔少一笔的字："这些字念出来都一样。错在哪一处，多半是当年某位祖先手一抖，或那天抄到天黑看不清，或他心情好写得仔细些——都是不管紧的地方。它一旦错了没人改，就一代一代往下传。一代多一处。数出十一个，就是十代之前的十次'不管紧'。"

岭上一时静了。

沈先生这才开口。他用石头在沙上写了一整面：要紧字全对得上，不要紧字对不上。

"你们的经还是那部经，谁念都不会念错，"他说，"可它已经成了三部经。不是谁抄得更用心。是有些字不会错，有些字没人管。"

没人接话。老人们还惦记那个"错"到底算不算坏事。

沈先生说："你们村的'之'写成'乙'，念经的时候是坏事；可它不耽误念经。一百年后你们和邻村的字认不出来了，也不耽误念经。"

那晚货队走了。沈先生独自留在岭上，把沙面抹平重写，写了一行：**要紧的字，一错就露，露了就改；不要紧的字，错了没人看，没人看，就一路错到底。**

第二天清早，岭脚又来一支队，收的是《桑叶经》。村里人奇怪：《桑叶经》粗陋得很，是几十年前一个懒和尚随手抄的，怎么也值得专门来收？

收货的人说：不是收经，是收"账"。他数《桑叶经》的"不要紧字"，发现它错的地方一点也不比《河图经》少，一代也是错那么几个。

"它抄得那么粗，走样怎么还不比《河图经》快？"

"因为它每代错的数，跟《河图经》每代错的数差不多。"那人说，"走样快慢，跟经的好坏没关系。"

沈先生听见了。这时村里又传来消息：去年冬天瘟疫，两个抄经人没了，只剩一个孤儿顶班。那一年全村只出了一部抄本，孤本上的错字数目格外扎眼——翻查旧砖才发现，那两年各家的写法明显乱了一大截。

沈先生怔住了。他去翻最底下那几块老砖，才看清一件事：那两年村里只剩一两个人抄经，一个人手一抖的错法，成了那年全村的写法。等人手回来，这写法仍旧改不掉——它已经成了"祖上传下来的规矩"。

他在那面沙上又添了一行：**字错得多不要紧，要紧的是错字碰上一个孤本的时候，全村都成了那一个。**

## 这个故事在讲什么

### 概念

**中性演化理论**（Neutral Theory of Molecular Evolution，木村资生 Kimura，1968 / 1983）。

一句话：当一个分子层面的改变对生物的适合度影响小到自然选择分辨不出来时，它的命运由**随机漂变**决定，而不是由"更好／更坏"决定。

三点关键：

1. **"中性"是相对于适合度而言，不是"没有功能"。** 一个错别字让经书念不通，那是非中性；一个多一笔少一笔、念出来意思一样的字，那是中性。判据只有一个：改掉它，会不会影响个体留下后代的数量。
2. **漂变如何决定命运。** 一个新突变在群体里的初始频率约为 1/(2N)（N 为有效群体大小）。若它是中性的，最终固定下来的概率恰好等于初始频率——大群体里几乎注定消失，小群体里更容易"碰上"并传下去；一旦固定，就是全体成员都带着它，与它好不好无关。
3. **由此得到一个反直觉的结论：替换速率 ≈ 突变率，与生物的大小、复杂程度无关。** 一个只活一天的细菌和一头大象，只要突变率相同，每一代积累的中性替换数目就差不多。复杂性不靠"多抄错几个字"堆出来。

**分子钟**是这个理论最著名的副产品：当替换主要由突变和漂变决定时，两条谱系分开后，序列差异应当随时间近似线性增长。于是"数一数不一样的地方有多少"就能倒推"分家多少年了"——不需要化石，不需要年轮。

### 与近义概念的边界

- 中性论**只主张**在分子层面、多数位点上，替换的主力机制是漂变；它没有否认选择。形态、生理、行为层面的改变仍大量由适应推动；功能位点上的有害突变会被迅速清除。
- 中性 ≠ 无用。很多中性位点有结构或功能后果，只是后果弱到在当前环境里不足以被选择分辨。
- 中性论与**近中性理论**（King & Thomas, 2010）的差别在于：当 |N·s| 不大时（群体不大、选择系数很小），漂变与选择难分，替换速率就与 N 有关，分子钟也会走偏。
- 与**遗传漂变**的关系：漂变是机制，中性论是关于"多数替换属于哪一类"的论断。单个漂变事件本身无所谓中性不中性。
- 与**适应基因之争**的关系：基因组学时代有一派主张物种间基因组差异大多是适应性的，中性论是这场争论的坐标原点。

### 3-5 个生活例子

1. **错别字**："已经"打成"己经"没人改，因为意思没变；"三令五申"打成"三今五伸"，全村都回头重抄。
2. **口音**：几十代之后，山前山后的口音分得越来越开，谁也没因此更有优势；可一旦分家，差异就固定下来，谁也改不回去。
3. **族谱与 DNA 鉴定**：DNA 差异越多，说明两家分开越久——这是法医亲缘鉴定和寻亲的基本逻辑。
4. **手抄药方**：同一张方子传两百年，改动十几处，剂量禁忌全变了，没人说得清哪一处是原方、哪一处是某人手抖。
5. **产品外观件**：键盘布局、图标圆角、包装配色的改动多数与功能无关，但照样一代代定型，最终让两家"同源"产品看起来毫不相干。

### 陷阱一：把"中性"读成"没有意义"

中性判据是"对适合度的影响小到选择分辨不出"，不是"这个位点毫无功能"。同一个替换，在实验室环境里无害，在野外可能有微弱优势；而微弱优势在小群体里仍会被漂变淹没。"中性"始终是相对于特定环境、特定群体、特定突变而言的。

### 陷阱二：把中性论读成"自然选择是错的"

这是最常见的误读，也是当年 Kimura 被围攻的核心。事实相反：中性论让人们第一次能定量估计净化选择的强度（在重要功能位点上选择效率极高），并把"选择负责什么、漂变负责什么"分开。功能约束与选择从来是同一件事的两面。

### 陷阱三：把分子钟当成一把直尺

"近恒定速率"是粗略近似：不同位点的突变率差别很大（有些字抄一百遍必错，有些几乎不错），不同谱系的世代时间不同，不同环境下的突变率也不同。当比较的时间跨度远大于世代时间时，速率异质性会让推算明显偏离。真实做法是松弛钟、多速率模型加化石校准，而不是一把直尺。

### 陷阱四：把"差异多"读成"更高级或更落后"

差异多是中性替换堆积的结果，与优劣无关。《桑叶经》错得不比《河图经》少，这个细节就是整个理论的反面注脚。

### 中性演化理论的 5 层用途

1. **定年与谱系重建**：从差异数目推分歧时间，是系统发育学、病原体溯源、法医亲缘鉴定的基础工具。King & Thomas（2010）用线粒体溯祖树深度反推物种分化时间，是这一支最漂亮的成果之一。
2. **检验选择的强度**：McDonald–Kreitman 一类方法用"多态位点上的非中性比例 vs 固定差异中的非中性比例"之比估计选择，中性模型正是它的零假设。
3. **解释基因组复杂度的来源**：基因组大小与生物复杂性脱钩（基因组悖论），用中性替换速率加有效群体大小可给出定量解释。
4. **近中性框架成为演化基因组学的通用语言**：当 N·s 接近 1 时，选择与漂变势均力敌，演化速率与适应能力都跟 N 挂钩。
5. **临床与法医应用**：肿瘤突变时钟、SNP 位点连锁不平衡估计有效群体大小、家系与群体谱系匹配，都直接拿中性模型当零假设。

## 故事里的隐喻，对应着什么

| 故事元素 | 学术对应 |
|---|---|
| 祖传手抄经卷《河图经》 | 分子序列（基因组） |
| 一代抄一代，每代传副本 | 沿谱系逐代的复制与突变累积 |
| 青石岭上一块砖一代 | 谱系的代际排列（序列差异矩阵） |
| "要紧字"（人名、山名、关键字） | 功能位点，受净化选择强约束，突变被迅速清除 |
| "不要紧字"（多一笔少一笔，念出来一样） | 中性位点，替换对适合度的影响可忽略 |
| 念出来意思变了 → 被发现 → 改回来 | 净化选择：不适配的替换被清除 |
| 没人念得出错 → 没人改 | 选择"看不见"的位置，漂变自由通过 |
| 数"不一样的地方" | 序列差异数（替换数） |
| 差异数 ∝ 分家代数 | 分子钟：近似恒定的替换速率 |
| 用差异倒推年代 | 分子钟定年、溯祖分析 |
| 抄经人手一抖／天黑看不清 | 随机突变，不带方向，也不带意义 |
| 《桑叶经》错得不比《河图经》少 | 替换速率由突变率决定，与复杂程度、体量无关 |
| 瘟疫年只剩一个孤儿顶班 | 有效群体大小 N 骤降，漂变增强 |
| 一人手抖的错法成了那年全村的写法 | 中性替换随机漂变至固定（fixation） |
| "经还是那部经，可它已经成了三部经" | 功能保守与序列发散同时成立 |

## 一句话总结

> 分子序列的大多数变化不是被"挑"出来的，是被"漂"出来的——只有那些错了就会出事的字，才有人在旁边盯着改。

这就是 **中性演化理论（Neutral Theory of Molecular Evolution）**。
