# 2026-11-17 寓言故事 · 分水记

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

青石渡口有一道分水渠，渠首一道木板闸，三户人家共用一条水。

沈家住渠头，地最厚；柳家住渠尾，地最薄；中间那片叫三分田，归何满仓。老规矩是：清明放水，头七天归沈家，第二个七天归柳家，最后七天归何满仓。规矩立了二十年，没红过脸。

有一年上游修了新坝，水比往年少两成。秋后三家在闸房算账。沈家说自己家吃水最足，该多担；柳家说自己那段渠渗得厉害，也该多担；何满仓把去年的收成册子摊开，一页页翻给人看。他不是说少，是说"欠"。去年该到手的那部分他没摸着，今年还是那个数，他记了两年。

"一样的水，怎么还有欠不欠？"沈家问。

没人答得上来。

又有一年上游大水，水从渠口溢出去。三家都多得收成，粮囤装不下，多出来的堆在院子里，谁也不觉得多。柳家后来说，那年多出来的粮他记不清是多少；少的那年他记一辈子。

"那今年怎么分？"沈家提议掷签定次序，旱年让上年收成最少的那家先开闸。众人当场翻脸。何满仓说："我不要先开闸，我要平分。"众人惊："你八亩薄田，一半的水都不够，你要一半做什么？"

"我什么都不要，"何满仓说，"我只要那个'一定'。"

沈家不懂。何满仓解释：给他平分，他年年都有一半；给他"五成可能整渠归他，五成可能一滴没有"，他死活不肯换。旁边老陶插嘴：人就是这样，宁要手里那份稳的，不要天上那口大的。

春上有卖"雨签"的：一张一文，押哪天会下雨，押中加倍，押不中全损。老陶买签从不要"必中"的，也不要"多半"的，专挑"三成"。

"你买三成的？"

"我买三成的雨，我总觉得轮不到我家下。"

可老陶家屋顶年年漏，他年年买"必赔"的那张，晒谷子时一天看三回。他说那签上盖着印的。

沈家买签专押"上游今年开闸晚"——他说"我年年盯着上游，我比谁都清楚"。他最懂的那件事，也是他押得最重的那件事。

那年年底算总账，老陶输得最多。

账房写条子有两种写法。给沈家："今年灌了三分水。"沈家念着挺高兴。给何满仓："今年少了七分水。"何满仓把条子推回去，脸沉下来。同一件事，一句话之差。

"不是三分。"何满仓说，"是七分。"

从那以后何满仓的册子多了一栏，分三行：今年实际得了多少；比去年少了多少；少了以后还差多少。第三行他一直没填。有人问为什么，他说填上那个数，一年就过不下去了。

闸房的老墙上他后来刻了一行字，刻得很浅：

"水不看你亏了多少，只看你从哪一笔往下数。"

## 这个故事在讲什么

**前景理论**（Prospect Theory）：一个描述人在不确定条件下如何做选择的模型，由丹尼尔·卡尼曼与阿mos·特沃斯基在 1979 年提出，2022 年诺贝尔经济学奖表彰的行为科学工作以此为核心。

它的核心主张有四条，故事里每一条都有一个对应的物件：

1. **参照点依赖**：人的评价不是看绝对结果，而是看结果相对某个参照点（故事里何满仓的"去年"、沈家的"渠头"）。
2. **损失厌恶**：同样的绝对量，"少"比"多"痛得多（"欠"与"记一辈子"）。
3. **价值函数不对称**：收益区是缓的（多得记不清），损失区是陡的（少得记一辈子）。
4. **概率加权**：人对概率的感知不是线性的，小概率被高估、中高概率被低估（老陶的"三成雨"与"必赔签"）。

**边界辨析**（容易混的近邻）：

- **对比期望效用理论**：期望效用假设人对金钱结果用线性效用函数加权求和，且用原始概率；前景理论不是它的"更精确版本"，而是一个行为描述模型——它说的是人实际怎么算，不是人应该怎么算。
- **对比"风险厌恶"**：风险厌恶是对波动本身 concave 的偏好；损失厌恶是价值函数在零处不对称（损失一单位的痛约等于收益两单位的乐）。二者可以独立存在，一个稳赢不亏的选项照样能惹人拒绝。
- **对比"心理账户"**（塞勒）：心理账户讲的是人怎么把不同钱分门别类地记账；前景理论讲的是结果怎么被评价。前者是抽屉，后者是尺子。
- **对比博弈论里的"前景"**：那是另一个数学概念，与心理决策无关。
- **对比规范性的"最优决策"**：前景理论不评价对错，它给出的是可估计的参数（损失厌恶系数、权重函数拐点）。

**生活中的落地例子**：

1. 保险：保费 100 保 1000、胜率 1%，很多人不买；2% 概率赢 50 块的彩票却人人抢——这是小概率被高估的直接后果。
2. 手里的股票跌 10% 就割肉，没拿着的股票涨 10% 却不追——参照点是"自己的成本"，而净值本身没变。
3. 卖不掉的旧冰箱：自己拉走要付车钱，退货运回要付运费，价同，选择完全不同——因为参照点是"已经拥有"。
4. 涨 10% 的高兴抵不上跌 10% 的难受：同一条净值曲线，人的心情不对称。
5. "稳拿 45" 与 "五成赢 100、五成归零"：多数人选前者，尽管期望一样。

### 陷阱一：以为前景理论是说"人不理性"

**错。** 它是描述性模型，不是判决书。规范性的期望效用仍然告诉你什么该做；前景理论告诉你现实里人怎么做，所以它能预测偏差发生在哪一步。把它当成"你错了"的证据，等于用天气预报去指责没带伞的人。

### 陷阱二：把损失厌恶和风险厌恶混为一谈

**错。** 风险厌恶是对"波动" concave；损失厌恶是价值函数在参照点两侧不对称。一个只有上行、没有下行的选项（稳赚）依然可能被拒绝——因为它相对参照点仍然算"没赚到"。混同这两个会让人误以为"消除风险就能消除损失厌恶"，而实际上消除波动不改变不对称性。

### 陷阱三：以为参照点是客观事实

**错。** 参照点常常是被构造出来的、可被框架操纵的：写"灌了三分"还是"少了七分"，写"损失"还是"节省"，把"我们"改成"你们"。同一个客观数字，换个框就换一个感受。所以用前景理论做政策沟通时，第一步永远是先把参照点摆明。

### 陷阱四：以为把公式参数改对就完事了

**错。** 卡尼曼自己反复说过：修正参数往往救不了一个"框架选错了"的市场。概率权重函数不是对客观概率的更好估计，它是主观的；用主观权重去做"客观期望值最大化"，本身是循环的。实践里有效的是改变选项的呈现方式（先问参照点是什么），而不是求一个更准的 λ。

### 陷阱五：以为前景理论能解释所有非理性

**错。** 它解释不了注意力、习惯、社会规范、注意力稀缺带来的后果。禀赋效应有时是参照点造成的，有时纯粹是"转换成本"和"默认选项"造成的；两者可以叠加，拆不开时不要硬套。

### 前景理论的 N 层用途

1. **解释保险与彩票的错配**：小概率高估 → 低概率风险被忽视、高概率小奖被追逐。
2. **解释交易行为**：亏损卖出、盈利不卖、"处置效应"。
3. **解释风险投资的阶段反转**：早期成功→参照点抬升→遭遇损失→切换到失败框架→追求确定性或极端冒险。
4. **解释政策与定价沟通**：参照点选择（比去年涨还是比隔壁便宜）、框架（涨价 vs 补回差额）、把长期收益拆成多个小赢。
5. **解释谈判与分配**：损失的痛大于收益的乐，所以让步的门槛不对称，"收回 100 的伤害大于送出 100 的好处"。
6. **解释市场异象**：处置效应、彩票偏好、股权溢价的彩票需求假说。

## 故事里的隐喻，对应着什么

| 故事元素 | 学术对应 |
|---|---|
| 三家共一条渠、按七天轮水 | 结果在某参照点下的分配与评价 |
| 何满仓的"欠"（而非"少"） | 损失编码：相对参照点的负偏离 |
| 去年那七成 / 沈家的"渠头" | 参照点（参照依赖的锚） |
| 大水年多得记不清，少的记一辈子 | 价值函数：收益区凹（收益递减）、损失区凸（损失加剧） |
| "平分"与"五成可能整渠归我" | 确定性效应 / 凸显性；凸显概率权重 |
| 老陶专买"三成雨"，却年年买"必赔签" | 概率权重函数 S 形：小概率高估、中高概率低估 |
| 沈家专押"上游开闸晚"，因为他最懂上游 | 过度自信与知识盲区：最懂之处权重被放大 |
| 账房写"灌了三分"与"少了七分" | 框架效应：同一客观量的表述改变 |
| 何满仓册子第三行空着 | 参照点下移导致损失不可承受；现状偏差 |
| 墙上那句"从哪一笔往下数" | 参照点依赖的一句话总结 |

---

## 一句话总结

> 人不是按绝对结果算账的，而是按"相对哪个数、亏了还是赚了、那个概率有多真"三件事来算——这就是 **前景理论（Prospect Theory）**。

## 记忆口诀

- 口诀 1：**先找参照点**，一切评价从"跟谁比"开始。
- 口诀 2：**亏比赚痛**，痛约两倍，所以"不亏"常常比"多赚"更值钱。
- 口诀 3：**赚要递进，亏要加速**——价值函数是个歪S。
- 口诀 4：**小概率放大，中概率缩水**——概率不是原样算的。
- 口诀 5：**框架一改，感受全改**——同一数字换个说法就换一个决策。
