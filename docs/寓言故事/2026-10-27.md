# 2026-10-27 寓言故事 · 磨坊主的三个儿子

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

石桥河上游的磨坊还在转。磨坊主死了，留下三个儿子、一本账簿、三把钥匙，还有半仓麦子。

老大、老二、老三，按当地规矩，同时继承了磨坊。

三天之后，三兄弟在磨坊门口的石碑前碰面。碑上刻着老磨坊主留下的一行字：

> **"磨坊只有一架。麦子是同一仓。分的时候，先把账算清。"**

老大说："这有什么难的？把账簿拿来，我一个人算。"

老二说："凭什么你算？我也算。算出来不一样怎么办？"

老三什么也没说，转身回屋拿了把椅子，坐在门口。

老大和老二在屋里翻账簿。账簿很厚，入了三十年的账，字迹有老磨坊主的、有他儿子的、还有一个记工的。翻到第三页，两人发现同一笔麦子被记了两次：一次是"入仓"，一次是"出仓"，但两次的数量对不上。往下翻，类似的记法有几十处。

"你看，还是得请人来算。"老大说。

两人吵到日头偏西，账簿摊在石桌上，谁也没算完。

老三一直在门口坐着。

老二终于忍不住："三弟，你倒是说句话啊。"

老三站起来，走到石桌边，把账簿合上，然后说了一句话：

"你们算的是'这一仓麦子够不够分'。这个问题的答案，跟你们俩谁算的没关系。"

"那算什么？"老二不服气。

"算'**分的时候，谁先动手，谁就少担一份风险，但少得也少**'。"

老大老二都不说话了。

老三接着说："爹留下三把钥匙，不是因为他偏心，是因为他知道**分麦子这件事，只有一个办法能不出错**。"

"什么办法？"

"**先立规矩，再动麦子。**"

老三从怀里掏出一张纸，是他自己写的。他念给两个哥哥听：

"第一条：这一仓麦子，三家先各取三成，剩下的一成按当年记账的份数分。这一成怎么算？按'记账时写了多少、且经三个人都认的'来算。"

"第二条：谁对账目有异议，**不许自己改账**，必须把三家一起喊来，当着面核。核完的结果，三家都认，才算数。"

"第三条：分完了，如果发现账算错了，**从下一年这一成里扣**，不回头翻旧账。"

"第四条：明年不管收成多少，这三条都不改。要改，三家一起改。"

老大老二听完，老大先开口："第二条和第三条，爹活着的时候都没这么严过。"

"爹活着的时候不需要。"老三说，"爹一个人说了算，他说了算就是规矩。现在三个人了，**规矩必须写在纸上，因为纸不会偏心**。"

老二问："那这第四条有啥用？年年不改？"

"年年不改才叫规矩。"老三说，"**每年都能改的规矩，等于没有规矩——因为谁强势谁改。**"

石头上的三兄弟分完那一成麦子，用了整整七天。核账的时候，兄弟之间有过三次争吵，有两次差点动手。但没有人改账本。

第二年，麦子少收了两成。三兄弟按老规矩分：先各取三成，剩下的一成照旧按认过的记账份数分。那年三家都没说话。

第三年，麦子丰收，多了半仓。三兄弟又先各取三成，剩下的一成——

老二突然说："等等。爹的账本上，今年的入仓比去年多了四成。"

"那说明今年该多分了？"老大说。

"不是。"老三把账本翻到最后，"爹的账本最后一句写的是'分法照旧'。**账上多出来的那部分，不是分的东西，是记着的东西。记着的和分着的，不是一回事。**"

老大看着弟弟。

老三说："我昨晚想了一夜。**多出来的麦子，是要用来补去年亏的空口的。** 去年三家都按老规矩拿的，可去年没吃够。爹那本账记得不是'今年该分多少'，记的是'**账要平**'。"

"怎么平？"

"缺口先补。多出来的部分，先把去年三家都没吃饱的那个缺口补上，补完还有剩，才按老规矩分。"

老二张了张嘴，没反驳。因为他也记得，去年冬天他家的麦子磨得比另外两家薄。

三个兄弟又核了五天账，最后的方案写成了三条，刻在石碑背面，挨着老磨坊主的那行字。

此后二十年，石桥河的麦子有收有歉，磨坊的账从来没乱过。三家也没红过脸。

很多年以后，有人问老三："你们三个分个麦子，用了七天，还立了四条规矩，值得吗？"

老三说了一句被三村人记了很多年的话：

> "**分东西的时候，最容易出的错不是算错了，是'谁说了算'说不清。**"
>
> "**账是可以错的，规矩不能歪。账错了还能改，规矩歪了，就永远在争。**"
>
> "**你们要是只记住一条——记住那个'三成先取、剩下按认过的账分、错的下一年扣、改要三家一起改'的法子。**"
>
> "**这法子不是我定的，是它自己长出来的。天地间只要有四样东西凑齐了——**东西只有一份**、**三家分**、**账要当面对**、**往年不能白算**，**这样一套分法就一定在那儿等着你们。**"
>
> "**凑不齐呢？那就吵到来年。**"

## 这个故事在讲什么

### 概念

**核心概念：Shapley 值（沙普利值）与合作博弈的分配方案**

三个兄弟分一仓麦子，兄弟间是**联盟博弈（coalitional game）**，特征恰恰是：**合作（合作才有利可分）＋结盟（不同联盟能分到不同）+ 不可转让（麦子一旦分完就不能转给别人）**。

**Shapley 值**正是这种博弈的标准解法。定义：

$$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(n-|S|-1)!}{n!} \left[ v(S \cup \{i\}) - v(S) \right]$$

即：玩家 i 的分配 = 遍历所有"其他玩家的加入顺序"，按每种顺序等概率下，**i 在那个顺序中"最后进入"所增加的那部分价值**的期望。

**故事里的映射**：三兄弟是三个玩家，三种麦子分配格局是三个联盟组合的价值函数 v(S)。老三定的"先各取三成、剩下的一成按认过的记账份数分"，正是在构造一个 v，使得 Shapley 值恰好等于各方应得。

### 为什么这个概念重要

**1. Shapley 值是唯一满足四条公理的分配方案。**

这个"唯一性"是 Shapley 定理的核心结论，它靠四条公理锁定：

| 公理 | 内容 | 故事对应 |
|---|---|---|
| **对称性（Symmetry）** | 若两玩家在所有联盟中的边际贡献相同，则分配相同 | 两个哥哥若贡献完全一样，所得必须一样 |
| **有效性（Efficiency）** | 全体分配之和 = 总价值 v(N) | 三家之和 = 一仓麦子，不能多也不能少 |
| **虚拟玩家（Dummy）** | 若某玩家对任何联盟都无边际贡献，则分配为 0 | 白吃不动手的那家分不到 |
| **可加性（Additivity）** | 两人游戏的 Shapley 值之和 = 合并游戏的 Shapley 值 | 减法与加法可以分开算 |

**2. 它解决的问题，正是"分麦子"式的现实困境。**

在现实中，这个结构极其常见：

- **中央与地方的事权与支出划分**
- **多部门联合治理的成本分摊**
- **联盟成员的贡献分配（论文作者、专利发明人、基金项目参与者）**
- **多主体联合投资项目的收益分配**
- **供应链中的成本分担谈判**

每一项里，问题的核心都不是"总量多少"，而是"**这个增量到底该归谁**"。

**3. 故事里"当面对账、不许自己改账"这条规矩，恰好是 Shapley 值可计算的前提。**

Shapley 值依赖于 v(S) 对**所有子集**的度量。如果联盟价值只能靠事后争议、靠强势方说了算，那测出来的 v 就不真，Shapley 值也就失去意义。**"核账"不是形式主义，它是价值函数可测量的前提条件。** 这也解释了为什么老三坚持第四条"要改三家一起改"——**规则的可预期性，是分配可计算性的基础。**

### 陷阱一：把"按付出多少分"当作 Shapley 值

**错。** Shapley 值不看你"做了多少"，看的是**边际贡献**——"你在场时多出来的那部分价值"。

关键差异在于**顺序**。若甲在联盟里做的活是乙做不了的（乙来不了，甲不来则整个项目做不成），那甲的边际贡献远大于他干的活数。反之，若乙的活甲也能干，那乙在"甲已在场"的联盟里边际贡献为零。

**故事中**：如果老三不来，两个哥哥永远核不完账（v({老大,老二}) < v(全部) 的差距就是老三的价值），那即便老三一分麦子没搬，他的分配也高。**这是 Shapley 值最反直觉也最正确的地方：贡献不是劳动量，是不可替代的增量。**

### 陷阱二：认为"平均分"或"按人头分"也是公平的

**错，而且违反有效性之外的三条公理。**

- **按人头平均分**违反**对称性**：若三人贡献完全相同还行，一旦贡献不同就分配错误。
- **按工作量和分**违反**虚拟玩家公理**：一个纯粹搭便车的人也能分到。
- 更根本的是，二者都**没有回答"边际贡献"这个真问题**，而是回避了它。

**"平均分"是最省事的分配方式，也是最不公平的分配方式**——因为它默认了"每个人的不可替代性相同"这个几乎总是错误的前提。

### 陷阱三：忽视"顺序"本身会改变分配结果

**这是 Shapley 值最容易被误解的地方。**

如果指定一个固定顺序（老大先来、老二再来、老三最后），按"最后进入者拿增量"分配，结果会**强烈依赖这个顺序**：最后进来的人会拿走几乎所有增量。**这正是老大老二最初各自算账、算出完全不同的结果的原因。**

Shapley 值的做法是：**把所有顺序等概率看待**。当一个玩家无论以什么顺序进入，贡献都相同时，顺序就无所谓了；而当顺序有影响时，用所有顺序的平均把它"洗平"。

**这就是"当面对核、不能自己改账"的数学意义**：它把"谁先谁后"的随意性，转为"所有顺序的平均"这一确定的、可复算的量。

### 陷阱四：以为 Shapley 值等于"最后进入者拿走增量"

**错。** 那只是**任意固定顺序下**的一种特例。Shapley 值是**所有顺序的平均**。

这个区别很实际：在固定顺序下，如果老大无论如何都第一个进，他最后的边际贡献可能远大于实际应得；而如果老三在某些顺序里排中间，他的贡献会被"漏掉"。**Shapley 值消除的正是这种"位置决定分配"的不公平。**

### 陷阱五：以为 Shapley 值一定能算出来

**错，而且这是最实际的工程约束。**

公式要对**所有 2ⁿ−2 个子集**求 v(S)。n 个玩家时，v 的测量次数是指数级的：

- 3 个玩家 → 6 个子集（可行）
- 10 个玩家 → 1022 个子集（勉强）
- 30 个玩家 → 10 亿个（**不可能**）

所以工程上有三条现实路径：

1. **限制联盟范围**（coalition structure）：把玩家分组，组内算、组间再算
2. **只测部分子集**：用抽样或启发式近似，牺牲精度换可行
3. **分解为小问题**：若 v 可分解为若干独立部分，Shapley 值也可分解

**故事里"三成先取"这一条，其实就是一次分组（把整体拆成三成 + 一成两部分计算），是极其朴素的分解技巧。**

### N 层用途

1. **经济学与公共财政**：地方事权划分、转移支付公式设计、跨区域成本分摊（Atkinson–Stiglitz 的最优税收理论直接用到 Shapley 值）
2. **机制设计**：拍卖与分配机制的核心工具（Groves 机制、VCG 机制都以 Shapley 值构造）；Shapley 值公理化之后，**"公平的分配"第一次有了唯一的数学定义**
3. **合作博弈论**：核仁（Nucleolus）、Shapley 值、Scrap 值构成"合作博弈解"三支柱；**公平性从道德判断变成了公理推导**
4. **算法与复杂度**：#P 难——精确计算 n 人联盟的 Shapley 值是 #P 完全问题，因为测量 v(S) 本身就是组合爆炸；**这催生了近似算法（点赞采样、蒙特卡洛、Ollmann）**
5. **人工智能与多智能体**：多智能体系统中奖励分配、信用分配（credit assignment）的理论基础
6. **软件工程与开源治理**：贡献度度量、代码所有权分配、贡献者声誉系统（如 Contributor Covenant 的争议解决机制）
7. **法律与司法**：破产清算中的债权分配、连带责任的内部追偿比例确定
8. **组织管理**：跨部门项目的成本与收益分摊、绩效奖金池分配

### 故事里的对应关系

| 故事元素 | 学术对应 |
|---|---|
| 三兄弟分一仓麦子 | 合作博弈 n=3，联盟博弈 |
| 一份麦子、三个兄弟 | 不可转让性（麦子不能转卖转移） |
| 合作才有利可分 | 合作性（超可加性，v(N) > 各部分之和） |
| 三家结盟能多拿 | 结盟性（superadditive） |
| 核账时记录"三家都认的"份数 | 价值函数 v(S) 的可测量性前提 |
| "谁先动谁少担一份风险，但少得也少" | 边际贡献 = 加入前后的价值差 |
| 老三不搬麦子但分得多 | 不可替代的边际贡献 > 劳动量 |
| "不许自己改账，必须三家当面对核" | 价值函数不能被单方操纵 |
| "错的下一年扣，不回头翻旧账" | 可加性/前瞻性结算，避免追溯性博弈 |
| "改要三家一起改" | 规则稳定性与可预期性 |
| "缺口先补" | 价值函数包含历史状态（存量非独立） |
| "记着的不等于分着的" | v(S) 的度量口径必须显式声明 |
| "凑不齐四样东西就吵到来年" | Shapley 定理的四条公理前提 |

## 一句话总结

> 分东西之所以吵，不是因为算不清，而是因为"谁说了算"没写下来；而真正的公平，是把每一个"多出来的那部分"归给那个**无论以什么顺序进入、都在场、就不可替代**的人。

## 记忆口诀

- 口诀 1：**四公理定唯一**——对称、有效、虚拟、可加。四条齐了，分法只有一种。
- 口诀 2：**Shapley 看边际**——不是你干了多少，是你"在"与"不在"的差额。
- 口诀 3：**顺序要平均**——固定顺序会分崩，所有顺序取平均才叫 Shapley。
- 口诀 4：**平均分最省也最贵**——省事的是它，赔的是不可替代者的信任。
- 口诀 5：**可加可拆**——大难题拆成小组算，这就是"先取三成"的技巧。
- 口诀 6：**核账是前提**——v(S) 测不准，Shapley 值再漂亮也是空中楼阁。
- 口诀 7：**2ⁿ 是硬墙**——n 人大联盟指数爆炸，只能分组、抽样或近似。
- 口诀 8：**正面例子更好记**——Shapley 值是诺奖级成果，2020 年 Lloyd Shapley 因其在博弈论中的贡献获诺贝尔经济学奖；John Harsanyi 1964 年获诺奖（合作博弈的核与解）。
