# 2026-11-18 寓言故事 · 独木桥关的捆法

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

盐场在县城东边四十里，中间隔着一道关。

关是一座独木桥，桥身只有一抱宽，一次过一个人。关口的木牌上刻着三条规矩：过桥一趟；一趟只准带三样东西；桥那头有人验货，货到了才算数。

盐工们起初的日子是这么过的。一户人家有米袋、酱罐、蓑衣、油灯、锄头、绳索、账本、水囊……十几样。桥一次只准带三样，那就得十几趟。有个叫老崔的盐工过一趟歇三天，一年到头有一半工夫耗在桥两头转悠。

县里的税吏看不下去，第二年改了一条规矩：一趟最多带三捆。

大伙儿立刻照做。米袋和酱罐捆一捆，蓑衣和油灯捆一捆，锄头绳索账本捆一捆，三趟就过完了。税吏说这回省事。可开春就出事：蓑衣一浸了油，灯点不着；桥板一颠，账本散页飞进河里，捞都捞不回来。

第三年出了个奇人。老脚夫陈跛子过桥，褡裢瘪的，什么都不带。税吏跟了一趟，想看他如何在桥上变戏法。陈跛子走到桥头停住，眼睛半闭，嘴唇动了两下："左脚先探。到第三根木桩蹲下。过了桥头往右数七步。"说完人就上去了，脚不停。到了对岸，他再念一遍口诀，又走回去。盐场的人跟着他学，也空着手去，盐照样到了。

县里一位教书先生听说了，跑到桥边记下那两句口诀，回来编成《过桥三十六法》，教给蒙童。

蒙童背得很流利，问一句答一句。可真把他们赶上桥，一半人钉在桥头不动：一边嘴里念着下一句，一边眼睛盯着脚下，生怕踩错。有个孩子在桥心卡住，后头的孩子一涌，人差点挤下去。先生急了，改了法子：口诀砍成三句，写在桥头木牌上，每人抬眼看一下再走。木牌上写了三十多个字，挤得密密麻麻。学生们照样走不动——他们一半在看字，一半在看脚。

先生站在岸上想不通：路就那么一条，木牌都立在路当中了，怎么还是走不动？

他转身去问陈跛子。陈跛子听完，伸出两根手指并拢，朝桥的方向一比："东西多。你把它捆成一捆，它就只算一样。"

先生愣住了："那三十六法呢？"

"那是给认不得路的人念的，"陈跛子说，"我不念。走熟了，路自己会走。"

先生回去把《过桥三十六法》锁进箱里，改教一件事：怎么捆。蒙童背口诀的时辰少了，桥上的拥堵却没了。可也留下个新问题——有个学生出桥之后照样不会捆，回了家问先生米袋和酱罐能不能捆一堆，他答不上来，只会背那三句口诀。

第五年，关吏动了恻隐之心，把木牌上"三样"那一行字刮了。

盐工们欢天喜地扛着十几样东西上桥。走到桥心，有人怀里抱着东西忘了脚下，一脚踩空，护栏朽了，人和货一齐落水。关吏又在木牌上把那行字重刻了一遍，字比原先还深。

刻字那天，先生就站在旁边。他这才明白那行字为什么刮不掉：不是东西太重，是一个人脑子里同时能端住的东西，本就这么点。捆得再少，也还有三捆；念得再熟，也占着地方。

## 这个故事在讲什么

**概念：认知负荷理论（Cognitive Load Theory, CLT）。**

一句话：学习不是"往脑子里塞多少东西"的问题，而是"同一时刻脑子里能同时摊开多少东西"的问题；教学、说明书、界面设计的功夫，不在加料，在减负和重新打包。

工作记忆（working memory）是此刻正在用的那块小台面，容量极小；长时记忆是仓库，容量近乎无限。Sweller 在 1988 年提出的核心主张是：**新信息的学习速度与质量，由工作记忆里同时被激活的信息单元数量决定，而不取决于内容量本身。** 学习者每秒钟都在干三件事：处理新信息（消耗工作记忆）、把新信息和旧知识挂钩（消耗工作记忆）、把挂钩后的结构存进长时记忆（不消耗工作记忆）。所谓"认知负荷"，指的就是工作记忆里此刻同时摊开着多少东西。

三个词要分清：

- **内在负荷（intrinsic load）**：材料本身的元素交互性（element interactivity）决定的、不可消除的部分。十件事互相独立，内在负荷就低；十件事互相纠缠（比如"同时考虑风向、湿度、步幅、手里的货重"），内在负荷就高。
- **外在负荷（extraneous load）**：设计不好带来的额外浪费。表格里画线之外还要加满解释、图上标的字母和文字说明讲的是同一件事，都是外在负荷。
- **有效负荷（germane load）**：用在建构图式上的那部分。早期 CLT 把三者并列，后来（Sweller & Sweller, 2023）主张把 germane 重新定位为"内在负荷的加工方式"，不再单列——但"学习必须占用工作记忆"这个前提没变。

**图式（schema）**是关键中介：把十几个元素打包成"一个"单元。元素交互性高时，新手看到的是十几个乱糟糟的要素；专家看到的是一个整体（Gick & Holyoak 的"好手看整体，菜鸟看成分"）。专家的工作记忆并没有变大，变的是打包能力——他的仓库里有现成的结构可以直接调用。

**边界辨析：**

- 与"工作记忆容量有限"（Miller 1956、Cowan 2001）：不是对立关系，是同一支派的源头。CLT 多了"如何设计"这一层——容量限制是生理事实，CLT 是可操作的设计原则。
- 与"认知吝啬者"（mindlessness，Bargh 的脚本理论）：一个讲注意不省、一个讲设计要省，不是同一件事。
- 与"双系统加工"（系统一/系统二）：一个讲加工系统的划分，一个讲负荷的来源与分配，不能互相替代。
- 与"认知负荷"在教育技术里的泛用说法：只有 Sweller 这条线才承诺"负荷类型→设计规则→可测效果"这套闭环。
- 与 ADDIE、SAMR 之类的教学设计流程模型：那是流程，不是机制。

**落地例子：**

1. **新员工入职培训**：先教"这台机器五个按钮各自干什么"，还是先教"开机到出活的一套流程"？前者元素独立、后者元素纠缠。讲流程时，"每个按钮"就是内在负荷本身；此时再逐个解释按钮，等于把内在负荷翻倍。
2. **药品说明书**：把"每次两片"和"每日三次"分开写在两个角落，就是把交互元素拆开；写在同一行"每次两片每日三次"就是把六个元素绑成一串让人自己解。
3. **开车导航**："前方 300 米右转，进入 XX 路"一句话是一个已打包的整体；换成"车距地面 3 米时应提前 0.7 秒抬起踏板"是几十个交互要素——新手听第一条，老手听第二条。给老手讲新手指令，就是纯浪费。
4. **乐谱与棋谱**：背谱不是记住一百万个音符，是记住二十种手型；手型是图式，音符是挂上去的。
5. **医生查房**：主任医师听一句话就调药（已打包），实习医生要把二十条指征逐条比对（未打包，负荷全压在当下）。

### 陷阱一：把认知负荷读成"学生笨"或者"内容太多"

负荷不是智商，不是记忆容量的绝对数值，也不是知识总量的多少。同样的十字路口口诀，走熟的人和生人负担差十倍，因为一个有图式一个没有。骂学生记性差是找错了地方。

### 陷阱二：以为讲得越多、图越多、标注越细越好

这是 CLT 最反直觉、也最赚钱的一条：冗余会杀学习。一张已经自解释的图旁边再写一段逐字解说，受教者得同时听、看、核对两份信息（split attention），工作记忆直接翻倍。**能用一张图说清的，就删掉那句说明；能让新手用的，就别同时给专家级的全量视图。**

### 陷阱三：以为"负荷越低越好"

低外在负荷不等于低负荷，更不等于学得会。表面流畅的讲义可能什么都教不会——CLT 明确指出，**适度困难（desirable difficulties）是必要的**：问题要保留一定难度，让学习者真的去推理、去检索、去构造图式。CLT 反对的是"浪费性的负荷"，不是"负荷"本身。

### 陷阱四：把"讲过了"当成"学会了"

CLT 解释了一类长期被误判的现象：学生能把操作步骤倒背如流，一上手就废。因为背诵时用的是"外显描述"的浅加工，负荷很低、体验很顺；但真正操作需要把描述和情境挂钩，而这一步从未被训练。**流畅感不等于学习**（fluency illusion）。

### 认知负荷理论的 4 层用途

1. **诊断层**：把"学不会"翻译成可操作的问题——是内在负荷太高（材料太纠缠），还是外在负荷太高（设计太吵），还是 germane 根本没发生（学完没挂钩）。三种病因三种药方。
2. **设计层**：给出一批有实验支持的设计规则——分段（segmenting）、标注（signaling）、去冗余（redundancy）、例题先行再渐隐（worked example → completion → problem）、预训练（pre-training）、隔离效应（isolated elements）、走查（self-explanation）。这是 CLT 最能落地的部分。
3. **评估层**：怎么知道负荷高不高？双任务范式（同时做第二任务看主任务变慢多少）、主观努力量表（NASA-TLX 一类）、错误类型分析（是"步骤漏了"还是"搞错了关系"）。
4. **迁移层**：解释"为什么学会了却用不出来"——情境依赖的迁移失败与元素交互性有关：当新材料与旧材料交互性更高（新手变专家的那个瞬间），旧图式接不住，需要重新教学而不是加练。

## 故事里的隐喻，对应着什么

| 故事元素 | 学术对应 |
|---|---|
| 独木桥，一次过一个人 | 工作记忆，一次只处理一件事 |
| 木牌上"一趟只准带三样" | 工作记忆容量上限（Cowan 约 4±1 个组块） |
| 十几样东西要分十几趟 | 无分组的原始处理，元素各自独立占用工作记忆 |
| 税吏改规矩"最多带三捆" | 分组（chunking）：把多元素打包成一个单元 |
| 米袋酱罐捆一捆、蓑衣油灯捆一捆 | 打包降低单元数，但引入新的元素交互性 |
| 蓑衣浸油灯点不着 | 交互性带来的迁移副作用：合并不当会互相干扰 |
| 陈跛子空着手过桥 | 专家图式自动化：过程已内化，不再占用工作记忆 |
| "左脚先探／第三根木桩蹲下／往右数七步" | 已封装的程序性图式，可整体调用 |
| 《过桥三十六法》倒背如流 | 语义记忆里的陈述性知识，不等于可执行程序 |
| 桥上一半人钉住不动 | 工作记忆被"念口诀 + 看脚"双任务占满 |
| 桥头木牌写三十多个字 | 外在负荷：文字/图形冗余、注意力被分割 |
| 学生一半看字一半看脚 | 分心（split attention）造成的外在负荷 |
| 先生改教"怎么捆" | 教学重心从"陈述"转到"结构化打包" |
| 出桥后仍不会捆的学生 | 流程性知识未与元素交互性匹配：能背不能迁移 |
| 盐工十几年过桥太慢 | 缺乏分组的纯流式处理 |
| 关吏刮掉"三样"那行字 | 撤除人为约束→外行负荷 |
| 一脚踩空、人货落水 | 负荷超限的事故表现：不是不努力，是同时端的东西太多 |
| 重新深深刻上那行字 | 承认容量上限，把约束显性化 |
| "不是东西太重，是脑子里同时能端住的东西本就这么点" | CLT 的核心命题 |
| 陈跛子的两句口诀 | 高度压缩的 chunk：多步映射到一个可调用的单元 |

## 一句话总结

> 学习不是往脑子里塞多少东西，而是同一时刻脑子里能同时摊开多少东西——所以功夫全在减负与重新打包。

这就是认知负荷理论。

---

## 记忆口诀

- 口诀 1：**先分组，再讲全**——单元数比内容量更要命，捆得越少越省心。
- 口诀 2：**图能说清的，删掉那句说明**——冗余即外在负荷，一图配一段字等于双倍扣分。
- 口诀 3：**讲给生手，别拿专家的全量视图压人**——新手要的是流程，专家要的是例外。
- 口诀 4：**倒背如流不等于会做**——流畅感是学习的错觉，握手般的手感才叫学会。
- 口诀 5：**难一点才对**——适度困难是必要的，杀学习的从来不是难度，是浪费。
