# 2026-10-28 寓言故事 · 报事楼的余数

> 每天一个研究生水平概念，借一个故事让它在心里生根。

---

## 故事

雾岭上有座报事楼。

镇上的规矩很怪：凡事未发生，报事楼先说。哪家柴房今夜走水，哪条山路会塌方，谁家孩子夜里咳了几声——全都说在前头。镇民照着楼里的话行事：说明日井水浑，大家便提前两日淘井；说东街米价要涨，各家便把米囤起来。

报事楼共三层，每层一位先生。

最底层的溪边先生看得见井水浑不浑；中层的桥头先生听得见各家咳嗽；最高层的雾岭先生从不下楼，只按下头递上来的"细报"发话。

每层的工作只有两件：先猜，再对照。

溪边先生听见井底有响动，猜是水泵坏了；不多时桶绳"啪"地断了。溪边先生立刻把"响动"与"断了"之间的差额报上去。桥头先生记下这个差额再往上递。雾岭先生收到一叠差额，把它们凑成一句"近半月水管皆老"。

镇上人管这个差额叫"余数"。

余数是楼的粮食。规矩是：**余数越大，下回猜得越准**。溪边先生头一回猜错，罚俸半年；猜准了，三年不用再猜。所以每个人都盼着听见真消息，也盼着自己的余数被采信。

楼里另有一杆"信秤"。

不是所有余数一样重。桥头先生偶尔会听错，会咳嗽，会打盹，他的余数在信秤上压得轻；溪边先生趴在井边，误差小，他的余数就压得重。**压得重的余数能改写压得轻的余数**——这是楼里最要紧的一条。

有一年，镇上来了个货郎，推销一种"听话的假手"。说戴上睡觉能代替真手挠痒，还省药钱。一个游方书生买了一只，夜里睡着，痒醒了，抬手去挠。

怪的是，他挠的方向偏了。

他明明觉得手在左半边，抬起来却挠到了右半边桌沿。书生说，雾岭先生一定出了错，替他把"左手的位置"安到了右边。

没人说破。只有卖假手的老贾在角落嘟囔了一句："楼里的先生们说了假话，假手可不说话。"

书生连着几夜做同一个梦。梦里他站在报事楼三层，每层都站满了人，人人举着一张纸，纸上写着明天会发生什么。他一张一张看过去，全是空的。他想喊，喊不出声。楼里静得他听见每一张空纸落地。

醒来时，手里真攥着一张纸，上面也是空的。

第二天他找到老贾，问假手到底做了什么。老贾说："没做什么。就是它一贴上，你身上那位'知道手在哪儿'——不是楼里的先生，是你自个儿身体里的那位——就分不清真假了。你身上那位最信自己的手。"

书生把这句话记在册子上，圈了三遍。

直到有一年冬天，溪边先生病死了。按规矩，溪边这一层得有人守着井。

那半个月，报事楼空着一层。

溪边没有消息递上去，二层的桥头先生只能靠往年的老账去猜；三层的雾岭先生靠桥头的猜的猜。镇上人照旧按楼里的话过日子：今日说井水浑，大家照旧淘井；后日说东街米价涨，大家照旧囤米。

半个月后，一桩谁也没料到的事发生了：镇东粮价真的涨了，涨得比谁猜的还狠。

而那些囤米的镇民，一半没熬过那个春天。

事后追责，楼里的人把账算到死人头上。可雾岭先生临终前留了一行字，写在册子最后一页：

**"余数不是余下的数，是差额本身。楼上没有下头送上来的差额，猜就只是猜。猜着猜着，猜会长出腿来，自己去看，自己去认。"**

没人懂这句。

后来镇上的年轻人把它抄在学堂的黑板角落，一代一代抄下去。


## 这个故事在讲什么

### 概念

**预测编码（Predictive Coding, PC）**：大脑不是被动接收感觉信号再拼出世界，而是**持续地自上而下生成对感觉输入的预测**，再把真实输入和预测之间的**差**（预测误差，prediction error）往上送。预测误差就是学习信号：网络用它去修改那些导致误差的连接。

完整机制有两半，缺一不可：

1. **误差驱动（error-driven）的学习规则**：只有产生误差的连接会被加强或减弱，等价于"哪里跌倒哪里改"。这与赫布学习（Hebbian learning）的"一起放电的连在一起"不同——赫heb 学不需要差值信号，预测编码需要。
2. **精度（precision, π）加权**：每条误差通路有一个独立的精度参数，决定这条误差往上送时占多大比重。精度相当于"这条信息有多可信"，它比"信号有多强"更本质。

关键的**层间回路**是：高层对低层做预测（自上而下），低层把预测误差往上传（自下而上），高层的表征被误差修正。用统计语言说，大脑是个**分层生成模型**，采用变分推断（variational inference）近似：用先验项（自上而下的预测）去约束从感觉输入中提取的隐状态（自下而上的误差），使推断既忠于数据又不违背先验。

**理论地位**：这是**自由能原理（Free Energy Principle, FEP）**在脑科学里的实现形式，也是**有效计算（effective computation）**和**预测加工（predictive processing）**学派的共同框架，被视为统一知觉、注意、记忆、意识的候选理论。

### 与近邻概念的边界

**与"自上而下加工"的边界**：经典的自上而下加工只指"先有概念再看"，是个局部现象；预测编码是整个知觉组织原则——知觉本身就是"用预测去解释信号"的过程，不存在一个"先裸看世界再套概念"的独立阶段。

**与贝叶斯感知（Bayesian perception）的边界**：预测编码常被描述为"近似的贝叶斯推断在神经元上的实现"。区别在于：贝叶斯感知是**计算层面的最优性主张**，不指定怎么实现；预测编码是**机制层面的具体算法**——指定了前馈/反馈连接、误差单元、以及胡伯与迈尔斯的自由能框架。

**与注意（attention）的边界**：在预测编码里，注意不是"聚光灯照某个地方"，而是**改变精度参数**：给某条误差通路加精度 = 提升它在下一次推断中的权重。注意力成了精度加权的一个特例。

**与误差学习（error learning, Rescorla-Wagner）的边界**：Rescorla-Wagner 是单层联结规则，只解释"预测误差怎么改权重"；预测编码额外提供了**层间结构**——多个抽象层级各自做预测和误差传递，这是解释"为什么我们能看见整棵树而不是一堆叶子"的关键。

### 四个生活化的落点

1. **你还没进家门就掏钥匙**：大脑在推门之前就已经预测了"锁孔形状、转动角度、钥匙手感"，插进去的那一刻误差几乎为零，你甚至没意识到自己做了什么。这就是预测编码最日常的证据。
2. **嘈杂酒馆里只听见自己的名字**：不是你的耳朵变灵了，而是"从背景里挑出与自身模型相关的信息"这条通路的精度被临时调高了。叫你名字的是信号本身，**注意是你调了信秤**。
3. **安慰剂与预期**：期待"药有效"会真实改变症状。因为"药会让我好"是一个高层预测，它向低层下发预期；症状与预期不符的部分就是误差，误差驱动系统去改变症状。预测编码是安慰剂效应最简洁的机制解释之一。
4. **新生儿看世界**：婴儿的视觉皮层已经具备"有边缘、有光斑、有缓慢运动"的先验，只是权重是软的。视觉体验就是这些软先验被误差一点点校准的过程。
5. **冥想与"无我"**：某些冥想流派的核心操作，是主动降低"自我模型"的精度——把关于"我此刻在想什么"的误差通路调弱，主观上就出现"念头还在，但好像不是我在想"。

### 陷阱一：把预测当成"想出来"

最常见的误解是以为预测编码只是"经验主义"的通俗版——认为大脑只是把过去的经验往上一套。

实际上预测编码强调的是**主动推断**：大脑不只被动接收，还在**主动采样**（active inference）环境——伸手动一动、眼睛扫一下，让世界为自己提供误差。婴儿不会只躺着看，他会伸手、抓、蹬，因为只有自己动才能造出误差。这条"谁制造了误差"的线索，很多入门文章完全不提。

### 陷阱二：以为"误差越小越好"

错。误差是系统的**燃料**，不是故障。

完全消灭误差意味着完全不再接收输入——那是脑死亡的状态。真正的健康态是**误差恒常**：系统维持一个适度的、可控的预测错误水平。精神分裂症的核心特征之一，正是预测精度调节失常：要么把无关刺激的误差通路过度放大（满脑子都是"信号"），要么把真实刺激的误差过度压制（以为自己在控制，实则是大脑的内部生成）。**异常的，不是误差的多少，而是精度的分配。**

### 陷阱三：把所有"脑解释"都套成预测编码

预测编码不是万能钥匙。它目前主要在知觉与注意上有强证据；把它直接套到情绪、社会认知、语言语义上，证据强度差异很大。见到一篇论文说"这是预测编码的神经基础"，先问三件事：**误差信号在哪测到的？精度参数有独立证据吗？还是只是把已有结果重新叙述了一遍？**

### 预测编码的 N 层用途

1. **知觉的构造**：视觉不是像素拼接，是"生成模型 + 误差"的循环推断；错觉（错觉直线、赫尔姆霍姆方块）正是先验压过数据的地方。
2. **注意即精度调节**：从 Posner 线索实验到 Transformer 的注意力，形式上都在做"给一部分信息加权"。
3. **精神疾病的机制假说**：精神分裂症（自上而下预测过强）、抑郁症（自下而上误差过强）、自闭症（弱先验的窄化）——这些都不是"某区域坏了"，而是精度分配出了问题。
4. **机器学习中的对应**：预测编码与变分推断、预测误差梯度下降是同一件事的不同表述；它也是"预测式编码 vs. 描述式编码"之争的落点。
5. **机器人与具身智能**：预测式机器人不是等数据来拟合世界模型，而是不断预测"动一下会发生什么"并用误差修正；这也是探索与主动学习（active learning）的神经科学对应物。
6. **听觉与语音**：内稳态理论（grossberg）早就提出听觉系统是"预测 + 误差"的分层回路；音高、辅音识别都依赖预期。
7. **意识理论**：全局工作空间与高阶理论都可被重述为"哪一层的内容被高精度地广播给了高层"。这仍是开放问题。

## 故事里的隐喻，对应着什么

| 故事元素 | 学术对应 |
|---|---|
| 报事楼三层 | 分层（hierarchical）预测系统，高抽象到低抽象逐级排列 |
| 每层一位先生 | 每一层的预测器，生成对下层输入的预测 |
| 先猜，再对照 | 自上而下的预测 + 自下而上的误差 |
| 溪边先生猜"水泵坏了" | 低层感觉与内感受预测 |
| 响动与断了之间的差额 | 预测误差（prediction error） |
| "余数" | 误差信号本身，楼里的全部信息货币 |
| 余数越大，下回猜得越准 | 误差驱动的权重更新，也就是学习 |
| 猜错罚俸，猜准免猜 | 误差反过来修改预测器参数 |
| 雾岭先生把一叠差额凑成一句话 | 高层对低层误差的抽象与整合 |
| 雾岭先生往下发话 | 高层预测向下调制低层知觉 |
| 信秤 | 精度（precision），误差通路的信噪倒数 |
| 压得重的余数能改写压得轻的余数 | 高精度误差通路主导推断结果 |
| 雾岭先生不出门，靠余数说话 | 层级化表征，纯由误差驱动自上而下生成 |
| 假手上的"挠到右边" | 本体感觉预测被外部装置污染 |
| 老贾："楼里的先生们说了假话，假手可不说话" | 身体自己的预测系统不被外部装置替换 |
| 满楼举着空纸 | 预测与输入脱钩，只有预测没有误差 |
| 书生手里真攥着空纸 | 自上而下生成的内部模型压过了外部输入 |
| 溪边先生病死，二三层空转 | 缺少最底层的误差输入，预测退化为凭记忆瞎猜 |
| 半月后粮价真涨 | 靠上层的先验撞对了，但没有误差校准过 |
| 囤米镇民饿死 | 先验驱动的行为没有及时被真实误差修正 |
| 雾岭先生遗言"余数是差额本身" | 误差不是残差，是系统赖以生存的信息 |
| "猜会长出腿来，自己去看" | 主动推断：主体主动采样以产生误差 |

## 一句话总结

> 大脑不是一台被动接收信号的照相机，而是层层向下预测、层层向上索取差额的机器——它学的不是世界，是"世界与我猜的差多少"，而它信哪一层，就看哪一层的差额压得更重。

这就是预测编码。

## 记忆口诀

- 口诀 1：**先猜再对，差额最贵**——预测编码的顺序：预测在前，误差在后。
- 口诀 2：**误差是粮，不是病**——没有误差就没有学习，脑子靠误差活着。
- 口诀 3：**信秤称的不是大小，是可信度**——精度决定一条误差通路的话语权。
- 口诀 4：**楼越高，猜越虚**——层级越高预测越抽象，也越需要下层的差额来校准。
- 口诀 5：**没有底层差额，上层就是空转**——高层的先验再准，没有误差校准也是瞎猜。
- 口诀 6：**主动去撞，误差才有**——伸手、转头、追问，是自己制造信息差。
