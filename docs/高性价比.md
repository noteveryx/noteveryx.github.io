## 📖 关于这本书

> - **作者立场**：作者本人也没做到大部分条目，这是一份按**性价比排序的备选清单**，不是任务清单。做不完两条就算数。
> - **来源标注**：所有数据来自随机分组试验、长期跟踪研究或官方统计；少数没有官方文件撑着的会标"经验"。
> - **证据分级**：A = 高质量证据（随机试验 / 大样本长期跟踪 / 官方统计），B = 较硬证据，C = 经验居多。
> - **本站版本**：与原书快照一致（2026-10-08）。
