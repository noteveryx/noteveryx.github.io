## 今日核心概念

### 1. IPv6 过渡技术
定义：IPv6 过渡技术指在 IPv4 与 IPv6 长期共存期间实现两网互联互通的技术体系，包括双协议栈、隧道与地址转换三大类，是网络规划设计师必考的演进设计内容。
关键要点：
- 三大过渡路线：双栈（同时运行 v4/v6，最简单但设备资源开销大）、隧道（v6 over v4 或 v4 over v6）、翻译（NAT64/DNS64 实现协议转换）
- 隧道分类：手工隧道（IPv6 over IPv4 手工配置隧道、GRE 隧道，适合经常通信的站点间）、自动隧道（6to4：地址前缀 2002::/16 嵌入 IPv4 地址；ISATAP：地址中嵌 IPv4，适合主机接入；Teredo：穿越 NAT）
- 6to4 地址结构：2002 + IPv4 地址十六进制 + 子网 ID + 接口 ID，边界路由器自动从目的地址提取隧道终点
- NAT64 + DNS64 组合：DNS64 合成 AAAA 记录（前缀 64:ff9b::/96），IPv6-only 终端经 NAT64 网关访问 IPv4 服务器
- 演进策略四阶段：双栈试点 → IPv6 骨干承载 IPv4（隧道）→ IPv6 为主 IPv4 边缘接入 → IPv6-only（ government 政务外网改造常按此分阶段推进）
- 规划要点：地址规划按层次聚合（运营商 /32、站点 /48、子网 /64），接口 ID 基于 EUI-64 或随机生成兼顾隐私

### 2. VXLAN 与数据中心大二层设计
定义：VXLAN（可扩展虚拟局域网）是一种 Overlay 网络技术，用 UDP 封装二层报文实现跨三层网络的大二层互通，突破 VLAN 4096 的限制，是云数据中心网络设计的核心。
关键要点：
- 封装格式：原始以太帧 + VXLAN 头（8 字节，含 24 位 VNI 标识，支持 1600 万+) + UDP（目的端口 4789）+ 外层 IP 头
- 核心角色：VTEP（隧道端点，完成封装/解封装，物理交换机或虚拟交换机均可承担）
- 控制平面两种模式：泛洪学习（数据平面自学习，类似传统交换）与 EVPN（MP-BGP 控制平面发布 MAC/IP 路由，减少泛洪，主流方案）
- EVPN 五类路由：Type1 以太网自动发现、Type2 MAC/IP 通告（主机路由）、Type3 组播、Type4 以太网段（防环与 DF 选举）、Type5 IP 前缀（三层网段路由）
- 解决三大问题：VLAN 数量不足（24 位 VNI）、二层跨数据中心延伸（隧道穿越三层）、虚拟机热迁移要求同网段（大二层承载）
- 设计要点：Spine-Leaf 架构等距时延、ECMP 多路径、Underlay 用 OSPF/IS-IS/BGP 互联，Overlay 承载业务；网关集中式（简化）vs 分布式（vTEP 本地执行三层转发，扩展性更好）

### 3. 生成树协议与二层可靠性
定义：生成树协议通过阻塞冗余链路消除二层环路，并可在故障时自动切换恢复，是园区网汇聚/接入层设计的可靠性基础。
关键要点：
- 演进：STP（802.1D，收敛 30-50 秒）→ RSTP（802.1w，快速收敛 1-10 秒，引入根端口/指定端口/替代端口/备份端口四种角色与 Discarding 状态）→ MSTP（802.1s，多实例按 VLAN 分组负载分担）
- RSTP 快速收敛机制：Proposal/Agreement 握手机制（点对点链路秒级切换）、边缘端口（直接转发，等同 PortFast）、根端口快速切换（P/A）
- STP 根桥选举：最小桥 ID 优先（优先级 + MAC），优先级默认 32768，规划时手工指定核心交换机为根桥并设备份根
- 链路聚合 Eth-Trunk/LACP：多条物理链路捆绑为一条逻辑链路，带宽叠加且无环（STP 视为单链路不阻塞）；LACP 模式主动协商，需两端配置一致
- 二层可靠性组合设计：堆叠/CSS 集群 + 链路聚合，消除 STP 依赖，实现设备级+链路级双冗余
- 故障排查要点：环路引发广播风暴（端口流量异常、CPU 升高），启用环路检测、风暴控制、广播抑制

### 4. 网络故障诊断与性能优化方法
定义：网络故障诊断遵循分层排错方法论，从物理层到应用层逐层定位，结合协议分析工具与性能指标进行量化优化，是网络规划设计师下午案例的常考实操题。
关键要点：
- 分层排错顺序：物理层（线缆、光功率、端口 up/down）→ 数据链路层（VLAN、MAC、ARP）→ 网络层（IP、路由、ICMP）→ 传输层（端口、TCP 状态）→ 应用层（DNS、HTTP、证书）
- 常用命令及定位目标：ping（连通性）、tracert/traceroute（路径定位故障跳点）、display ip routing-table（路由表）、arp -a（地址解析）、nslookup/dig（DNS）、netstat（端口与连接状态）
- 镜像与抓包：端口镜像 SPAN/RSPAN 将流量引至分析设备；Wireshark 分析三次握手、重传、窗口变化，TCP 重传率高提示链路质量差
- 性能指标四件套：带宽（bps）、时延（传播/传输/排队/处理四类）、抖动（时延变化，影响语音视频）、丢包率（>1% 明显感知）
- QoS 优化手段：分类标记（DSCP/802.1p）→ 流量监管 CAR（入方向丢弃超限）→ 拥塞管理（WFQ 按权重调度）→ 拥塞避免（RED/WRED 随机提前丢弃防全局同步）
- 典型案例排查思路：访问慢先分段测（内网 vs 出口），出口流量饱和则优化 QoS 或扩容，单应用慢则抓包看时延分布定位服务器处理瓶颈

## 案例分析题
**题目**：某市政务云数据中心采用两台核心交换机（Spine）与多台接入交换机（Leaf）组网，传统 VLAN 划分业务。现需满足三个新需求：①虚拟机需跨机房热迁移且保持 IP 不变；②业务系统数量增长后 VLAN 规划告急；③要求减少二层泛洪流量。请回答：（1）说明应采用什么技术方案及理由；（2）说明该方案中数据报文的封装结构；（3）对比说明集中式网关与分布式网关的优缺点；（4）控制平面推荐使用什么技术及其优势。

**参考答案**：
（1）应采用 VXLAN（Overlay）技术，Spine-Leaf 架构承载 Underlay。理由：VXLAN 使用 24 位 VNI 标识，突破 VLAN 4096 限制，满足业务扩容需求；通过隧道封装实现跨三层物理网络的大二层互通，虚拟机可在跨机房范围内热迁移且 IP/MAC 不变；EVPN 控制平面通过 BGP 发布主机路由，替代数据平面泛洪学习，显著减少泛洪流量。
（2）报文封装结构（由内到外）：原始二层以太网报文 → VXLAN 头（8 字节，含 24 位 VNI）→ 外层 UDP 头（目的端口 4789）→ 外层 IP 头（源/目的 VTEP 地址）→ 外层以太网头。VTEP 负责在入口封装、出口解封装。
（3）集中式网关：三层网关集中在 Spine（或专用网关设备）上，配置集中、管理简单、跨子网流量统一经过网关便于策略控制；缺点是网关流量集中易成瓶颈，东西向流量绕行 Spine，路径非最优。分布式网关：每个 Leaf 节点均承担三层网关（VTEP 本地执行三层转发），东西向流量本地就近转发、路径最优、扩展性好，通过虚拟网关（VBDIF 绑定同一 VNI、MAC 相同）实现双活；缺点是配置复杂、全网策略一致性维护难度大。云数据中心通常推荐分布式网关。
（4）控制平面推荐 EVPN（以太网虚拟专用网），基于 MP-BGP 扩展通告 MAC/IP 路由信息。优势：主机 MAC/IP 地址通过 Type2/Type5 路由集中发布，VTEP 无需泛洪学习，减少泛洪占用带宽；支持 ARP 抑制与代答；支持多归属双活接入与快速收敛；跨数据中心场景可直接用 EVPN 多协议扩展打通。

**踩分要点**：
- 指出 VXLAN 技术（1 分）并说明 24 位 VNI 突破 VLAN 4096 限制（1 分）
- 大二层跨三层互通支撑虚拟机热迁移且 IP 不变（1 分）
- EVPN 替代泛洪学习、减少二层泛洪（1 分）
- 封装结构完整列出：原始帧 + VXLAN 头（含 VNI）+ UDP（4789）+ 外层 IP（1 分），VTEP 封装/解封装职责（1 分）
- 集中式网关：配置简单、流量集中成瓶颈、东西向绕行（1 分）
- 分布式网关：本地转发路径最优、可扩展性强、配置复杂（1 分）
- EVPN 基于 MP-BGP 发布 Type2（MAC/IP）路由（1 分）、ARP 抑制/多归属/快速收敛至少答出两点（1 分）

## 记忆口诀
- IPv6 过渡三法：「双栈并存最省心，隧道穿山跨旧网，翻译 NAT64 通两岸」
- 自动隧道区分：「6to4 前缀 2002，ISATAP 主机插中间，Teredo 专穿 NAT 门」
- VXLAN 封装：「外三层 UDP 四七八，VNI 二十四位大，千六百万段不愁，VTEP 两端来打包」
- EVPN 路由五类：「一自二主三组播，四段防环五前缀」（Type1 自动发现、Type2 MAC/IP、Type3 组播、Type4 以太网段、Type5 IP 前缀）
- RSTP 四角色：「根指替备记心间，丢弃取代侦学转，握手边缘快收敛」
- 分层排错：「先看线再 VLAN，路由通了查端口，最后才到应用层」
- QoS 四步：「先分类标记，再监管入卡，拥塞 WFQ 调度，WRED 防抖丢」
