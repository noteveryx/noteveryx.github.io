# （高级）网络规划设计师 · 第 7 次学习

## 今日核心概念

### 1. VPN 技术体系（IPSec VPN 与 SSL VPN）
定义：在公共网络上通过隧道、加密、认证技术构建的虚拟专用网络，分为网络层 IPSec VPN 与传输层 SSL VPN 两类。
关键要点：
- IPSec VPN 工作在网络层，提供 AH（认证头，协议号 51）与 ESP（封装安全载荷，协议号 50）两种协议，ESP 同时提供加密与认证，AH 只认证不加密。
- IPSec 两个阶段：第一阶段通过 IKE 协商建立管理连接（主模式 6 个报文/野蛮模式 3 个报文），第二阶段通过快速模式建立安全连接（协商 SA）。
- IPSec 两种封装模式：传输模式（保护载荷，用于主机到主机）与隧道模式（保护整个 IP 包，用于网关到网关）。
- SSL VPN 工作在传输层与应用层之间，基于 HTTPS（443 端口），以浏览器免客户端接入，按业务颗粒授权，适合移动办公与远程访问。
- 选型口诀：局域网对等互联用 IPSec，分散远程接入用 SSL。

### 2. 防火墙体系与安全域划分
定义：部署在信任边界、依据安全策略对进出流量进行控制过滤的设备/系统，现代防火墙以安全域（Zone）为核心组织安全策略。
关键要点：
- 防火墙三大安全域：Trust（内网，优先级 85）、Untrust（外网，优先级 5）、DMZ（非军事区，优先级 50），域间流量默认拒绝，需显式放行。
- DMZ 用于部署对外发布的服务器（Web、邮件、DNS），外网可访问 DMZ，DMZ 不能主动访问内网 Trust，实现"内外隔离、服务外置"。
- 防火墙安全策略五元组匹配：源地址、目的地址、源端口、目的端口、协议；状态化检测维护会话表，回程报文自动匹配放行。
- 防火墙三大性能指标：吞吐量、并发连接数、新建连接速率；规则匹配自上而下、逐条匹配，顺序影响性能与安全。
- 纵深防御体系：边界防火墙 + IPS + WAF + 抗 DDoS + 沙箱，形成多层拦截。

### 3. 入侵检测（IDS）与入侵防御（IPS）
定义：IDS 旁路部署监听流量并告警（检测型），IPS 串联部署实时阻断攻击（防御型）。
关键要点：
- 部署方式：IDS 旁挂镜像口（SPAN 口），不影响业务转发，事后分析；IPS 串联在流量路径上，可实时丢包阻断，但有单点故障风险，需配置硬件 Bypass。
- 检测技术：特征检测（模式匹配，误报低但无法发现新攻击）与异常检测（建立流量基线，可发现未知攻击但误报高）。
- IDS 误报与漏报的平衡：调整签名阈值、白名单、结合威胁情报库。
- 高级威胁需配合沙箱（未知文件行为分析）与 NDR（网络检测与响应）构建检测响应闭环。

### 4. 等保 2.0 网络架构安全要求
定义：《网络安全等级保护基本要求》（GB/T 22239-2019）中针对网络架构层的安全通用要求，政务系统普遍要求三级。
关键要点：
- 三级系统网络架构核心要求：网络设备业务处理能力满足业务高峰期需要；核心交换、接入设备链路与设备冗余；划分 VLAN 与安全域，重要网段与其他网段隔离。
- 一个中心三重防护：安全管理中心 + 安全通信网络、安全区域边界、安全计算环境。
- 三级与二级关键差异：三级强制要求通信传输保密性（加密）、边界防护完整性、入侵防范（IDS/IPS 必配）、恶意代码防范、剩余信息保护、异地数据备份（三级：异地实时备份）。
- 等保测评五环节：定级、备案、建设整改、等级测评、监督检查；三级系统每年至少测评一次。
- 网络设备自身要求：登录地址限制、双因素认证（关键设备）、密码策略、SNMP v3、关闭不必要服务、操作日志留存不少于 6 个月。

### 5. 网络接入安全（802.1X 与准入控制）
定义：基于端口的网络接入控制协议，用户接入网络前须经身份认证，配合 NAC 实现终端准入合规检查。
关键要点：
- 802.1X 三角色： supplicant（客户端）、authenticator（接入交换机）、authentication server（认证服务器，RADIUS，UDP 1812/1813）。
- 认证流程：EAPOL 交换 → 交换机封装 EAP 为 RADIUS → 服务器校验 → 下发 VLAN/ACL 动态授权。
- 三种接入认证对比：802.1X（端口级、安全强、需客户端）、Portal（Web 免客户端、适合访客）、MAC 认证（免交互、适合打印机等哑终端）。
- NAC 准入联动：终端补丁、杀毒软件合规检查，不合规自动隔离到修复区。
- 政务网实践：办公终端 802.1X + 访客 Portal + 打印机 MAC 认证，认证服务器与 AD 域账号统一，实现"一人一账号、终端一准入"。

## 案例分析题

**题目**：某市政务服务中心外网改造项目，包含办公终端约 800 台，对外提供政务服务的 Web 服务器、邮箱服务器需向互联网发布，系统定级为等保三级。网络分为互联网区、DMZ 区、办公区、核心区四个区域。请回答：
（1）设计四个区域之间的安全域划分与互访策略。
（2）为对外服务区选择并说明 IDS/IPS 部署方式。
（3）为办公终端设计接入认证方案。
（4）简述等保三级对通信传输与数据备份的强制要求。

**参考答案**：
（1）安全域划分与策略：
- 核心区优先级最高（Trust），办公区次之，DMZ 区居中，互联网区（Untrust）最低；
- 互联网 → DMZ：仅放行 80/443/25 等对外服务端口，源地址经抗 DDoS 与 WAF 清洗；
- DMZ → 办公区/核心区：默认禁止，仅放行应用所需的具体端口（如应用服务器访问数据库端口）；
- 办公区 → DMZ：按业务需要放行；
- 办公区 → 互联网：经 NAT 与上网行为审计后放行；
- 各域间默认拒绝（deny any），白名单显式放行，策略遵循最小授权原则。
（2）对外服务区部署 IPS 串联在防火墙与 DMZ 交换机之间，实时阻断针对 Web 服务的攻击（SQL 注入、跨站等）；同时在核心交换旁路部署 IDS 镜像监听全网，发现横向渗透并告警；关键节点配置硬件 Bypass 避免单点故障，配合沙箱检测未知威胁。
（3）办公终端采用 802.1X 认证：终端安装 supplicant，接入交换机作 authenticator，RADIUS 服务器对接 AD 域统一账号，实现一人一账号；认证通过后动态下发 VLAN；打印机等哑终端采用 MAC 认证；访客通过 Portal 认证进入访客 VLAN 并与办公网隔离；配合 NAC 做补丁与杀毒合规检查，不合规终端隔离至修复区。
（4）等保三级强制要求：
- 通信传输：采用密码技术保证通信过程中数据的保密性与完整性（如 HTTPS/TLS、国密 SM 系列）；
- 数据备份：提供异地实时备份功能，利用通信网络将关键数据定时批量传送至异地备份场所；重要数据本地+异地双备份，恢复演练定期开展。

**踩分要点**：
- 安全域互访策略必须体现"默认拒绝+白名单放行+最小授权"三条原则，写出 DMZ 不得主动访问内网（约 3 分）；
- IPS 必须答出"串联部署、实时阻断"，IDS 答出"旁路镜像、事后告警"，并写出 Bypass 防单点（约 3 分）；
- 802.1X 三角色（客户端/交换机/RADIUS 服务器）缺一不可，哑终端 MAC 认证与访客 Portal 认证为加分项（约 3 分）；
- 等保三级关键句：通信"保密性与完整性"、备份"异地实时备份"——漏"实时"扣分（约 4 分）。

## 记忆口诀

- IPSec 阶段口诀：「一主二快」——第一阶段 IKE 主模式协商管理连接，第二阶段快速模式协商安全连接。
- ESP 与 AH：「ESP 加密又认证，AH 只验不加密」。
- 防火墙域优先级：「信高非中不低」——Trust 85、DMZ 50、Untrust 5。
- IDS 与 IPS：「旁路检测 IDS，串联阻断 IPS，串上必配 Bypass」。
- 等保三级备份：「本地备份加异地，实时传送不间断，三级每年一测评」。
- 接入认证三兄弟：「哑终端找 MAC，浏览器走 Portal，办公终端 802.1X」。
