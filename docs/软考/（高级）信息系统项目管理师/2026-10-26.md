## 今日核心概念

### 1. 决策树与期望货币价值（EMV）
定义：决策树是风险型决策的图形化工具，用方形节点表示决策点、圆形节点表示机会点（状态节点）、末端节点标注结果值，分支标注各方案与各状态的概率。期望货币价值（Expected Monetary Value, EMV）是对某一决策方案的各条分支按其发生概率加权求和所得的期望收益，用于比较多个备选方案的优劣。

关键要点：
- **三类决策与对应工具**：确定性决策（单一确定结果，直接比较）→比较法；风险型决策（多种结果且概率已知）→**决策树 + EMV**；不确定性决策（多种结果且概率未知）→决策树 + 决策准则（乐观准则大中取大、悲观准则小中取大、折中准则、**最小最大后悔值准则**）
- **EMV 计算式**：EMV = Σ（各分支结果值 × 该分支发生概率）；概率之和必须等于 1
- **EMV 的适用前提**：只适用于**风险型**决策（概率已知），对不确定性决策不可用；EMV 本质是"大数定律下的期望最优"，**一次性决策不一定能实现该期望值**
- **决策树绘制顺序（考试给分点）**：先在右端画结果节点并标注金额 → 从右向左画机会节点并标注概率 → 再向左画决策节点（方框）→ 自右向左计算各机会节点的期望值 → **回溯剪枝（标注最优方案）**
- **敏感度分析（转折概率）**：求"某方案成为最优所需的临界概率"。若方案优势仅在概率超过某阈值时成立，则该概率是项目的**关键监控指标**，应专项跟踪
- **EVPI（期望完美信息价值）** = 已知完全信息时的期望收益 − 按概率加权时的最优期望收益；EVPI 是"值得花多少钱去买信息"的上限，用于判断是否值得做市场调研/试点验证

### 2. 博弈论、纳什均衡与委托代理
定义：博弈论研究多个决策者（参与人）之间策略相互影响的均衡问题，包含参与人、策略（行动）、收益（支付）三要素。纳什均衡指在给定其他参与人策略不变时，任何一个参与人都无法通过单方面改变策略提高自身收益的策略组合。

关键要点：
- **均衡与效率是两件事**：纳什均衡是"稳定"但不一定是"最优"，如囚徒困境的均衡结果是双方皆劣；**帕累托最优**才对应"整体最好"，二者不重合
- **信息不对称的两副形态**：
  - **逆向选择（签约前/事前）**：交易一方掌握更真实的信息，采购方可能选到"看起来好、实际差"的方案 → 治理手段：资格审查、业绩与案例核查、样板间/试点验证、履约能力评价
  - **道德风险（签约后/事后）**：签约后信息方改变行为、偷工减料或降低投入 → 治理手段：里程碑验收、量化验收标准、履约保证与质量保证金、第三方监理、履约评价与失信惩戒
- **激励相容（IC）与参与约束（IR）**：机制设计要让"如实申报、认真履约"成为参与者的**最优选择**，否则再严的合同也只是纸面条款
- **重复博弈与声誉机制**：单次博弈中机会主义占优；多期合作中"未来收益"可抑制短期违约，因此**长期合作履约记录**本身就是治理资产
- **零和 vs 非零和**：零和博弈（蛋糕分割型，如预算争抢）结果是零和的，非零和（政企合作、多部门数据共享）可通过创造增量价值实现双赢——政务信息化中应优先把博弈设计成**非零和**（如按数据共享带来的减支按比例返还额度）

### 3. 运筹学优化模型：线性规划、网络分析与排队论
定义：运筹学用数学模型求资源配置最优解。线性规划（LP）是求线性目标函数在线性约束下最优解的方法；网络分析研究图上路径、流量问题；排队论研究随机到达与随机服务的系统。

关键要点：
- **线性规划三要素**：决策变量、目标函数、约束条件；线性规划的最优解必在某个**顶点（可行解基）**取得
- **灵敏度分析与影子价格（对偶价格）**：某资源约束的影子价格表示"该资源增加一个单位带来的目标函数增量"，可据此判断资源是否值得追加投入
- **网络最大流与最小割定理**：最大流等于最小割；用于节点/链路的容量测算（如政务外网带宽、数据交换通道吞吐）
- **排队论基本模型**：
  - M/M/1：ρ = λ/μ（利用率），ρ→1 时等待时间趋于无穷；系统稳定性要求 **λ < μ**
  - M/M/c：多窗口排队，常用于政务大厅窗口设置、热线坐席数量测算
  - 关键指标：平均队长 L、等待时间 W、忙时利用率；**利用率超过 80% 需扩容**，否则等待时间将非线性暴涨
- **库存论 EOQ（经济订货批量）**：Q* = √(2DS/H)，D 年需求量、S 单次订货成本、H 单位库存持有成本；用于硬件、备件、耗材采购量测算
- **网络计划技术**：双代号时标网络图、时差与关键线路（与进度管理模块衔接），是运筹学在项目管理中最直接的应用

### 4. 项目管理数学基础：概率分布、蒙特卡洛与统计推断
定义：项目管理数学基础运用概率论与数理统计对项目风险和绩效进行量化分析，主要工具包括概率分布、蒙特卡洛模拟、决策树、线性规划、方差分析与抽样检验。

关键要点：
- **常用分布**：离散（二项分布、泊松分布）；连续（均匀、正态、对数正态、**三角分布/PERT 使用的 β 分布**）
- **三点估算**：乐观 O、最可能 M、悲观 P；期望工期 Te =（O + 4M + P）/ 6；标准差 σ =（P − O）/ 6；方差 σ² =（P − O）²/36；路径工期 = 各活动期望之和，路径方差 = 各活动方差之和
- **蒙特卡洛模拟三步**：① 为每个不确定变量设定概率分布 → ② 成千上万次随机抽样组合并计算结果 → ③ 统计结果分布（P10/P50/P90、完工概率、成本超支概率）
- **置信区间与假设检验**：显著性水平 α（常用 0.05）、t 检验、卡方检验；用于判断绩效差异是真实改进还是随机波动
- **方差分析（ANOVA）**：单因素方差分析可比较"多个方案/多个团队/多个指标"在均值上的差异是否显著，避免用**平均值掩盖离散程度**（案例常考"平均分高但方差大"）
- **常用分布选择口诀**：成本超支倾向右偏 → 用**对数正态**；工期有下限无上限 → 用**三角/PERT**；无上下限的均匀估算 → **均匀分布**

### 5. 项目决策中的认知陷阱与决策纪律
定义：项目决策中因认知偏差导致的系统性判断错误，识别并规避这些陷阱是项目经理的核心职业素养之一。

关键要点：
- **沉没成本谬误**：已投入且不可收回的成本不应影响后续决策；判据是"从此刻起，边际收益是否大于边际成本"
- **锚定效应**：容易把第一个数字（初始报价、早期估算）当作基准并围绕它调整；对策是对每项估算做**独立估算 + 多来源交叉验证**
- **升级承诺（承诺升级）**：为维护自我形象或避免承认失败而继续投入劣质方案；对策是设置**预设的止损点（kill criteria）**，到期无条件评估
- **框架效应与可得性启发**：同一事实因表述方式不同得出相反结论（"成功率 90%"与"失败率 10%"）；对策是统一用**绝对数 + 概率 + 基准**三要素表述
- **近因效应与规划谬误**：用最近一次顺利的经验推算未来，导致系统性乐观；对策是**参照类预测**（用同类项目历史数据做基准，而非团队主观判断）
- **确认偏误**：只搜集支持既有判断的信息；对策是团队内指定一名"**反对者**"，强制呈递反面证据
- **决策纪律三问**：① 备选方案是否穷举？② 结论对哪些假设最敏感（转折概率）？③ 什么证据出现时应推翻当前决策？

## 案例分析题

**题目**：

某市政务服务数据管理局拟建设"跨部门数据共享交换平台"升级项目，三家方案由三家单位报价，专家组评估如下（单位：万元，三年期，不折现）：

- **方案A（自建）**：建设成本 200 万，年运维 40 万；专家组评估成功概率 70%，成功后每年产生效益 120 万
- **方案B（整体外采 SaaS）**：三年总费用 360 万；成熟产品成功概率 95%，每年效益 130 万
- **方案C（混合：自建核心 + 外采成熟模块）**：建设成本 120 万 + 外采 180 万，合计 300 万；成功概率 90%，每年效益 150 万

评审会上出现四种情况：
1. 数据局信息中心提出用期望货币价值比较三方案。
2. 专家测算发现，若方案C因需通过等保三级测评而延迟 3 个月上线，其成功概率将从 90% 降至 70%。
3. 信息中心在评审中发现，外包供应商掌握模型与接口的真实性能数据，而局方无法核验，供应商为拿下项目刻意隐瞒了接口并发能力的实测值。
4. 项目建成后，运维科室仍按原有流程人工处理工单，未使用新平台，运维人员私下认为"用了新平台出事要担责，不用只按惯例办"，且该科室负责人的绩效考核只与工单按时办结率挂钩。

**问题**：
1. 该方案选择属于哪一类决策？应使用何种量化工具？EMV 的计算前提是什么？
2. 分别计算三个方案三年的净期望收益（效益期望 − 成本），并给出排序结论。
3. 针对第 2 种情况，决策是否改变？请计算转折概率并说明管理含义。
4. 针对第 3 种情况，用博弈论分析问题性质，指出属于逆向选择还是道德风险，并提出至少四条治理措施。
5. 针对第 4 种情况，用博弈论的重复博弈与激励相容机制，设计使运维人员主动使用新平台的机制方案。

**参考答案**：

**问题 1**：
- 属于**风险型决策**：存在多个备选方案，每个方案的结果有多种可能，且**概率已知（可由专家组评估）但不完全确定**。
- 若概率**已知**，用**决策树 + 期望货币价值（EMV）**比较；本题三方案互斥且成本效益可货币化，EMV 直接适用。
- **计算前提**：① 各结果状态的概率必须已知且**互斥完备、合计为 1**；② 收益与成本必须可**货币化计量**；③ 期望值是**长期重复决策下的平均值**，一次性决策未必实现该值；④ 若概率未知（不确定性决策），**不能使用 EMV**，应改用乐观/悲观/折中/最小最大后悔值准则。

**问题 2**（三年净期望收益 = 效益期望 − 成本）：

- **方案A**：成本 = 200 + 40×3 = 320；效益期望 = 0.7 × 120 × 3 = 252；**净期望 = 252 − 320 = −68 万**
- **方案B**：成本 = 360；效益期望 = 0.95 × 130 × 3 = 370.5；**净期望 = 370.5 − 360 = +10.5 万**
- **方案C**：成本 = 120 + 180 = 300；效益期望 = 0.9 × 150 × 3 = 405；**净期望 = 405 − 300 = +105 万**

**排序：方案C（+105）> 方案B（+10.5）> 方案A（−68）**，选择方案C。三个方案净期望均为正时，应进一步比较**风险敞口**（方案C 概率分散度最大、方差最大），可辅以蒙特卡洛模拟给出完工/效益达标概率区间。

**问题 3**：
- 方案C 在概率降为 70% 时：效益期望 = 0.7 × 150 × 3 = 315；净期望 = 315 − 300 = **+15 万**，仍**大于方案B 的 +10.5 万**，故**排序未改变，仍选方案C**，但优势从 94.5 万压缩到 **4.5 万**，安全边际几乎消失。
- **转折概率计算**：设方案C成功概率为 p，令 C 与 B 净期望相等：450p − 300 = 10.5 → **p = 69%**。即 **p < 69% 时应改选方案B；p = 69% 时两方案等价；p > 69% 时方案C最优**。
- **管理含义**：① "69%" 是本项目的**关键监控阈值**，应纳入项目风险登记册并设置预警；② 概率每下降 1 个百分点，净期望减少 4.5 万，属高敏感变量，须专项跟踪等保测评进度；③ 结论稳健但脆弱，**不能仅凭 EMV 拍板**，应叠加**多方案保留与分阶段实施**（先上方案B保底、等保通过再切换C）；④ 建议做**蒙特卡洛模拟**输出 P50/P90 区间，确认在悲观情景下是否仍成立。

**问题 4**：
- **问题性质**：信息不对称 + 委托代理关系。发生在**签约前的信息甄别环节**，属于**逆向选择（事前）**，不是道德风险（后者发生在签约后的履约行为中）。
- **逆向选择的成因**：供应商比采购方更了解自身产品的真实性能（隐瞒接口并发实测值），局方缺乏甄别手段，导致"低报性能、以次充好"具有收益，理性供应商都会隐瞒。
- **治理措施（四条以上）**：
  1. **事前的信号与甄别**：要求供应商提供近三年同类项目合同与验收证明、同业第三方检测报告、驻场演示与压力测试实测报告；建立供应商**信用与履约评价档案**，与省級公共资源交易信用平台数据打通。
  2. **专业监理介入**：引入第三方监理单位对接口性能、并发能力做**独立验证与实测**，把"供应商自证"变成"第三方验证"，直接消除信息不对称根源。
  3. **样本验证与试点先行**：采用"**试点—扩容**"方式，在小范围真实业务上以实测数据验证性能后再全量铺开，以真实运行数据替代供应商声明。
  4. **激励相容的合同设计**：性能指标与付款挂钩（里程碑付款 + 保留金/质量保证金），写明**接口并发实测值不达标的违约金与解约条款**，使"如实披露"成为供应商的最优选择。
  5. **履约期与退出机制**：设置履约保证、联合验收、违约退出条款，并将履约记录纳入供应商信用档案。
- **答题要点**：必须点明"**逆向选择 + 事前 + 第三方验证 + 激励相容**"四个关键词，并给出至少四条可操作措施。

**问题 5**：
- **问题定性**：运维人员处于"**多期重复博弈**"中，但其考核只与工单办结率挂钩（单期局部激励），且其个人风险（出事担责）与平台收益不匹配——典型的**激励不相容 + 短期博弈**，导致理性选择是不用新平台。
- **机制设计四条**：
  1. **风险与收益共担，消除"用新平台担责"的负激励**：制定新平台操作错误免责与容错清单（合理操作偏差不追责），明确因未使用新平台导致的数据错误与舆情事件反而纳入追责——即**"不用的风险 ≥ 用的风险"**。
  2. **修正考核指标**：将绩效从"工单按时办结率"单一指标，改为"办结率 + 新平台使用率 + 一次解决率 + 差错率"组合指标，并设置新平台使用率的**阶段爬坡目标**（如首月 60%、三月 80%），使采用行为进入个人收益函数。
  3. **重复博弈与声誉机制**：把平台使用情况纳入科室与个人的**运维履职评价档案**，与评优、晋升、培训机会挂钩；同时对采用突出的科室公开通报表扬——利用"未来多期收益"抑制短期机会主义。
  4. **惩罚与奖励对称**：对绕过平台处理工单（"线下走流程"）建立稽核机制与通报；对按新平台规范操作并降低差错率的科室给予绩效加分，形成对称激励，避免只罚不奖。
  5. **降低切换成本与学习负担**：配套培训、编制操作手册与常见问题库，设置上线初期驻场答疑，把"用了容易出错"的担忧转化为"不会用所以怕用"，从供给侧解决采用障碍。
- **答题要点**：点明"**重复博弈 + 局部最优导致整体不优 + 修正考核指标消除激励不相容 + 风险共担 + 声誉机制**"。

**踩分要点**：
1. 决策类型判断 + 工具选择 + **EMV 适用前提（概率已知、货币化、大数定律局限）**——三处得分点，缺一扣分。
2. **三个方案的成本与效益期望必须分别完整列出计算式**（尤其方案A 的"建设+三年运维=320"、方案C 的"120+180=300"），只给结论不给过程扣分。
3. 转折概率求解过程（450p − 300 = 10.5，p = 69%）与**阈值管理含义**是本题最高区分度得分点。
4. 问题四必须准确区分**逆向选择（事前）与道德风险（事后）**，并给出可操作治理措施；只答"加强管理、签协议"不得分。
5. 问题五必须落到**激励机制设计**层面（考核指标修正、风险共担、声誉与多期博弈），泛泛谈"加强培训沟通"不得分。
6. 建议在答案末尾补一句**多方案保留/分阶段实施**的决策纪律，体现项目经理视角。

## 记忆口诀

- 口诀 1：**三型决策三套招**——确定比大小，**风险用 EMV**，不确定用四准则（大大、小小、折中、最小最大后悔）。
- 口诀 2：**EMV 三前提**——概率已知（合为1）、**能折成钱**、是**大数长期值**（一次不一定兑现）。
- 口诀 3：**决策树四步走**——右端标金额，往左标概率，算期望值，最后**回溯剪枝**。
- 口诀 4：**敏感度看转折点**——临界概率 = 净期望相等解；**它就是必须监控的红线**。
- 口诀 5：**逆向选择在前，道德风险在后**——签约前怕**掺假**，签约后怕**偷懒**；前者靠**第三方验证**，后者靠**里程碑验收**。
- 口诀 6：**纳什均衡 ≠ 帕累托最优**——均衡只管**谁都不后悔**，不管**整体好不好**。
- 口诀 7：**排队论抓两个数**——**利用率 ρ=λ/μ**、**λ<μ 才不崩**；**超 80% 就扩容**，否则等待时间暴涨。
- 口诀 8：**EOQ 一根式**——Q\*=√(2DS/H)，D 需求、S 单次订货、H 持有成本，**订货批量别拍脑袋**。
- 口诀 9：**分布选型对症**——成本超支**右偏用对数正态**，工期有底无顶**用三角 PERT**，无界估算**用均匀**。
- 口诀 10：**方差分析防平均值骗人**——平均高**不代表**稳，**离散度**才见真相。
- 口诀 11：**四大决策陷阱**——沉没成本不回头、锚定先入为主、承诺升级要止损、可用性偏误要设**反对者**。
- 口诀 12：**重复博弈破短期博弈**——单次机会主义占优，多期**声誉与未来收益**能压住；政务合作**尽量设计成非零和**。
- 口诀 13：**决策纪律三问**——方案穷举了吗、**哪条假设最敏感**、**什么证据推翻我**。
