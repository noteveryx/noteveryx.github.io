# 2026-09-24 第54次学习

## 今日核心概念

### 1. 团队绩效域

定义：团队绩效域是与团队人员相关的活动与职能，聚焦于项目团队成员的领导力、文化、情商、协作与赋能，是 PMBOK 第七版八大绩效域中与人最密切相关的领域。

关键要点：

- 团队领导力：领导者通过愿景、影响力与决策力引导团队，区别于管理者（职权驱动）转向领导者（影响力驱动），需具备服务型领导、情境领导、变革型领导三种典型风格。
- 高绩效团队特征：塔克曼五阶段（形成、震荡、规范、成熟、收尾）演进到成熟期后呈现目标一致、心理安全、互信协作、持续学习的特征。
- 文化与情商：情商五要素（自我觉察、自我调节、自我激励、社会觉察、社交管理）直接影响团队凝聚力，项目经理情商贡献度约占项目成功率的 30%-40%。
- 协作与赋能：服务型领导（仆人式领导）强调授权、激励与赋能，通过 RACI、责任分配矩阵、RAM 明确角色，通过心理安全感促进创新。
- 团队建设活动：集中办公（作战室）、团队章程、奖励与认可机制、培训与技能矩阵、冲突管理五策略（撤退/缓和/妥协/强迫/合作/面对）。

### 2. 不确定性绩效域

定义：不确定性绩效域关注项目实施过程中各种模糊性、风险、复杂性与混沌状态的识别、评估、应对与持续监测，是 PMBOK 第七版中专门应对 VUCA 时代项目特征的新增绩效域。

关键要点：

- 不确定性来源：风险（已知未知）、模糊性（未知未知）、复杂性（多变量相互依赖）、波动性（快速变化）四类来源（也称 VUCA 框架）。
- 识别与评估：风险分解结构 RBS + 概率-影响矩阵 + 蒙特卡洛模拟 + 储备金分析（已知-未知 + 管理储备）。
- 应对策略：威胁四策（规避、转移、减轻、接受）+ 机会四策（开拓、分享、提高、接受），并增加"适应"作为新策略应对模糊性。
- 灵活性交付：敏捷、精益、迭代交付、Scrum Sprint、滚动式规划、占位符需求（Enabler Story）、延迟决策至最后责任时刻（Last Responsible Moment）。
- 反脆弱能力：借鉴塔勒布反脆弱思想，通过期权思维（实物期权）、小步快跑 A/B 测试、预留缓冲（Conway 法则、缓冲优化）等手段从不确定性中获益。

### 3. 度量绩效域

定义：度量绩效域关注如何建立度量体系、采集关键数据、分析度量结果并指导项目决策与持续改进，是连接"做"与"价值"的桥梁，对应"度量金字塔"三层模型。

关键要点：

- 度量金字塔三层：底层度量（团队工作率、缺陷密度、生产率）→ 中层度量（挣值 EV、偏差 SV/CV/SPI/CPI、TCPI）→ 顶层度量（业务价值 ROI、NPV、客户满意度 NPS）。
- 关键度量指标：进度（SPI、燃尽图）、成本（CPI、EAC=BAC/CPI、ETC、VAC、TCPI）、质量（缺陷密度、逃逸缺陷率、MTBF）、范围（需求稳定性、变更率）、风险（风险敞口、储备金消耗率）。
- 度量陷阱：忽略度量有效性（数据≠信息）、度量滥用（古德哈特定律"指标成为目标时就不再是好指标"）、局部优化（牺牲全局）、度量成本大于价值。
- 持续改进：PDCA 戴明环 + 度量驱动的回顾会议 + 度量基线 + 度量能力成熟度（CMMI 度量分析 MA 域、数据管理 DMM）。
- 可视化技术：仪表盘（Dashboard）、累积流图、控制图、趋势分析、燃尽/燃起图、价值流图（VSM），强调"一眼可见、一目了然"。

### 4. 项目工作绩效域（重点补充）

定义：项目工作绩效域涵盖项目管理过程中实际开展的工作内容、过程与产物，是八大绩效域中最具体的执行层面，与过程管理高度对应。

关键要点：

- 五大过程组对应：启动（章程、干系人识别）→ 规划（基准、子计划）→ 执行（实施、团队建设、采购交付物）→ 监控（综合变更控制、整体盘点）→ 收尾（合同收尾、行政收尾、经验教训）。
- 整合管理核心：项目章程授权 + 变更控制 CCB + 项目收尾三件套 + 经验教训知识库 + 阶段关口审查。
- 范围-进度-成本铁三角：范围基准（WBS、WBS 字典）→ 进度基准（关键路径、网络图、资源平衡）→ 成本基准（按时间分段 S 曲线），三者经挣值 EV 联动分析。
- 工具集：WBS、RAM、RACI、责任矩阵、网络图（PDM、ADM）、S 曲线、燃尽图、敏捷看板（Kanban）、累积流图。
- 与 PMBOK 第六版的兼容：第 7 版绩效域 = 第 6 版 49 个过程的重新归类，过程虽重组但工具技术、输入输出、角色职责基本不变，备考需新旧对照。

## 案例分析题

**题目**：
某大型电子政务平台项目（合同金额 1800 万元，工期 18 个月）已执行至第 9 个月。在第 9 个月状态审查中，项目经理老陈发现以下情况：
（1）PV（计划值）= 900 万元，EV（挣值）= 720 万元，AC（实际成本）= 810 万元。
（2）项目团队最近出现两位核心开发人员离职，一位是架构师、一位是测试负责人，导致部分接口开发停滞。
（3）需求方（甲方）提出一项紧急新增需求：要求系统增加"人脸识别实名认证"功能，估计需要增加 60 万元成本和 1.5 个月工期。
（4）公司质量部门季度审计指出项目技术文档与代码同步滞后 30%，文档评审缺陷率达 18%。
问题：
（1）请计算项目的 SV、CV、SPI、CPI，并判断项目当前的绩效状态。
（2）若项目按当前 CPI 趋势继续执行，请计算 EAC 和 VAC，并评估是否需要在剩余 9 个月内追加成本或赶工。
（3）针对人员离职、需求变更、文档滞后三个问题，请分别提出具体应对措施。
（4）从 PMBOK 第七版八大绩效域视角，说明项目经理老陈应优先关注哪两个绩效域，并说明理由。

**参考答案**：

（1）SV = EV - PV = 720 - 900 = -180 万元（负值，进度滞后）；CV = EV - AC = 720 - 810 = -90 万元（负值，成本超支）；SPI = EV/PV = 720/900 = 0.80（每计划 1 元仅完成 0.80 元）；CPI = EV/AC = 720/810 ≈ 0.89（每投入 1 元仅产生 0.89 元价值）。综合判断：项目同时存在进度落后和成本超支，处于"落后-超支"象限，需要综合纠偏。

（2）EAC = BAC / CPI = 1800 / 0.89 ≈ 2022.47 万元，VAC = BAC - EAC = 1800 - 2022.47 ≈ -222.47 万元。即预测最终超支约 222 万元，需追加约 222 万元成本或启动风险储备金。建议：（a）申请动用管理储备金（已知的未知）；（b）剩余阶段推行赶工（Crashing，加资源赶关键路径）或快速跟进（Fast Tracking，并行施工）；（c）启动变更控制 CCB 评审。

（3）应对措施：
- 人员离职：立即启动人才备份计划，关键岗位实行"双岗互备（A/B 角）"，知识资产文档化（架构决策记录 ADR、代码注释、wiki），外部紧急招聘或借调，提前规划非关键路径工作。
- 需求变更：走变更控制五步（申请 → 分析 → CCB 评审 → 实施 → 验证），评估 60 万+1.5 月影响全部相关方，更新范围/进度/成本基准，签补充协议，如变更影响超过阈值则重新做商业论证 BC。
- 文档滞后：推行"代码即文档"+ 自动化文档生成（Swagger/OpenAPI、Javadoc）、每周文档审计纳入质量门、文档缺陷率纳入 KPI、技术评审 Gate 必须文档齐备。

（4）应优先关注"团队绩效域"和"度量绩效域"（次选"不确定性绩效域"）。理由：
- 团队绩效域：两位核心人员离职直接冲击团队稳定与产出，需立即通过团队重建、心理安全、知识传递、激励保留等措施稳住团队，符合"人是最关键资产"的治理原则。
- 度量绩效域：SPI 0.80、CPI 0.89 已是红灯，必须建立实时仪表盘（仪表盘+累积流图+燃尽图），用度量驱动纠偏决策，避免凭感觉管理。
- （次选）不确定性绩效域：人员流失 + 需求变更加剧模糊性，需启用储备金、灵活交付、期权思维应对 VUCA。

**踩分要点**：
- 挣值计算公式务必精准：PV、EV、AC 含义、SV/CV/SPI/CPI 公式不能混淆。
- EAC 计算要根据假设选用不同公式：典型情况 EAC=BAC/CPI；如认为偏差属特殊原因用 EAC=AC+剩余 BAC；如认为未来偏差同比例用 EAC=AC+(BAC-EV)/CPI。
- 应对措施要"对症下药"，不可笼统说"加强管理"，要落到工具、流程、角色、责任。
- 八大绩效域选择要"就事论事"：根据案例问题匹配对应绩效域，并给出至少一条具体落地动作。
- 涉及人员管理必答"塔克曼阶段、情商、心理安全、知识管理"四件套。

## 记忆口诀

口诀一（八大绩效域速记）：**「团开策测工不安，变划交付量实盘」**
团队、开局（干系人）、策划（规划）、度量、工作、**不**确定性、变革（开发方法与生命周期）、交付（生命周期）
对应英文：Team / Stakeholder / Planning / Measurement / Work / Uncertainty / Development / Delivery

口诀二（挣值三组数据）：**「计成实，PVEVA C PV-计，EV-成，AC-实」**
- PV 计划值 Planned Value
- EV 挣值 Earned Value
- AC 实际成本 Actual Cost
- SV = EV - PV（进度偏差）
- CV = EV - AC（成本偏差）
- SPI = EV / PV；CPI = EV / AC

口诀三（挣值结果判定）：**「进一退一，进一退百」**
SPI > 1 进度提前；SPI < 1 进度落后；CPI > 1 成本节约；CPI < 1 成本超支。
SPI=CPI=1 为完美正方形基准。

口诀四（风险应对策略四四）：**「威逼利诱，险中求胜」**
威胁：规避、转移、减轻、接受；机会：开拓、分享、提高、接受；
新增适应策略：应对模糊性。

口诀五（PMBOK 七 vs 六）：**「七绩效六过程，五组加一纵」**
第七版 8 大绩效域 = 第六版 5 大过程组 + 49 个过程的"重组映射"；新增裁剪、价值、不确定性三主题；不再强调"瀑布式 49 过程必须全覆盖"，改为裁剪适用。
