## 今日核心概念

**主题**：项目招投标管理与合同订立 —— 政府采购方式、招标文件合规性、投标报价策略、串通投标识别与合同签订

### 1. 招标投标法律体系与政府采购方式

定义：招标投标是项目建设方（招标人）为选定承建方而依法组织的择优活动；政府采购方式是财政性资金采购货物、工程和服务时可选的五种法定途径。《招标投标法》（2017修正）、《招标投标法实施条例》（2019修订）、《政府采购法》及其实施条例、《电子招标投标办法》、《必须招标的工程项目规定》构成完整规则体系。

关键要点：
1. **五种政府采购方式**：公开招标、邀请招标、竞争性谈判（竞争性磋商）、询价、单一来源。公开招标是主要方式；达到规模标准的必须公开招标，邀请招标须经审批或认定，单一来源须公示并书面说明理由。
2. **公开招标时限**：招标公告发布期不得少于5日；招标文件发售期不得少于5日；自招标文件发出之日起至投标人提交投标文件截止**不少于20日**；投标截止至少15日前发出澄清或修改通知，不足15日的顺延截止时间。
3. **开标**：在投标截止时间的**同一时间**公开进行，地点为招标文件预先确定的地点，主持人宣布唱标。
4. **评标委员会**：人数为5人以上单数，其中技术、经济等方面专家**不少于成员总数的2/3**；评标方法为经评审的最低投标价法或综合评估法。
5. **定标与签约**：中标通知书发出之日起**30日内**订立书面合同，且不得再订立背离合同实质性内容的其他协议。
6. **法律效力层级**：招标公告、投标邀请书属于**要约邀请**；投标文件是**要约**；中标通知书是**承诺**，中标通知书发出时合同即告成立。
7. **时限红线**：投标人或其他利害关系人投诉的，一般自知道或应当知道之日起**10日内**向行政监督部门提出。

### 2. 招标文件编制合规性与否决投标情形

定义：招标文件是招标人对项目技术标准、商务条件、进度、资质、报价、评标方法的全部要求，是投标与评标的唯一依据，也是审查招标行为合法性的第一对象。

关键要点：
1. **招标文件核心构成**：投标人须知与前附表、合同主要条款、技术规格与需求说明、投标文件格式、评标标准与方法、投标截止时间、投标保证金、附件。
2. **禁止设置的限制排斥性条件**（实施条例第32条）：以特定行政区域或特定行业业绩、奖项作为加分或中标条件；设置与项目实际规模不相称的资质要求、明显超过项目特点的业绩门槛；限定所有制形式或组织形式；针对不同投标人设置差别化的技术要求；资格条件与招标项目实际不相适应。违反者责令改正；影响中标结果的**依法取消中标结果**。
3. **典型违规倾向性条款识别**：指定或变相指定品牌与产地（"须为某品牌服务器""须提供某厂商原厂授权"）、限定本地注册或本地服务机构、要求与项目无关的行业协会认证、设定只有一家能满足的业绩数量。
4. **投标保证金**：不得超过招标项目估算价的**2%**，有效期应与投标有效期一致；履约保证金不得超过中标合同金额的**10%**。
5. **常见否决投标（废标）情形**：投标文件未按要求盖章或无法定代表人授权；投标人资格不符合；投标报价低于成本或高于最高投标限价；未按要求提交投标保证金；同一投标人提交两个以上不同的投标文件或报价且未声明备选；项目负责人存在在建项目或投标争议；投标文件有实质性响应缺陷；弄虚作假、串通投标。
6. **招标文件澄清与修改**：须书面通知所有已获取招标文件的潜在投标人，内容属于招标文件组成部分；澄清修改内容影响投标文件编制的，应顺延投标截止时间。

### 3. 投标报价策略与联合体投标

定义：投标报价策略是承包方基于成本测算、竞争态势与招标文件要求，对报价水平、报价结构、支付条款和风险分配所作的整体谋划。

关键要点：
1. **报价基本原则**：依据招标文件、掌握实际成本、考虑风险、留有合理利润、符合竞争策略；报价不得低于成本，不得高于最高投标限价。
2. **不平衡报价法**：对工程量可能增加的项目适当报高、可能减少的适当报低；对早期施工项目报价偏高以提前回款，后期项目偏低；招标人不同意时须按要求调整。它能改善现金流与资金效益，但**过分偏离成本或被认定为不平衡报价的，可能被否决投标**。
3. **寿命期费用法（全寿命周期成本）**：将建设成本与运行维护、升级改造、能耗等费用一并折算比较，在满足性能的前提下选择总拥有成本最低方案；适用于政务云、机房、机电等长周期运营类项目。
4. **其他报价方法**：成本加成法（成本加合理利润）、多方案报价法（招标范围不明确时提出若干可选方案并分别报价）、按招标人不同要求分别报价（正式报价、可选择报价、单独报价）。
5. **联合体投标要点**：两个以上法人或其他组织可联合投标，须签订**共同投标协议**，明确各方拟承担的工作和责任，并将协议连同投标文件一并提交招标人；各方均须具备相应资格条件，联合体资格以**各方资格条件的综合**确定；联合体各方对招标人承担**连带责任**。联合体协议不得再转包，且联合体成员数量受限。
6. **投标风险清单**：漏项（漏报项目清单项、暂列金、措施费）、技术规范理解偏差、低价低于成本、投标保证金被没收、废标、中标后履约违约赔偿、原材料与人工价格波动、汇率与政策变化。

### 4. 串通投标（围标陪标）识别与法律后果

定义：串通投标是指投标人与招标人、评标委员会成员、其他投标人之间相互串通，损害招标投标公平竞争的行为，是招投标领域最严重的违法形态之一。

关键要点：
1. **法定串通情形**：投标人与招标人串通投标；不同投标人相互串通投标报价；投标人与招标人串通后相互约定中标人；投标人为招标人或者评标委员会成员提供财物、借款、担保等；投标人泄露标底；不同投标人的投标文件由同一单位或个人编制；不同投标人的投标保证金从同一单位或个人的账户转出；不同投标人授权同一单位或个人办理投标事宜。
2. **实务识别特征**：投标文件制作特征雷同（错误点相同、格式完全一致、同一作者）；报价呈规律性阶梯且首尾呼应；投标文件中的"暗标"标识异常；投标时间集中于同一秒；保证金同源；投标人之间存在股权、人员、地址、邮箱、电话关联；陪标方常报接近最高限价或明显偏离市场价的异常低价。
3. **法律后果**：中标无效，招标投标无效；没收投标保证金；处以中标项目金额千分之五以上千分之十以下罚款；取消投标资格；记入不良行为记录；情节严重的追究刑事责任（《刑法》第二百二十三条）。
4. **实务识别意义**：招标人一方发现疑似围标应首先**暂缓定标、保留投标文件原始载体与时间戳证据**，固定证据后再向行政监督部门报告；不得自行宣布废标后重新招标而不留痕。

### 5. 合同签订与合同档案管理

定义：合同签订是把中标结果法律化的行为；合同档案管理是对合同文本及其履约过程证据文件的归集、保管与检索，是项目结算、审计与争议维权的基础。

关键要点：
1. **合同成立与生效**：中标通知书发出时合同成立，双方按期签订书面合同；合同自双方签字盖章之日起生效，法律另有规定或附生效条件的从其规定。
2. **合同文件组成与份数**：合同协议书、中标通知书、投标函及附录、专用合同条款、通用合同条款、技术规范与图纸、已标价工程量清单、其他文件；一般一式肆份，甲乙双方各执贰份，具有同等法律效力。
3. **保证与担保**：履约保证金不超过中标合同金额的10%；建设工程质量保证金一般不超过结算总价的**3%**，缺陷责任期一般1年、最长不超过2年。
4. **档案管理要求**：合同正本、副本编号唯一并由专人保管；电子合同与纸质合同同等效力；变更单、签证单、验收单、结算书、往来函件作为合同档案组成部分一并归档；建立合同台账与履约状态台账，实现到期提醒与风险预警。
5. **争议解决条款风险**：必须**在诉讼与仲裁中二选一**，同时约定"既可诉讼又可仲裁"或"既可向法院起诉又可提交仲裁"属于约定不明，可能导致条款无效并回转到法定管辖；管辖法院或仲裁机构约定应明确唯一，且不得违反级别管辖和专属管辖规定。
6. **违约金与定金规则**：定金数额不得超过主合同标的额的**20%**；违约金过分高于损失的（一般以超过损失30%为界）可请求人民法院或仲裁机构予以适当减少；定金与违约金不能同时主张，只能择一适用。

## 案例分析题

**题目**：

某市政务云服务平台扩容及三年运维服务项目进行公开招标，预算980万元，全部使用财政性资金。招标文件中设置如下条款：投标人须具备CMMI5级认证，须拥有本省政务云成功案例不少于两个，须在本地设有服务机构并提供本地化运维响应承诺。

甲、乙、丙三家公司参与投标。投标文件显示：三家的技术方案章节排版格式完全一致，报价表第7行均出现同一处小数点错位（将19.8万元写为1.98万元），三家的报价分别为980万元、985万元、982万元，且均高于最高投标限价。中标结果公示期间，投标人丁向行政监督部门提出投诉，称三份标书存在雷同。

中标后，招标人与中标人另行签订《补充协议》，约定"本合同总价在原中标金额基础上上浮3%，其余条款不变"。合同第37条约定"因本合同发生的争议，乙方可向甲方所在地人民法院起诉，也可以提交甲方所在地仲裁委员会仲裁"。

问题：
1. 该项目招标文件中存在哪些违规条款？应承担什么后果？
2. 该次招标投标是否构成有效投标？招标人应如何处置？
3. 《补充协议》的效力如何？为什么？
4. 合同第37条的约定存在什么问题？应如何修改？

**参考答案**：

1. **违规条款及后果**
   - "须拥有本省政务云成功案例"属于以特定行政区域的业绩作为中标条件，违反《招标投标法实施条例》第三十二条，构成限制、排斥潜在投标人。
   - "须在本地设有服务机构并提供本地化响应"属于对投标人组织形式和经营地址设置差别化条件，同样属于限制排斥。
   - "须具备CMMI5级认证"若与项目实际规模、技术要求不相适应，属于设定与项目实际不符的资质门槛；若该项目不属于依法必须招标的机电、基建类项目，将CMMI5作为强制资格条件的依据不足。
   - 后果：责令改正；改正前不得继续招标投标；影响中标结果的，依法取消中标结果；情节严重的，对单位及直接责任人给予行政处罚。

2. **投标有效性与处置**
   - 三家投标报价均高于最高投标限价，属于报价不符合招标文件实质性要求，**投标文件应被否决**（废标）。
   - 投标文件格式、错漏完全一致且报价呈规律性分布，加上保证金同源等疑点，符合串通投标的法定情形特征，应认定为**串通投标**，本次投标无效。
   - 招标人处置：立即暂停定标与合同履行，**书面报告行政监督部门**并接受调查；固定证据（投标文件原始文件、加密标书时间戳、制作设备与IP记录、保证金转账凭证）；配合查处，对相关投标人没收投标保证金并提请行政处罚；依法重新招标或依法确定其他投标人，公开处理结论。
   - 投诉处理：行政监督部门应在受理后**20日内**作出书面处理决定；投诉成立的，应暂停招标投标活动。

3. **补充协议效力**
   - 无效或应予调整。《招标投标法》第四十六条明确规定，招标人和中标人不得再行订立背离合同实质性内容的其他协议；招标人不得改变中标结果。
   - 上浮3%总价直接改变合同价款这一实质性条款，属于"背离合同实质性内容"，该补充协议无效，对双方不产生约束力。
   - 正确做法：仍应按中标通知书和投标报价确定的金额980万元（或经复核后的中标价）履行合同；确需调整的，只能通过**合同变更程序**在原合同价款范围内依法进行，并履行变更审批、备案程序。

4. **争议解决条款问题**
   - 同时约定诉讼和仲裁，约定不明确，可能导致该条款无效，回退到法定管辖，给当事人带来程序不确定与额外成本。
   - 修改方式：二选一并写明唯一管辖机构——"向甲方所在地人民法院提起诉讼"，或"提交××仲裁委员会仲裁"，同时写明具体仲裁委员会全称、仲裁地、适用的仲裁规则；涉及不动产、建设工程施工合同专属管辖的，不得违反专属管辖规定。

**踩分要点**：

- 第1问必须**逐条对应**：行政区域业绩 → 实施条例第32条"以特定行政区域的业绩或奖项作为加分、中标条件"；本地服务机构 → 限制经营地址与组织形式；资质不相适应 → 第32条"资格条件与招标项目实际不相适应"。落点术语写全可得分。
- 第2问两个采分点缺一不可：**报价超最高投标限价 → 否决投标**；**标书雷同+报价规律 → 串通投标 → 投标无效**。只答"废标"不答"串通"会丢分。处置措施要写"暂停定标、书面报告行政监督部门、固定证据"。
- 第3问核心得分点是**第四十六条"不得订立背离合同实质性内容的其他协议"**，并结合"总价属实质性内容"展开，最后落到"按中标价履约、变更须走变更程序"。
- 第4问核心得分点是**诉讼与仲裁不得并用、必须二选一、约定不明条款可能无效**，并要给出具体可行的修改表述。
- 全题通用得分点：涉及数字记忆点必须写准——**20日（发招标文件至截止）、15日（澄清顺延）、30日（签约、投诉处理决定）、10日（投诉期限）、2%（投标保证金）、10%（履约保证金）、3%（质量保证金）、5人以上单数且专家不少于2/3**。
- 有观点分：不要停留在"招标程序违法"的定性上，要写出**实务处置动作**（暂停、报告、举证、固定证据、重新组织招标），这是集成项目管理工程师岗位能力的直接体现。

## 记忆口诀

**招标时限口诀：五五二十三十一**

- 招标公告与文件发售：各**5**日
- 文件发出至投标截止：**20**日
- 澄清修改至少提前**15**日（不足顺延）
- 中标后签约**30**日、投诉处理决定**30**日
- 投诉提出**10**日内

**评标与保证金口诀：五评委二三分之一，金二履十质三**

- 评标委员会**5**人以上**单数**，专家不少于成员总数**2/3**
- 投标保证金不超过估算价**2%**
- 履约保证金不超过中标合同金额**10%**
- 质量保证金不超过结算总价**3%**

**禁止条款口诀：区域业绩、本地机构、范围资质三不得**

- 不得以特定行政区域业绩、奖项作为加分或中标条件
- 不得限定本地服务机构、所有制与经营地址
- 不得设置与项目规模不相称的资质和业绩门槛

**串通投标六不得口诀：同文件、同保证金、同机构、同时间、同账户、同授权**

- 同一单位或个人编制多份标书
- 保证金同一单位或个人账户转出
- 同一单位或个人授权办理多标投标
- 标底泄露、约定中标人、串通报价
- 后果：中标无效、罚没保证金、罚款、取消资格、可能追刑责

**合同签订口诀：通知即成立，三十日内签；不得另立背离实质性内容的协议；诉仲二选一，定金不超二成**

- 中标通知书发出时合同成立，30日内签订书面合同
- 不得再订背离合同实质性内容的其他协议
- 诉讼与仲裁必须二选一，约定唯一
- 定金不超过主合同标的额20%，与违约金不得并用
