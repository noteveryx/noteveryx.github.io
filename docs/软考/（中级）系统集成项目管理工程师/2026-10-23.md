## 今日核心概念

### 1. 项目成本管理的核心框架

**项目成本管理 = 在批准的预算内完成项目，同时确保成本节约不损害项目范围、进度、质量。**

核心工具链：**成本估算 → 成本预算 → 成本控制**

**成本类型三分类（必背）**：

| 分类依据 | 类型 | 能否追加预算 |
|---|---|---|
| **与项目工作量的关系** | 不变成本（固定）、可变成本 | **不变成本不能追加**，只能通过提高效率降本 |
| **可追溯性** | 直接成本、可间接成本 | 间接成本分摊到直接成本上 |
| **可控性** | 可控成本、不可控成本 | 不可控成本只监测不控制 |

**关键认知**：估算成本时最容易漏的是**管理储备**与**应急储备**，两者都属于项目总成本，但只有应急储备计入成本基准。

### 2. 三阶段成本估算方法

| 方法 | 属于 | 优点 | 缺点 | 适用阶段 |
|---|---|---|---|---|
| **类比估算（参数模型）** | 粗略 | 快、便宜 | 历史相似性要求高，准确性 −25%~-50% | 立项/粗略估算 |
| **自下而上估算（WBS）** | 详细 | 准确、可控 | 耗时、易受工时估算偏差与遗漏影响 | 详细计划阶段 |
| **参数估算** | 详细 | 基于统计关系（如每平米造价） | 需要可靠历史数据库 | 有数据积累时 |
| **三点估算（PERT）** | 详细 | 体现不确定性 | 需三点值 | 风险较高活动 |
| **数据分析和储备分析** | 详细 | 科学 | 需充分数据 | 有数据时 |
| **决策分析** | 详细 | 风险与不确定性高时 | 复杂 | 投标/重大决策 |
| **质量成本（COQ）** | 贯穿 | 平衡质量投入 | — | 全生命周期 |

**自下而上的黄金公式**：

```
项目总成本 = Σ(各工作包成本) + Σ(各活动成本)
          = 各项估算 + 应急储备（Contingency，"已知未知"）
          + 管理储备（Management Reserve，"未知未知"）
```

**应急储备**：**已识别的风险**的应对预算，**包含在成本基准内**，用于项目经理控制。
**管理储备**：**未识别风险**的应对预算，**不包含在成本基准内**，需高层审批才能动用。

### 3. 挣值分析（EVM）核心公式与五种 EAC

#### 3.1 三大基本参数

- **PV（计划价值 Planned Value）**：到某时点**计划要完成**的工作的预算价值
- **EV（挣值 Earned Value）**：到某时点**实际完成**的工作的预算价值
- **AC（实际成本 Actual Cost）**：到某时点**实际花费**的金额

**关键理解**：EV 用"预算单价"而不是"实际单价"计算已完成工作的价值——**这样才能把"花了多少钱"和"干了多少活"分开看**。

#### 3.2 两大偏差与两大指数

| 指标 | 公式 | 含义 | 判读 |
|---|---|---|---|
| **SV** | EV − PV | 进度偏差 | < 0 落后 |
| **CV** | EV − AC | 成本偏差 | < 0 超支 |
| **SPI** | EV / PV | 进度绩效指数 | < 1 落后 |
| **CPI** | EV / AC | 成本绩效指数 | < 1 超支 |

**关键认知**：
- **偏差（SV/CV）是绝对值，看"差了多少"；指数（SPI/CPI）是比率，看"差得有多严重"**
- **CPI 与 SPI 会"互相影响"**：进度落后会导致成本超支（加人加班赶工）；成本超支也可能是"提前做了用成本更高的方案"
- **SV ≠ 延迟天数**：SV 不能直接换算成工期延误，需要配合网络图与关键路径分析

#### 3.3 EAC 的五种估算方法（高频考点）

| 公式 | 适用场景 | 假设 |
|---|---|---|
| **EAC = BAC / CPI** | 当前偏差是**偏差性的**（可纠正） | 后续按当前效率继续 |
| **EAC = AC + (BAC − EV)** | 当前进度是**独立的**（如进度领先但成本超支） | 剩余工作按原预算单价 |
| **EAC = AC + (BAC − EV) / CPI** | 同时存在进度与成本偏差，且**偏差是综合性的** | 剩余按当前综合效率 |
| **EAC = AC + ETC** | 已知剩余工作的估算 | 直接给出 |
| **EAC = AC + (BAC − EV) + 剩余风险储备** | 需计入剩余应急储备 | — |

**选哪个的判断逻辑**：
- 只成本超支、进度正常 → **AC + (BAC − EV)**
- 只进度落后、成本正常 → **BAC / CPI**（其实 CPI≈1 时即为 BAC）
- 进度成本都偏差且相互关联 → **AC + (BAC − EV)/CPI**
- 偏差将要纠正（如已批准追加预算、已安排赶工）→ 仍用 BAC/CPI

### 4. 完工尚需绩效（TCPI）

**TCPI = (BAC − EV) / (BAC − AC) = 剩余预算 / 剩余成本**

- **计算方式**：用**成本**做分母 → 得到 TCPI（成本）
- **用工期做分母** → 得到 TCPI（工期），需先算出 EAC

**决策规则（重要考点）**：

| 情形 | 判断 | 含义 |
|---|---|---|
| TCPI > 1 | 剩余工作**还留有余地** | 可接受，有缓冲 |
| TCPI = 1 | **刚好够用** | 临界，需重点关注 |
| TCPI < 1 | **已经超支，必须用更少的钱做完剩余工作** | 不可行，需立即纠偏 |

**注意**：**BAC−AC 为负数时（即已超支到超过程序总额），TCPI 无法正常计算**，此时应判断**项目是否还有继续的价值**——这是"止损"决策的信号，不是继续算 TCPI 的场景。

### 5. 挣值与其他挣值变体

- **PV（计划价值）**、**EV（挣值）**、**AC** 构成 EVM 三参数
- **ETC（完工尚需估算）**：完成剩余工作所需的成本
- **BAC（完工预算）**：全部工作的预算成本
- **VAC（完工偏差）**：BAC − EAC（正数=节省，负数=超支）
- **TCPI**：见上

**扩展概念**：
- **挣值曲线（EVM 曲线）**：PV、EV、AC 三条曲线的相对位置反映项目健康度
- **典型偏差类型**：**只有 AC 翘头（成本超支）** → 效率问题；**只有 SV 落后（进度落后但成本正常）** → 效率尚可；**SV+CV 同时恶化** → 双重问题，最危险
- **挣值与质量的关系**：CPI < 1 且 SPI < 1 同时出现，**往往暗示质量问题被忽略**（赶工导致返工）

## 三个常考陷阱

### 陷阱一：EV 用实际成本计算

**错。** EV 用"**预算单价 × 实际完成量**"。用实际成本算 EV，会把"花得多"和"做得多"混在一起，失去偏差诊断能力。

**正确定义**：`EV = 实际完成工作量 × 预算单价`

### 陷阱二：把 SV 直接换算为工期延误天数

**SV 是"预算金额的偏差"，不是"时间的偏差"。** 一个价值 100 万的活动 SV = −20 万，不代表延迟 20 天（取决于该活动的预算单价）。

**正确做法**：用网络图找出**关键路径上偏差最大的活动**，用活动的工期与进度数据计算实际工期偏差。

### 陷阱三：把应急储备和管理储备混淆

| 项目 | 应急储备 | 管理储备 |
|---|---|---|
| 应对 | 已识别风险 | 未识别风险 |
| 是否在成本基准内 | **是** | **否** |
| 谁控制 | 项目经理 | **高层管理者** |
| 动用程序 | 直接使用 | 需高层批准 |

**最常见的错误是把两者都算进成本基准**——会导致成本基准虚高，挣值分析失去意义。

## 案例分析题

### 案例 1 — 挣值分析的纠偏决策

**题干**：某市政务云平台建设项目，合同金额（不含税）8000 万元，工期 24 个月。项目管理办公室（PMO）在第 18 个月末进行挣值分析，数据如下：

- PV（PV18）= 6000 万元
- EV（EV18）= 4800 万元
- AC（AC18）= 5400 万元
- 预计剩余 6 个月的工作可按 BAC 中剩余 2000 万元预算完成，但分析发现云厂商的存储与流量费用大幅上涨，剩余工作的实际成本预计需 2300 万元。

**问题**：
1. 计算 SV、CV、SPI、CPI，并分析项目健康状况。
2. 若项目经理认为剩余工作能在原预算 2000 万元内完成，计算 TCPI（成本）并判断可行性。
3. 若项目经理认为剩余工作需 2300 万元，项目总完工预测是多少？此时 TCPI 说明什么？
4. 该项目剩余仅 6 个月但进度已严重落后，项目经理应采取哪些纠偏措施？请按优先级排序。

**参考答案**：

**问题 1 — 偏差计算与健康诊断**：

| 指标 | 计算 | 结果 | 判读 |
|---|---|---|---|
| SV | EV − PV = 4800 − 6000 | **−1200 万元** | 进度**严重落后** |
| CV | EV − AC = 4800 − 5400 | **−600 万元** | 成本**超支** |
| SPI | EV / PV = 4800 / 6000 | **0.80** | 完成 80% 计划工作量 |
| CPI | EV / AC = 4800 / 5400 | **0.889** | 花钱效率为 89% |

**健康状况诊断：SV < 0 且 CV < 0，SPI = 0.80 < 1，CPI = 0.889 < 1，项目"进度落后 + 成本超支"双重恶化，属于最不利的情形。**

**进一步分析**：
- 计划进度：18 个月应完成 6000/8000 = **75%**，实际完成 4800/8000 = **60%**，**落后 15 个百分点**
- 按此进度，若不加干预，完工时将远超 24 个月
- CPI = 0.889 意味着每花 1 元只创造了 0.889 元的预算价值，**超支 12.5%**
- **双重恶化往往暗示质量隐患**：赶工导致的返工、需求蔓延带来的边做边改、或技术方案选择失误

**问题 2 — TCPI（成本）与可行性**：

```
TCPI = (BAC − EV) / (BAC − AC)
     = (8000 − 4800) / (8000 − 5400)
     = 3200 / 2600
     ≈ 1.23
```

**判断：TCPI = 1.23 > 1，说明剩余 3200 万元的预算（剩余工作量）还有 23% 的成本余量，可以接受。**

**但必须附加两个重要提醒**：
1. **TCPI > 1 不代表项目健康**。它只说明"剩余预算对剩余工作够用"，**不改变已发生的 600 万超支**。
2. 剩余工期只有 6 个月（完成剩余 40% 工作量），**关键路径是否允许**？若关键路径上必须串行的活动需 8 个月，**再多的预算也无用**——**需要同时做工期可行性分析**。

**问题 3 — 完工预测与 TCPI**：

```
EAC = AC + ETC = 5400 + 2300 = 7700 万元
VAC = BAC − EAC = 8000 − 7700 = +300 万元（预计节余）
```

```
TCPI = (BAC − EV) / (BAC − AC) = 3200 / (8000 − 7700) = 3200 / 300 = 10.67
```

**TCPI = 10.67 意味着什么**：要让剩余工作只花 300 万元完成，**每花 1 元要完成 10.67 元预算价值**，而目前效率是 0.889 元/元——**需要效率提升 12 倍**。

**结论：不可行。此时正确的做法不是继续压缩效率，而是：**
1. **确认 EAC 估算的可靠性**（ETC 2300 万元是否有依据，是否过于乐观）
2. **判断项目继续的价值**：剩余工作是否值得投入
3. **启动纠偏或范围变更**：申请追加预算、削减范围、或调整验收标准
4. **若既不能追加预算也不能减范围，须评估终止项目的沉没成本**

**问题 4 — 纠偏措施（按优先级）**：

**第一优先级：立即控制进一步损失（止血）**
1. **冻结非必要支出**：暂停可选的优化项、非关键采购、扩容等非必需支出
2. **成本全面复核（Estimate at Completion 审计）**：核实 ETC = 2300 万元的估算依据，是否遗漏了已知风险；识别剩余工作中的"隐性范围蔓延"
3. **剩余工作重新做 WBS 与成本估算**：把剩余 40% 的工作重新拆解并重新估算，找出成本超支的根因（是技术方案、是范围、是估算误差还是效率问题）

**第二优先级：恢复进度（追赶）**
4. **快速跟进（Fast Tracking）**：把原本串行的活动改为部分并行。**注意：前提是剩余工作的依赖关系允许，且不增加风险**
5. **赶工（Crashing）**：对关键路径上成本斜率最小的活动追加资源
6. **关键路径分析**：先做网络图找出关键路径，**只有关键路径上的活动压缩才有效**——非关键活动压缩不影响总工期
7. **里程碑批量处理**：若项目为分批上线，可将剩余里程碑合并、部分功能延期至后续版本

**第三优先级：结构性调整（治本）**
8. **范围变更（Scope Reduction）**：与业主协商，**将非核心功能移至下一期**。**这是进度落后 + 预算紧张时最有效的手段**，因为"砍范围"是唯一能同时缓解两个问题的动作
9. **技术方案优化**：评估是否有更经济的实现方案（如降低配置、复用已有组件），**注意不能为降本牺牲质量与合规性**（政务项目尤其要注意等保要求）
10. **风险应对**：识别剩余 6 个月的重大风险并制定应对计划（预留应急储备）

**第四优先级：组织与沟通**
11. **加强变更控制**：剩余阶段严格控制变更，任何变更必须评估其对进度与成本的双重影响，并走正式审批
12. **升级沟通**：向项目指导委员会报告真实状况，申请追加预算或范围调整的正式授权。**不可自行消化，不可隐瞒**——隐瞒只会在后期以更大代价爆发
13. **经验教训前置**：将本次偏差的根因记录入组织过程资产，用于后续同类项目估算改进

**关于优先级排序的说明**：**进度落后 + 预算紧张时，"砍范围"的优先级应高于"赶工"**——因为赶工会增加成本（与预算紧张矛盾），而砍范围同时缓解两个问题。**但砍范围必须走正式变更程序并获得业主书面批准。**

## 记忆口诀

- 口诀 1：**三成本分类**——工作量（不变/可变）、可追溯（直接/间接）、可控（可控/不可控）。
- 口诀 2：**估算六方法**——类比（粗）、自下而上（准）、参数（需数据）、三点（显风险）、数据分析、决策分析。
- 口诀 3：**总成本 = 工作包 + 应急 + 管理**——应急在基准内（PM 管），管理在基准外（高层批）。
- 口诀 4：**EV 用预算单价**——不是实际单价，这是 EVM 的核心设计。
- 口诀 5：**偏差看绝对、指数看相对**——SV/CV 是金额，SPI/CPI 是比率。
- 口诀 6：**EAC 四种情形**——偏差性→BAC/CPI；独立→AC+(BAC−EV)；综合→AC+(BAC−EV)/CPI；已知ETC→AC+ETC。
- 口诀 7：**TCPI = 剩余预算 ÷ 剩余成本**——>1 尚有余地，=1 刚好，<1 已超支。
- 口诀 8：**BAC−AC 为负时别算 TCPI**——那是止损决策的信号，不是算账的场景。
- 口诀 9：**SV 不等于延期天数**——那是金额偏差，工期看关键路径。
- 口诀 10：**双恶化最危险**——SV+CV 同时恶化往往藏着质量问题。
- 口诀 11：**只有压缩关键路径才有效**——非关键活动压缩等于白花钱。
- 口诀 12：**进度+预算双紧 → 先砍范围**——唯一同时缓解两个问题的动作，但必须书面批准。
