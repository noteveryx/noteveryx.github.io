## 今日核心概念

### 1. 线性规划与资源优化配置

定义：线性规划是运筹学中用于在**一组线性约束条件下，求线性目标函数最优解**的数学方法。在系统集成项目中，它把"人力、设备、资金、算力"等有限资源与"工期、成本、覆盖范围"等目标建立为数学模型，求出资源配置的最优组合，典型应用包括多项目资源平衡、机房扩容方案选型、投标资源投入组合优化。

关键要点：
1. **三大要素**：决策变量（选择什么，如"是否采购X设备"）、目标函数（最大化利润或最小化成本）、约束条件（预算上限、工期上限、容量上限），三者缺一不可。
2. **模型标准形式**：目标函数 `max Z = Σ c_j x_j`，约束条件 `a_ij x_j ≤ b_i`，且 `x_j ≥ 0`；解必须在**可行域（多边形的顶点）**上取得最优，这是图解法只需画顶点的原因。
3. **图解法步骤**：① 建立坐标系并标注约束线；② 判断可行域（所有约束交集）；③ 求各顶点坐标；④ 逐顶点代入目标函数比较；⑤ 选最优解并做**敏感性分析**（哪条约束最紧、松弛量最小则其资源最值钱）。
4. **松弛量与影子价格**：约束右端 `b_i` 增加一个单位引起目标函数最优值的变化量就是影子价格（对偶值），它等于该资源的"边际价值"，用于判断追加投资是否划算；松弛量为 0 的约束叫**紧约束**，是项目瓶颈。
5. **无解与多解判别**：可行域为空（约束矛盾）则无可行解；目标函数等值线与某条边平行时出现**多重最优解**，此时可叠加得出全部最优方案。
6. **项目落地要点**：现实中约束往往不满足线性（存在固定成本、规模效应），需做**整数规划**（设备不可分割、只能整台采购）与**非线性规划**处理；灵敏度分析中，若某参数变化范围过大导致结论翻转，则说明模型稳健性不足，须补充假设重新论证。

### 2. 图论与网络计划关键路径方法

定义：图论用节点（活动或事件）和边（依赖关系）刻画离散结构关系，是进度管理网络计划技术（CPM/PERT）、最短路径、最小生成树的数学基础；系统集成项目从活动排序、工期优化到机房布线、链路路由、备份链路设计，均可归结为图论问题。

关键要点：
1. **网络计划两种表示**：**箭头图（AOA/双代号）**用箭线表示活动，节点表示事件，易出现"虚活动"；**网络图（AON/单代号）**用节点表示活动，逻辑关系显式标注，更适合项目管理系统使用。
2. **关键路径判定法则**：路径总工期最长者即为关键路径；其上活动**总时差为零**，总时差大于零的为非关键活动。总时差 = 关键路径长度 − 该路径长度，自由时差 = 活动最早完成时间 − 活动最早开始时间。
3. **最短路径算法**：**迪杰斯特拉算法**适用于边权非负的单源最短路径，逐步确定距离最小的顶点；**弗洛伊德算法**求任意两点间最短路径，边权可为负。机房跨机房专线带宽成本最小化、应急调度最短路径均属此类。
4. **最小生成树**：**普里姆算法**适合稠密图、**克鲁斯卡尔算法**适合稀疏图，目标是让全网连通且总链路成本最小，用于政务专网/物联网组网方案比选。
5. **关键链法（CCM）与缓冲管理**：以关键链替代关键路径，以**项目缓冲（PB）**吸收整个项目的不确定性，**接驳缓冲（FB）**吸收"前置活动提前完成"的浪费，**任务缓冲（RB）**吸收单个活动的波动，用**八/十分之六法则（50/50规则）**监控缓冲消耗，超过 50% 触发黄色预警，超过 80% 触发红色预警。
6. **网络计划优化次序**：先压缩关键路径上的活动（赶工/快速跟进/资源平滑），再调整逻辑关系（搭接并行），最后考虑非关键活动的资源释放；任何压缩都必须重算总时差，防止关键路径发生转移。

### 3. 决策分析与期望货币价值（EMV）

定义：决策分析是在信息不完全、结果具有随机性时，选择使**期望收益最大**的方案的量化方法。核心工具是**决策树**，先判断结点类型（**决策结点**用方框、**机会结点**用圆圈、**结果结点**用三角），再**从右向左**计算各方案的期望货币价值，**从左向右**选择最优行动。

关键要点：
1. **期望货币价值**：EMV = Σ（各状态发生概率 × 该状态下的收益/损失），概率之和必须为 1；计算方向必须是**机会结点从右往左、决策结点从左往右**。
2. **后悔值法（最大后悔值最小化）**：先求每种状态在各方案中的最优收益，再求后悔值 = 该状态最优收益 − 本方案收益，取每方案的最大后悔值中的最小者，结论应与 EMV 法一致，若不一致需检查概率设置。
3. **决策树三大优点**：① 直观展示决策顺序与逻辑；② 定量计算各方案期望；③ 可在树上直接标注**机会结点**的信息价值。
4. **敏感性分析（临界值分析）**：求使结论翻转的临界参数（概率、收益、成本），是评审判卷的高频考点——常问"自研成功的概率低于多少时应改为外包"。
5. **信息价值与期望价值（EVPI）**：EVPI = 完全信息下的期望收益 − 现有信息下的最大 EMV，用于判断"是否值得花钱做市场调研/需求调研"。
6. **不确定性与风险偏好**：期望值相同但方差不同则风险不同，方差大者风险高；项目投标决策中可用**效用函数**刻画风险厌恶（效用曲线凹型表示保守，凸型表示冒险）。
7. **项目应用边界**：EMV 假设风险中性、概率可估计；概率估计不可靠时应改用**情景分析、三点估计（PERT）**或"最不利情形分析法"，避免用伪精确数字支撑决策。

### 4. 博弈论与纳什均衡

定义：博弈论研究多个决策者相互影响的策略选择问题。在项目多供方协同、数据共享、跨部门合作中，各方均追求自身利益最优，** Nash 均衡（纳什均衡）**是任何一方单独改变策略都无法改善自身收益的策略组合，是预测各方行为的基准。

关键要点：
1. **基本要素**：**参与人（玩家）**、**策略（行动）集合**、**收益（支付）矩阵**、**信息**。分析步骤：① 明确参与人与各自目标；② 列出策略组合；③ 填写支付矩阵；④ 找**占优策略**（无论对方怎么选都最优）；⑤ 无占优策略时找**纳什均衡**（标注"最佳反应"箭头）。
2. **占优策略与纳什均衡关系**：存在占优策略时，纳什均衡一定由占优策略构成；无占优策略时纳什均衡可能不唯一（多重均衡），此时制度设计重点是**选择哪个均衡**（如设置默认选项）。
3. **帕累托最优与纳什均衡未必一致**：如"囚徒困境"，纳什均衡是双方都不配合（集体次优），而双方配合才是帕累托最优，**逆向选择与道德风险**是典型的非最优均衡后果。
4. **混合策略均衡**：当无纯策略均衡时，以一定概率随机化各策略形成期望收益相等的均衡，考试中常要求计算混合策略概率。
5. **制度设计的四条路径**：① **惩罚机制**（对违约行为设置高额违约金、列入黑名单）；② **奖励机制**（按数据共享量、接口调用量付费）；③ **改变收益结构**（把单边垄断收益改为分成收益）；④ **信息对称化**（公开考核数据、引入第三方评估）。
6. **项目应用**：双源采购中的价格竞争、联合体投标中的责任分配、承建方与监理方的信息博弈、跨部门数据共享中"谁先共享谁吃亏"的典型囚徒困境，其破解关键都是**合同条款设计**而非单纯技术手段。

### 5. 概率统计与不确定性量化

定义：概率统计为项目的不确定性提供量化语言：用**分布与期望**刻画随机结果，用**方差与标准差**刻画波动，用**抽样与假设检验**从样本推断总体，用**置信区间**表达估计的不确定性。

关键要点：
1. **常见离散分布**：**二项分布 B(n,p)** 描述"n 次独立试验中成功次数"（如 5 个模块中 3 个通过测试）；**泊松分布 P(λ)** 描述单位时间内随机事件发生次数（如每小时到达的工单数、每周发现的缺陷数）。
2. **常见连续分布**：**正态分布 N(μ,σ²)** 用于大量独立微小因素叠加的场景（工期、成本），其 **3σ 原则**——约 68.3% 落在 μ±σ 内、95.4% 落在 μ±2σ 内、99.7% 落在 μ±3σ 内，是给出工期区间（如"最可能工期 T，区间 T±3σ"）的理论依据。
3. **期望与方差**：E(X) = Σ x_i p_i，Var(X) = Σ (x_i − E(X))² p_i；独立随机变量方差可加（Var(X+Y)=Var(X)+Var(Y)），这是 PERT 公式 `T = (O + 4M + P)/6` 与 `σ² = ((P−O)/6)²` 的来源。
4. **标准差与风险**：方差越大波动越大；**变异系数 CV = σ/期望值** 用于比较不同量纲方案的风险水平，是项目健康度评估的常用指标。
5. **抽样与估计**：大样本情形下样本均值近似服从正态分布；**置信区间**表述为"在 95% 置信水平下总体均值落在 [L, U]"，区间越宽表示估计越不确定，对应到项目即"调研样本不足以支撑结论"。
6. **假设检验思想**：先设原假设 H₀（小概率事件），若统计量落在拒绝域则否定 H₀；对应项目质量检验即"抽检不合格则判整批不合格"，以及缺陷率显著性检验。
7. **实战注意**：正态分布要求样本量足够且无严重偏态，小样本用 t 分布；项目数据常有偏态（工期长尾），此时用**对数正态**或**蒙特卡洛模拟**更稳妥。

## 案例分析题

**题目**：

某市拟建设"城市数据中台"项目，包含数据汇聚、治理、共享服务三大模块。建设单位在技术路线上存在两种可选方案：

- **方案甲（完全自研）**：前期研发投入 80 万元，研发成功概率 0.6；成功后预计可形成可复用产品，市场收益 300 万元，可支撑全市 12 个区县复制推广；失败则 80 万元投入全部沉没，无收益，但不影响后续转外包。
- **方案乙（核心组件外购 + 集成）**：授权采购与集成投入 50 万元，采用成熟组件，成功概率 0.9；成功后预计收益 150 万元；失败概率 0.1，失败时同样损失全部投入。

同时，供应商选择环节出现博弈：市大数据局将数据中台的第三方运维分包给甲、乙两家集成商，双方均面临"是否主动向对方共享本方数据接口与运维知识"的选择。支付矩阵如下（单位：万元，代表各自收益）：

| 甲 \ 乙 | 共享 | 不共享 |
| --- | --- | --- |
| **共享** | 8，8 | -4，14 |
| **不共享** | 14，-4 | 0，0 |

问题：
1. 请用决策树/期望货币价值法分别计算方案甲、方案乙的期望货币价值，并给出推荐方案。
2. 计算方案甲被选中的**临界成功概率**，并说明该结论的敏感性含义。
3. 对甲乙双方的"共享/不共享"博弈进行分析，指出是否存在纳什均衡，该均衡是否为帕累托最优，并给出至少两条破解当前博弈格局的合同或制度措施。
4. 结合进度网络计划与图论知识，说明该项目在工期紧张时应优先采用的关键路径管理手段，并指出"进度压缩"后必须重新计算的指标。

**参考答案**：

**第1问：期望货币价值计算**

- 方案甲：EMV(甲) = 0.6 × 300 + 0.4 × (−80) = 180 − 32 = **148 万元**
- 方案乙：EMV(乙) = 0.9 × 150 + 0.1 × (−50) = 135 − 5 = **130 万元**
- 结论：方案甲期望货币价值更高（148 > 130），推荐采用**方案甲（完全自研）**。但需提示：方案甲方差大、风险高，若建设单位风险偏好保守，应结合敏感性分析与承受能力再决策。

**第2问：临界概率（敏感性分析）**

设方案甲的成功概率为 p，与方案乙的 EMV 130 万元相等：
p × 300 + (1 − p) × (−80) = 130
320p − 80 = 130 → p = 210 / 320 = **0.656**

即：当方案甲成功概率 **高于 65.6%** 时选择甲；**低于 65.6%** 时应改选乙（当前估计 0.6 < 0.656，说明按现有概率估计结论本身就应偏向方案乙——这一点正是敏感性分析的价值：它提示原先"推荐甲"的结论并不稳健，仅比临界点低 5.6 个百分点）。

工程化表述：若通过需求调研、技术预研、专家评审把自研成功概率由 0.6 提升到 0.66 以上，则方案甲由不优转优，这构成一次有价值的投资决策；反之，若概率无法提升，则应选择方案乙。

**第3问：博弈分析**

- **占优策略检验**：对甲而言，无论乙选"共享"还是"不共享"，甲选"共享"得 8，选"不共享"得 14 或 0，故"不共享"对甲是**占优策略**；对乙同理，"不共享"也是占优策略。
- **纳什均衡**：占优策略组合 **(不共享，不共享)**，收益为 (0, 0)，是**唯一的纳什均衡**。此时任何一方单独改为"共享"，收益都从 0 降为 −4，均无法改善，符合纳什均衡定义。
- **帕累托最优检验**：**(共享，共享) = (8, 8)** 明显优于 (0, 0)，存在帕累托改进空间，因此 (不共享, 不共享) 是**纳什均衡但不是帕累托最优**，属于典型的**囚徒困境**：各方理性选择导致集体次优。
- **破解措施（至少两条）**：
  1. **改变收益结构/分成机制**：将运维收益由"各自承接项目"改为按共享接口调用量与实际复用成果分成，把单边独占收益转化为共同增量收益，消除"谁先共享谁吃亏"的动因。
  2. **建立惩罚机制**：在合同中约定接口共享里程碑（如首月开放率不低于 60%），未达标方扣减服务费 10%~15%，连续两月不达标终止分包并列入供应商黑名单。
  3. **信息对称与第三方评估**：由建设单位或监理单位建立月度共享绩效公示看板，公开双方共享进度与接口调用数据，降低信息不对称，使博弈从不完全信息转向可观测。
  4. **首期先行+对等条款**：约定任一方未按期共享，另一方有权暂缓自身开放并获得工期与费用补偿（对等触发），打破非对称状态。
  5. **长期合作与联合收益**：以 2~3 年框架合同绑定，将单次博弈转化为重复博弈，重复博弈下"不共享"的长期收益小于"共享"的长期收益。

**第4问：进度与图论应用**

1. **优先采用关键路径管理**：以单代号网络图（AON）绘制三大模块 WBS 逻辑关系，识别关键路径，对关键路径上的活动集中资源保障；用**总时差**判定哪些活动可作为资源调剂的"缓冲池"。
2. **进度压缩次序**：① 赶工（增加优质人员/加班/双倍投入，代价是成本与质量风险上升）；② 快速跟进（将串行的设计编码改为搭接并行，风险是返工概率增加，须在质量计划中预留评审点）；③ 资源平滑（在不改变关键路径的前提下，把非关键活动的资源挪用到关键路径）。三者均只对关键路径有效。
4. **重算指标**：压缩后必须重新计算**各活动的最早/最迟时间、总时差与自由时差、新的关键路径与项目总工期**，并复核**成本基准与预算**、更新**进度基准与进度网络图**、重新做**风险登记册**（压缩带来返工、质量下降、成本上升等新风险）与**资源平衡计划**。特别提示：关键路径可能发生**转移**，压缩原关键路径后若产生新的关键路径，必须对新关键路径再次评估压缩可行性，否则会出现"压缩了却没缩短工期"的假象。
5. 可采用**关键链法**：对项目整体设置项目缓冲（PB）、对存在依赖关系的任务间设置接驳缓冲（FB）、对高波动任务设置任务缓冲（RB），按 50/50 法则监控缓冲消耗（消耗超 50% 黄色预警、超 80% 红色预警）。

**踩分要点**：

1. **EMV 计算必须带过程分**：概率 × 结果逐项列出、最终求和、给出比较结论，三者缺一扣分；注意"失败"状态的收益写 **−投入成本**（沉没成本全额损失），写成 0 是最常见的丢分点。
2. **临界概率是必考变形**：必须体现"由 EV(甲)=EV(乙) 解出 p"，并给出**双向结论**（高于临界值选甲、低于则选乙），只写一个数字不写判别规则只能得一半分。
3. **博弈分析四要素**：占优策略判定、纳什均衡（含收益）、帕累托最优对比、至少两条具体措施。只答"存在纳什均衡(不共享,不共享)"而无占优策略与帕累托分析，案例分只能拿一半。
4. **措施必须落到合同/制度层面**：写成"加强沟通、加强管理"不得分；必须出现可执行条款（里程碑、扣罚比例、公示、暂缓权、框架合同期限等）。题干是政务项目，答"数据接口、运维知识、共享率、考核"等政务场景要素更贴题。
5. **第4问陷阱**：不能只答"要压缩关键路径"，必须写出**重算总时差/自由时差、新关键路径与关键路径转移风险**；另外常错点是漏答"压缩后成本基准与进度基准需同步更新、需走变更流程"。
6. **格式与表述**：分问作答、每问先给结论再给推导，计算式与单位（万元）写全，措施条理化编号（①②③），便于阅卷人踩点给分。

## 记忆口诀

1. **决策树口诀**：决策树是"右算左选"——机会结点从右往左算期望，决策结点从左往右选最大；方框决策、圆圈机会、三角结果，三种形状别记混。
2. **敏感性口诀**："临界概率解方程，甲乙相等为分界；高则选甲低则选乙，稳健性看偏离多远。"
3. **占优与均衡口诀**："占优策略人人有，均衡未必人人优；一方改手若变差，此格即为纳什解。"——"一方改手若变差"就是纳什均衡的判定口诀。
4. **囚徒困境破解口诀**："改收益、加惩罚、晒数据、绑长约"，四句话对应四条制度路径。
5. **线性规划口诀**："定变量、写目标、配约束、画可行域；顶点取优、影子定价、松弛为零是瓶颈。"——"可行域顶点取最优"是图解法得分口诀。
6. **网络计划口诀**："长路径是关键、零时差是瓶颈；单双代号两套图，压缩只压关键线。"——"压缩只压关键线"是第4问的核心得分点。
7. **时差口诀**："总时差管不影响总工期，自由时差管不影响紧后活动"，两者不可混答。
8. **关键链口诀**："项目缓冲、接驳缓冲、任务缓冲；50/50 黄，80/80 红。"
9. **概率分布口诀**："二项看次数、泊松看频次、正态看叠加；3σ 六八九五九九七，工期区间靠它。"
10. **PERT 口诀**："三点估算 O 四 M 加 P 除六"，方差是"极差除六再平方"；期望值与方差口诀合并使用："期望决定大小，方差决定风险。"
11. **进度压缩口诀**："赶工加钱、快跟进叠、缓平滑移"，三法顺序记：先赶工、再快跟进、后资源平滑，且"只压关键路径，压缩后重算时差与新关键路径"。
12. **全篇收口口诀**："EV 算期望、博弈找均衡、图论抓关键、约束定资源、概率控风险"，五句话对应本篇五个概念，串联复习不迷路。
