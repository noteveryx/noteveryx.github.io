# （中级）系统集成项目管理工程师 · 第78次学习（2026-11-25）

**主题**：数据中心机房基础设施工程 —— 机房分级与业务匹配、供配电冗余与容量计算、制冷与气流组织、能效与绿色数据中心、动环监控与工程验收实测

**定位说明**：本篇从"设计—建设—验收"视角切入机房工程，与第73次（2026-11-18）"运行维护视角"的物理环境运维形成互补；本题域在本科目历史中为零覆盖专篇。

## 今日核心概念

### 1. 数据中心机房分级（A、B、C 级）与业务重要性匹配

定义：机房分级是依据电子信息设备所承载业务的重要程度与系统重要性等级，对数据中心在供电、空调、消防、安防、监控等基础设施上的可靠性要求进行分档的机制。现行规范体系（以《数据中心设计规范》GB 50174 及配套的供配电、空调系统分级要求为准）将数据中心分为三级：

- A 级（最高）：面向"不允许中断"的核心重要业务与关键主设备，基础设施须具备最高的冗余水平——双路独立市电、备用电源（柴油发电机组）、高冗余供配电与制冷、完善的监控与自控
- B 级（中等）：面向"允许短时中断但需保障重要业务"的重要业务，供电与制冷具备冗余但冗余度低于 A 级
- C 级（一般）：面向一般业务与辅助场地，以满足基本运行与安全为底线，不作高冗余要求

关键要点：
- 分级判定的**唯一依据是"业务重要性 + 系统重要性等级 + 允许中断时间（RTO）"，不是预算、不是已建楼房的现状**。常见错误是"先定投资再倒推机房等级"
- 分级判定必须形成书面结论并经建设单位确认：**业务系统清单 → 每个系统对应机房等级 → 每个系统对应的 RTO/RPO → 机房分级结论**，四个环节缺一不可
- 机房等级是**综合体等级，不是单项设备等级**。同一机房内可分区承载不同等级业务，但必须在供配电、制冷、通道、消防上做物理或逻辑隔离，不得"低等级设备挂在高等级供电上却共享低等级空调"
- A 级机房对应三个硬性前提，缺一即不成立：① 双路独立电源（不同变电站/不同母线段）② 备用发电机组（并机或N+X）③ 供配电与制冷均按不中断原则设计且有实测切换数据
- 等级下调属于**设计变更**，必须走正式变更流程并重新评审风险与投资影响；"口头确认降级"是后期验收争议与事故追责的首要证据缺口
- 等级判定结论须与合同、验收标准、招标文件技术需求书三者一致；任一处不一致即构成验收争议点

### 2. 供配电系统冗余设计与容量计算

定义：供配电系统设计是从市电引入到 IT 设备末端电源的完整链路设计，包含市电引入、配电柜与配电末端、不间断电源、备用发电、切换装置与末端 PDU。核心是"**在任一单点故障下不丢失已承载负载**"。

关键要点：
- 冗余度三档及适用关系：
  - **2N**：两套完全独立的系统各承担 100% 负载，任一套完全故障时另一套独立承担全部负载；冗余度最高，造价最高，A 级核心区首选
  - **N+1**：N 台设备分担负载加 1 台热备，单台故障时由备份接管，**前提是单台承载能力 ≥ 故障后全部负载**
  - **2(N+1)**：两路各自 N+1，双侧冗余，适合 A 级机房的关键分区
- 容量计算的三个系数必须写进设计说明：
  - UPS 容量 = Σ(设备额定功率) ÷ 功率因数 ÷ 负载率（负载率一般取 0.7–0.8），并按未来扩容留 20%–30% 余量
  - 制冷量 = IT 设备发热量 + 照明散热 + 新风焓差 + 运维散热，通常再乘设备散热系数（按设计手册取值，不低于 1.2）
  - 母线与电缆截面按电流、温升、压降、短路热稳定四项校验，**压降与热稳定往往先于载流量成为瓶颈**
- 后备时间（Hold-up）核算逻辑：A 级机房若配置柴油发电机，UPS 后备时间只需覆盖"发电机启动 + 并机 + 稳定输出"的时间段（工程惯例按不少于 0.5 小时核算），而非盲目追求数小时；但**无柴发时 UPS 后备时间必须覆盖发电以外的全部市电中断时长**
- 切换装置与旁路：双路市电须配自动转换开关（ATS）并具备手动旁路，UPS 须具备静态旁路与维修旁路；**ATS 与 UPS 的切换动作时间必须实测并记录，不是设计参数而是验收参数**
- 常见错误清单：负载率长期跑在 90% 以上（UPS 过载保护误动作）、双路市电实际来自同一变电站/同一段母线（伪双路）、发电机无定期带载试车记录、末端 PDU 无相位与回路标识、无负载均衡（单相集中导致零线过载）
- 机房专用回路与动力环境分离：UPS 输出与照明、空调动力、市电插座严格分路，**动力跳闸不得带倒 IT 负载**

### 3. 制冷系统、气流组织与温湿度控制

定义：制冷系统设计解决"热从哪里来、如何高效带走"的问题；气流组织是让冷风与热风分离、消除热点、降低送回风温度差的布流设计。判定成败的硬指标是**IT 设备进风温度**，而不是机房回风温度。

关键要点：
- 气流组织三条主线：
  - **冷通道封闭**：把冷风限制在冷通道内送入服务器进风面，是降低能耗与消除热点的第一优先手段
  - **热通道回风**：热风集中回到空调回风侧，避免与冷风混风
  - **地板/机柜布局**：机柜朝向与冷热通道对齐，配电柜、UPS、空调机柜不得挤占冷通道形成回流
- 热点（Hot Spot）的成因与治理：机柜前后功率密度不均、机柜盲板缺失导致气流短路、上送下送与冷通道封闭不匹配、风量分配不均。治理手段依次是**加装盲板 → 调整机柜布局 → 增设局部制冷或调整送风静压**
- 制冷方案三类及适用：风冷（机房专用空调）、水冷（冷冻水，需防漏与水质管理）、间接蒸发冷却（利用室外冷源，北方与过渡季节能效最优）。政务云数据中心机房改造常见做法是"风冷改造为水冷或间接蒸发"，改造期必须安排**临时制冷冗余**
- 冗余要求与温湿度控制：
  - A 级机房空调按 N+1 或 2N 冗余设计，且需做**冗余切换实测**
  - 温度区间与送风温差必须双向约束：温度过高直接触发服务器降频与宕机；温差过大导致相对湿度骤降引发静电与元器件损伤
  - 温度应取**机柜进风侧**测点，仅测回风口温度会掩盖热点
- 联动机制：动环监控必须实现"温度/负载升高 → 空调自动调节或启备 → 超限告警 → 工单派发"的闭环；案例中出现"告警有人看但无人处理"属于典型的闭环失效

### 4. 数据中心能效 PUE 与绿色数据中心评价

定义：PUE（电源使用效率）＝ 数据中心总能耗 ÷ IT 设备能耗，衡量非 IT 负载（制冷、供配电损耗、照明）的占比，是数据中心能效的核心指标；绿色数据中心评价是依据现行能效国家标准对数据中心能效水平、能效等级与资源环境管理进行评价认定的机制。

关键要点：
- PUE 的分子分母不可混算：分子含制冷、供配电损耗、照明等全部非 IT 用电；分母仅 IT 设备（服务器、存储、网络等）用电。**照明计入分子不计入分母**，这是最常犯的算错点
- 节能改造的三条主线及量化目标：
  - 制冷优化（占比最高，通常占非 IT 能耗六成以上）：冷通道封闭、热通道回风、自然冷源利用（室外机直接供冷）、群控与变频
  - 供配电优化：UPS 负载率提升至合理区间（避免长期低负载运行）、**休眠节能（低负载时旁路或部分模块休眠）**、直流供电与高压直流探索
  - 运维优化：精确送风、部分负荷控制、消除无效照明与过度制冷
- 部分负荷下的 PUE 往往高于满载 PUE，**"扩容后空载运行"是政务云普遍存在的能效黑洞**；考核应同时看年均 PUE 与 IT 负载率
- 能效等级评价以现行国标分档为准（最优档要求 PUE 控制在 1.3 以内，中间档 1.5 以内，基础档 2.0 以内），新建机房应以最高档为设计目标；具体限值以现行国家标准文本为准
- 绿色数据中心评价不止看 PUE，还包括**水资源利用（冷板液冷与中水回用）、碳排放、可再生能源使用比例、废弃电子产品回收处理**
- 项目管理上的意义：能效指标必须写入**设计文件、招标技术要求、合同验收指标、运维期考核**四个环节，否则建完即失管，是典型的"建管脱节"责任断点

### 5. 动环监控与机房工程验收实测

定义：动环监控（动力环境监控）是对供配电、UPS、空调、精密空调、漏水、烟感、温湿度、门禁与视频等机房设施运行状态进行采集、告警、联动与集中管理的系统；工程验收实测是按规范与设计文件，对设施的功能、性能、切换、冗余、接地、隐蔽工程等指标进行现场实测并留存原始记录的活动。

关键要点：
- 动环监控采集项至少覆盖：市电状态与电压电流频率、UPS 输入输出与电池健康度与旁路状态、配电柜开关状态与漏电、精密空调运行与告警与回风温度、机房温湿度、漏水、烟感、门禁与视频、接地状态；**缺项即失去监控基础，事故追溯与考核均无据**
- 告警分级与闭环：告警必须分级（紧急、重要、一般）、必须派单到人、必须有时限与闭环回单；"只在监控大屏滚动不派单"是无效监控
- 验收必做的实测项清单：
  - 供电切换：市电切换试验、UPS 切换试验、发电机带载试验（记录切换时间与输出电压频率波动）
  - 空调冗余：单台空调停机后其余机组能否维持设定温湿度
  - 接地：防雷接地与等电位联结接地电阻**实测并记录数值**，不接受"符合标准"这类表述
  - 制冷量与气流：分区送风量与温湿度分布实测、热点机柜排查报告
  - 布线与标识：永久链路测试报告、标签与端口对应关系核对、强弱电分离与桥架敷设检查
  - 隐蔽工程：桥架、管路、接地极、防水必须在**覆盖前**完成随工验收并留存影像
- 验收条件的通则：合同清单逐条核对完成、功能与性能与安全测试报告齐全、缺陷按严重程度分级且严重级清零、文档齐套（需求、设计、测试、竣工图、计算书）、第三方检测报告（如有约定）
- **验收标准必须可测量**："符合国家相关标准""满足设计要求""运行正常"均不可测，须替换为具体指标、阈值、测量方法、记录形式与判定方式
- 运维交接前置条件：配置与资产台账、应急预案、备件清单、账号与权限移交、源配置与运维手册、既有缺陷与遗留问题台账

## 案例分析题

**题目**：

某市政务数据管理局建设"市政务云三期数据中心机房基础设施建设项目"，合同金额 1.28 亿元，工期 14 个月，承建方为集成商 B，监理方为 C，建设单位为 A。建设内容包括：1 号机房（承载社保、医保、公积金等核心业务系统）、2 号机房（同城双活），以及配套的供配电、精密空调、动环监控、综合布线与消防系统。

项目实施过程中出现以下情况：

1. 建设内容与等级判定：招标文件技术需求书仅写"满足核心业务承载需要，按国家机房标准建设"，未明确机房等级。设计单位按 B 级机房出图并通过施工图审查。建设过程中 A 方口头同意"按 B 级做，先上"，未形成书面等级判定结论，也未对承载的社保、医保系统与机房的匹配性组织专项评审。

2. 场地与选址：1 号机房选址于政务云机房东侧三层，地下 2.8 米，距市政排水管廊 30 米，楼下为地下车库入口，夏季暴雨时该区域有过两次积水告警记录；未开展地质灾害勘察与洪涝风险评估，未做场地环境与腐蚀性气体检测。

3. 供配电：采用一路市电加单台 UPS 供电，UPS 容量按设备铭牌功率合计 1.0 倍配置；无柴油发电机组；市电进线双路来自同一变电站同一段母线；UPS 电池组未做容量核算与放电时间测试；无自动转换开关，切换靠人工在配电柜操作；末端 PDU 无相位与回路标识，实测单相电流不平衡度达 41%。

4. 制冷与气流：1 号机房采用 4 台风冷精密空调，冷通道未封闭，服务器机柜与配电柜、UPS 柜同列布置；建设完成后监控显示机房回风温度 24℃，但机柜进风温度实测最高 42℃，43 台机柜处于热点区，服务器降频告警月均 17 次；未做制冷量与送风量计算书，也未做冗余切换试验。

5. 能效：实测机房 PUE 为 2.31，全年用电量 2860 万千瓦时，其中制冷能耗占比 62%；项目立项文件与合同均未设定 PUE 或任何能效指标。

6. 动环监控与验收：动环系统仅接入机房温湿度与烟感，UPS 状态、精密空调运行与告警、漏水、门禁状态、漏电保护状态均未接入；告警只在监控大屏滚动，未对接工单系统。系统集成商以"设备上架完毕、网络 ping 通、机房无告警"为由申请初步验收，验收组签署"验收合格"。验收过程未做市电与 UPS 切换试验、未做接地电阻实测、未做精密空调冗余切换试验、隐蔽工程（桥架、管路、接地极）未随工验收且无影像记录；交付文档仅有设备清单，无制冷量计算书、UPS 容量计算书、气流组织图与竣工图。

7. 合同与变更管理：合同验收条款为"符合国家相关标准，建设成果满足使用要求"；B 方的设计变更（由原 A 级机房方案调整为 B 级）未走变更流程，无变更申请单、无风险评审记录；同城双活方案在合同中仅以"具备扩展条件"表述，建成后未做双活切换演练；机房工程质保期 24 个月，但精密空调与 UPS 未约定性能保证期与衰减更换条款。

**问题**：
1. 本项目机房等级的判定是否正确？应补充哪些判定工作？
2. 供配电与制冷设计存在哪些问题？应给出哪些整改要求？
3. 从气流组织与能效两个角度，说明应采取的优化措施与量化指标。
4. 动环监控与工程验收存在哪些缺陷？重新验收应具备哪些条件与实测项？
5. 在合同管理与变更管理方面应采取哪些补救措施？

**参考答案**：

**第 1 问：机房等级判定不成立，属实质性合规缺陷。**
1. 判定缺陷三条：一是判定依据缺失，未把"业务重要性—系统重要性等级—允许中断时间（RTO）"作为判定输入；二是判定程序缺失，未形成书面等级判定结论并由建设单位确认；三是变更未入流程，A 级调整为 B 级属设计变更，无变更单、无风险评审、无审批记录，程序上不成立。
2. 应补做的工作：① 逐系统梳理承载清单（社保、医保、公积金、公积金异地结算等）与各系统允许中断时间、恢复时间目标；② 由建设单位出具书面机房等级判定结论，明确 1 号机房与 2 号机房的分级及判定理由；③ 若确按 B 级建设，须书面论证核心业务的可接受性并落实替代保障措施（同城双活、异地灾备、备用电源），把"降级"的风险敞口以文件形式关闭；④ 对已发生的等级调整补做追溯性变更评审，评估供配电、空调、消防、安防的差距清单与整改投资。
3. 等级判定结论、招标文件技术需求书、合同条款、竣工验收标准四处必须一致，任一处不一致即构成后续争议源。

**第 2 问：供配电与制冷的设计与实施均不满足高可靠业务要求。**
1. 供配电问题逐条：① 一路市电，等于无冗余，任意一次市电检修即全机房失电；② 两路市电同源同段（同一变电站同一母线段），属"伪双路"，共因失效风险未消除；③ 无柴发，UPS 电池耗尽后即为彻底断电；④ UPS 容量按铭牌 1.0 倍配置，未除以功率因数、未按负载率 0.7–0.8 折算、未留 20%–30% 扩容余量；⑤ 电池组无容量核算与放电测试，实际可用容量不可知；⑥ 无 ATS，切换靠人工操作，切换时间不可控；⑦ PDU 无标识、单相不平衡 41%，存在零线过载与串接误接风险。
2. 供配电整改要求：按 A 级（或经判定后的目标等级）重构为双路独立市电 + ATS 自动切换 + 柴发自备 + UPS 按 2N 或 2(N+1) 冗余；重做 UPS 容量与后备时间计算书（后备时间须覆盖柴发启动并机与稳定输出的全过程），后备不足时先补 UPS 容量而非先降级；输出与照明、空调动力、市电插座分路；PDU 全面重新标识并做三相不平衡整改；补做市电切换、UPS 切换、柴发带载三项实测并留存记录。
3. 制冷问题逐条：① 4 台精密空调无 N+1 冗余且未做切换试验，单台故障即制冷缺口；② 无制冷量与风量计算书，选型是否匹配无从判断；③ 冷通道未封闭，冷风短路、回风混流；④ 服务器机柜与配电柜、UPS 柜同列，阻断送风形成热点；⑤ 43 台热点机柜、进风 42℃ 远超允许上限、服务器降频月均 17 次，属在用设备带病运行。
4. 制冷整改要求：补做制冷量与风量计算书并复核选型；冷热通道封闭、盲板补齐、机柜重排；增设冗余空调并做冗余切换实测；建立"IT 负载—进风温度—热点分布"实测机制，以机柜进风温度而非回风温度作为控制与验收指标；对 43 台热点机柜先做局部整改（盲板、布局、局部制冷），并核查服务器降频告警的影响面与业务风险。

**第 3 问：气流优化与能效优化应同步推进，指标必须量化并写入合同。**
1. 气流组织措施：冷通道封闭并加装盲板；冷热通道分离；机柜与配电、UPS、空调设备分离布置，通道尺寸按设备尺寸与送风要求核定；调整送风静压与送风方式，消除回流与短路；对 43 台热点机柜做逐柜排查，形成热点台账与整改记录；将机柜进风温度纳入动环告警阈值。
2. 能效措施与量化目标：① 冷通道封闭与自然冷源利用（过渡季与冬季直接利用室外冷空气），目标将制冷能耗占比由 62% 降至 45% 以内；② 空调群控与变频，避免多机低负载运行；③ 优化送风量与消除过度制冷，设定回风与送风温差阈值；④ UPS 负载率调整与部分模块休眠，降低供电损耗；⑤ 控制 IT 负载率合理区间，避免"扩容后空载"造成的 PUE 虚高。
3. 量化指标：PUE 由 2.31 降至 1.6 以下（中期）并向 1.3 以内（现行国标最优档）靠拢；以全年用电量下降 15%–20% 为阶段目标；改造期与稳态期分别测算，避免用部分负荷数据达标掩盖全年表现。
4. 指标必须写进四个环节：设计文件、招标技术要求、合同验收条款、运维期考核指标；并明确测量口径（测点位置、边界条件、统计周期、判定方式），否则事后无法验收。

**第 4 问：动环监控与工程验收均不满足要求，原"验收合格"结论应予撤销并重新组织验收。**
1. 动环缺陷：采集项缺失严重（UPS 状态、空调状态、漏水、门禁、漏电均未接入），导致配电、制冷两类核心设施处于监控盲区；告警未与工单闭环，"无告警"只反映采集项少而非运行正常；无 UPS 电池健康度与精密空调告警的专项监测。
2. 验收缺陷：验收标准不可测（"符合国家相关标准"）；缺少功能、性能、安全与机房工程四类实测报告；以"ping 通"替代机房工程验收；无市电与 UPS 切换试验、无接地电阻实测、无空调冗余切换试验、无制冷量与气流分布实测；隐蔽工程未随工验收且无影像记录，后期无法举证；交付文档缺计算书、气流组织图与竣工图；且在热点机柜、降频告警等质量问题未闭环的情况下即签署合格结论，验收把关失效。
3. 重新验收应具备的条件：① 整改完成并经监理复核，含热点治理、冗余切换实测、动环采集补齐；② 四类测试报告齐全——功能测试、性能测试、安全测试、机房工程测试（供电切换、接地实测、空调冗余切换、制冷量与气流分布）；③ 隐蔽工程随工影像与见证记录补齐并由监理签认；④ 文档齐套，含制冷量计算书、UPS 容量与后备时间计算书、气流组织图、竣工图、动环点位表与告警联动说明；⑤ 严重级缺陷清零，其余缺陷形成带责任人与时限的遗留问题台账并与质保金挂钩；⑥ 能效与冗余指标写入验收结论并具备可复测的测量方案。

**第 5 问：合同与变更管理补救措施应落到"可执行、可追责、可验证"。**
1. 合同补救：① 对不可测的验收条款出具补充协议或验收细则，把"符合标准"改为具体指标、阈值、测量方法、记录形式与判定方式（涉及 PUE、进风温度、切换时间、接地电阻、可用率等）；② 补充精密空调与 UPS 的性能保证期条款，明确效率衰减阈值与到期更换责任；③ 补充双活切换演练义务、演练次数与判据（切换时间、数据一致性、失败回切）；④ 补充动环采集项清单、告警分级与工单闭环要求，作为运维验收条件；⑤ 明确等级判定与重大设计变更的书面确认程序。
2. 变更管理补救：① 对已发生的 A 级转 B 级调整做追溯性变更评审，补齐变更申请单、影响分析（供配电、制冷、消防、安防、造价五个维度）、评审结论与建设单位书面批准；② 建立重大变更分级授权机制，等级判定、供配电架构、制冷架构、验收标准的变更由建设单位高层与技术负责人联签，承建方无权口头确认；③ 后续一律禁止"先实施后补单"，紧急变更可先行实施但须在规定时限内补办手续并留痕；④ 建立设计基线与台账同步更新机制，竣工图、计算书、动环点位表须与现场一致。
3. 责任与费用处理：对已降级且无书面批准的部分，明确在整改完成前的责任归属与费用承担；因等级降级、监控缺失、验收把关失效导致的业务影响（如服务器降频、数据读写异常），纳入问题管理与根因分析，形成永久措施；不因已签"验收合格"而免除整改责任，必要时启动合同争议处理或扣减质保金。

**踩分要点**：
1. 等级判定必须答出"判定依据 → 判定程序 → 结论确认 → 一致性核对"四段，只答"要按核心业务配高等级"最多得一半分。
2. 必须点明"同一变电站同一段母线的双路是伪双路、共因失效"，这是本题最有区分度的采分点之一。
3. UPS 容量计算要写公式：容量 = 额定功率合计 ÷ 功率因数 ÷ 负载率，并提 20%–30% 扩容余量；只写"容量不足"不得分。
4. 冗余等级必须区分 2N、N+1、2(N+1) 三个术语并说明 A 级应选 2N 或 2(N+1)，不能只写"增加冗余"。
5. 制冷问题要落到"冷通道未封闭 + 机柜与强电设备同列"两个具体成因，再落到"43 台热点机柜、进风 42℃、降频 17 次/月"三个案例数字。
6. 必须强调"以机柜进风温度为控制与验收指标，不以回风温度为准"，这是专业性分水岭。
7. PUE 计算与判断要写清分子分母边界（照明入分子不入分母），并答"部分负荷 PUE 高于满载 PUE、扩容空载是能效黑洞"。
8. 动环缺陷必须逐项列出未接入的采集项，并点明"无告警≠运行正常，采集项少而已"。
9. 验收缺陷必须批"以 ping 通代替机房工程验收"和"隐蔽工程未随工验收"两条。
10. 重新验收条件要答出"四类测试报告齐全 + 隐蔽工程影像 + 文档齐套 + 严重缺陷清零 + 遗留问题与质保金挂钩 + 指标可复测"六项。
11. 合同补救必须给出"把不可测条款改成指标、阈值、测量方法、记录形式、判定方式"五要素，这是通用踩分模板。
12. 变更管理必须答"追溯性变更评审 + 分级授权联签 + 禁止先实施后补单 + 设计与台账同步更新"四条。
13. 全案例数字必须取自题干原文，不得臆造；能引用题干数字处尽量引用，阅卷按"踩点给分"给分。
14. 结尾要点明"已签验收合格不免除整改责任"，体现责任闭环意识。
