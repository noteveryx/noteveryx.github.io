# （高级）系统规划与管理师 · 第64次学习（2026-10-22）

## 今日核心概念

### 1. 信息化标准与规范体系
定义：以统一的技术、管理和服务规则，约束信息化全生命周期（规划、建设、运行、维护、退役）各类活动的行为准则，是消除信息孤岛、实现互联互通与集约化的基础制度安排。

关键要点：
- **四层标准体系**：国际层（ISO/IEC、IEEE、COBIT）、国家标准层（GB/T系列、等保2.0 GB/T 22239、密评GB/T 39786）、行业层（金融JR/T、电信YD/T、医疗WS/T）、企业层（本单位技术规范、管理规范、数据规范）。
- **五类标准**：基础类（术语、体系框架）、技术类（网络协议、接口、数据格式、数据元）、管理类（开发、测试、运维流程、项目管理）、安全类（等级保护、密码应用、数据分类分级）、安全与隐私类（个人信息保护、数据出境）。
- **落地要点**：统一数据元与编码是标准化的第一抓手；接口标准决定系统间互操作性；数据标准化→业务标准化→管理标准化的推进次序不可颠倒。
- **常见失分点**：混淆"指导性文件"（如GB/T推荐性标准）与"强制性规范"；把等保2.0与密评混为一谈（前者保安全保密，后者保密码合规）。

### 2. 信息技术治理（IT Governance）
定义：机构为确定IT相关决策权与责任框架、确保IT被有效用于支持战略目标而进行的机制安排，回答"谁决策、谁执行、谁监督、担不担责"。

关键要点：
- **COBIT五大领域**：EDM评估与指导（治方向）、APO目标达成（治规划）、BAI建设交付（治建设）、DSS服务交付与支持（治运行）、MEA监控评估与审查（治评价）。
- **三支柱**：治理（GEV，评估方向与合规）、管理（EDM/APO/BAI/DSS，推进落地）、技术（云、大数据、平台工程，提供底座）。
- **治理模式三形态**：集中式（强管，集团统一规划、统一建设、统一安全）、分散式（弱管，各分子公司自建自管）、混合式（多数大型集团采用的现实选择，集团管方向与底座，单元管应用）。
- **治理成熟度CMM五级**：C0初始级（依赖个人英雄、随意性强）→C1可重复级（有文档可复用）→C2已定义级（统一标准与流程）→C3已量化级（指标可度量）→C4优化级（持续改进）。

### 3. 流程再造（BPR）与流程持续改进
定义：流程再造是对组织业务流程做根本性、全局性再思考与彻底性再设计，以显著提升关键绩效（成本、质量、速度、效益）；与持续改进相比，再造是"推倒重来"，改进是"点滴优化"。

关键要点：
- **再造四原则**：围绕结果而非任务组织流程；让使用流程结果的人执行流程；将信息处理纳入产生信息的实际工作；视同地域为原则，但可跨地域集中协作。
- **渐进修补 vs 激进重构**：渐进式（自动化、规范化→重新设计）风险低见效慢；激进式（直接重设计流程）见效快但阻力大、风险高。企业实践中多为"渐进为主、重构择机"。
- **流程与数据的关系**：流程优化必然带来数据标准化需求，数据标准化又会反过来约束流程，二者互为表里。
- **价值链分析**：识别支持性活动与增值活动，砍掉不增值环节（VA识别：客户是否愿意付钱），压缩非增值（NVA）与必要非增值（BVA）。
- **流程绩效指标**：周期时间、流程成本占比、一次通过率、客户满意度、返工率。

### 4. 组织变革管理
定义：在组织引入新技术、新流程、新制度时，通过人员、流程、技术三方面变革，使组织从当前状态平稳过渡到目标状态的过程，是信息化落地成败的决定性因素（业界共识：三分之一技术、三分之一管理、三分之一人员）。

关键要点：
- **Lewin三阶段**：解冻（打破现状、建立变革紧迫感）→变革/移动（推行新流程新技术）→再冻结（固化成果写入制度与考核，形成新惯例）。
- **Kotter八步**：创造紧迫感→组建领导联盟→确立愿景与战略→沟通愿景→扫除障碍→创造短期胜利→巩固成果与变革（更多尝试）→固化成果融入文化。
- **干系人策略**：高权力-低支持→重点说服；低权力-高支持→重点激励；高权力-高支持→核心盟友；低权力-低支持→保持通知。
- **阻力来源五类**：认知阻力（不懂）、情感阻力（不愿）、习惯阻力（惯性）、利益阻力（动了奶酪）、组织阻力（部门墙与权责）。
- **落地铁律**：一把手挂帅 + 变革办公室常设 + 培训与沟通全覆盖 + 试点先行分批推进 + 考核挂钩激励到位。

### 5. 绩效评价体系：KPI / OKR / 平衡计分卡
定义：以结构化、可量化的指标体系衡量组织及信息化部门业绩并驱动改进的方法，是IT治理落地的"抓手"，解决"IT价值说不清、责任追不了"的问题。

关键要点：
- **KPI**：关键绩效指标，强调"考核"，自上而下分解，指标刚性、期末结算、扣罚导向，容易导致数据造假与短期行为。
- **OKR**：目标与关键结果，强调"对齐与挑战"，自下而上制定，目标公开、周期短（季度）、评分不打钩不与薪酬直接挂钩，敢定高目标。
- **平衡计分卡BSC四维度**：财务（股东/投资回报）、客户（服务对象满意度）、内部流程（研发与交付效率）、学习成长（组织能力与人才），四维因果链：学习成长→内部流程→客户→财务；战略地图把四维目标绘制为因果关系网络。
- **信息化绩效指标体系**：如系统可用率99.9%、需求交付准时率、运维故障MTTR/MTBF、变更成功率、用户满意度、信息安全事件数、项目ROI、投资完成率。
- **关键原则**：指标必须与战略目标对齐（战略一致性），数量控制在每个部门5—10个，指标可归因、可控、有数据源，避免"唯数字论"。

## 案例分析题

**题目**：

某省属能源集团（1家集团公司，下辖12家分子公司、4.2亿元年度信息化投入、近4000名员工）组建成立10周年。此前信息化建设采取"各分子公司自建自用"模式，各单位口径不统一、数据不通、重复采购严重。集团拟编制"十四五"信息化规划并进行架构整合，人力资源部提出以流程再造推动组织变革，集团信息中心主任提出以KPI考核信息化部门绩效。集团董事长办公会上提出四项要求：

1. 统一数据口径与业务编码，消除信息孤岛；
2. 三年内建成集团级财务共享、供应链协同、人力资源共享三个集中平台；
3. 建立集团对分子公司信息化工作的管控机制；
4. 通过变革保障方案使划转的共享中心人员平稳过渡。

请指出该集团在标准化、IT治理、流程再造、变革管理与绩效评价五个方面的主要问题，并提出改进建议。

**参考答案**：

一、标准化方面的问题与建议
问题：各分子公司自建自用，未建立集团统一的信息化标准体系，数据元、编码、接口标准不统一，重复建设导致数据无法打通，直接影响集中平台建设。
建议：制定集团信息化标准体系，分四层推进——国际层对标ISO/IEC与COBIT，国家层遵循等保2.0与密评要求，行业层对标能源行业信息化规范，企业层制定数据元规范、编码规范、接口规范、开发运维规范；以"统一数据元与主数据编码"为第一抓手，先做数据标准化，再做业务标准化，最后做管理标准化。

二、IT治理方面的问题与建议
问题：采用分散式治理，分子公司自建自管，集团缺乏对信息化投资的决策权、架构标准与安全底线，导致重复采购与架构碎片化；集团信息中心人手不足，缺乏常设治理机构。
建议：建立混合式治理模式（集团管方向与底座、分子公司管应用），依托COBIT五大领域建立集团信息化治理框架；设立由集团CIO牵头、含财务/审计/业务/安全的信息化治理委员会，重大投资、架构评审、安全例外统一决策；参考成熟度模型评估当前处于C0—C1级，制定三年路径向C3级（已量化）迈进。

三、流程再造方面的问题与建议
问题：以"建平台"代替"改流程"，若不先做流程梳理与价值链分析，三个共享平台将变成"把分散的混乱流程原样搬到线上"，形成新的信息孤岛。
建议：先做流程识别与价值链分析，区分增值VA、必要非增值BVA与非增值NVA环节，砍掉审批过环、重复录入等不增值节点；再按"围绕结果组织流程、谁用结果谁执行、信息处理纳入实际工作、视同地域为原则"四原则重新设计流程；以渐进式修补为主（自动化、规范化→重新设计），对审批链条过长的关键流程择机做激进重构；建立流程责任中心与流程Owner，明确流程绩效指标（周期时间、一次通过率、返工率）。

四、变革管理方面的问题与建议
问题：共享中心涉及跨部门划转与人员身份转变，若无变革方案，将出现"系统建成了、业务不用、员工抵触"。
建议：按Lewin三阶段推进——解冻阶段调研阻力来源（认知/情感/习惯/利益/组织五类），对划转人员开展岗位胜任力评估与培训，宣传重组的战略价值与员工长远利益；变革阶段一把手挂帅、成立常设变革办公室、选试点单位分批推广、按干系人象限制定沟通策略（高权力低支持重点说服、低权力高支持重点激励、高高组建联盟）；再冻结阶段将新流程、新职责写入制度文件与绩效考核，组织知识沉淀与经验教训总结。

五、绩效评价方面的问题与建议
问题：仅以KPI考核信息化部门，容易只考核"系统上线率、上线及时率"等交付类指标，导致运维质量、数据质量、业务成效无人负责。
建议：构建"战略对齐"的绩效体系——上层用平衡计分卡BSC绘制战略地图，将"降本增效、共享复用、风险可控"分解到财务、客户、内部流程、学习成长四维；考核层采用KPI保障底线（可用率、变更成功率、故障MTTR、安全事件数、数据质量合格率）；目标牵引层引入OKR设置挑战性目标并公开对齐；指标数量控制在5—10个，可归因、可控、有数据源，季度复盘与年度考核结合，避免唯数字论。

**踩分要点**：
1. 必须分五段作答，每段结构统一为"问题—原因—建议"，按题目给出的五个方面逐条对应，漏一条即丢3—5分；
2. 标准化答"四层体系+以统一数据元为抓手+数据→业务→管理标准化次序"，答"要统一标准"只能得1分；
3. IT治理答"治理模式+COBIT五大领域+治理委员会+成熟度路径"，必须点出"分散式治理→混合式治理"的判断；
4. 流程再造答"价值链VA/BVA/NVA分析+四原则+渐进vs激进选择"，不能只答"要优化流程"；
5. 变革管理答"Lewin三阶段（解冻—变革—再冻结）+Kotter八步要点+阻力来源五类+干系人分层"，三阶段名称写全；
6. 绩效评价答"KPI/OKR/BSC三者定位区别+BSC四维度因果链+指标可归因可控"，只写"加强考核"不得分；
7. 结合案例数据（12家分子公司、4.2亿投入、三个共享平台、共享中心划转）逐条落地，避免通用模板答案。

## 记忆口诀

**标准体系四层记**：国际国标行业企——基础技术管理安全，数据编码先下手。

**COBIT五域口诀**：评估指导定方向，目标达成做规划，建设交付去落地，服务交付保运行，监控审查评成效。（EDM-APO-BAI-DSS-MEA）

**治理模式三形态**：集中强管统一走，分散自管乱出头，混合管方向也管手——集团定调子、单元定日子。

**成熟度五级记**：初始靠英雄可重复，定义靠标准量化，靠优化持续长。（C0→C1→C2→C3→C4）

**流程再造四原则**：围绕结果而非任务，用结果的人办流程，信息处理融进业务，地域集中别分散。

**再造与改进分清楚**：再造是推倒重来，改进是小步快跑。

**价值链三分类**：增值客户愿付费，非增值砍掉它，必要非增值保留再优化。

**Lewin三阶段**：先解冻破旧习，再变革推新事，后冻结成惯例。

**Kotter八步**：紧迫、联盟、愿景、沟通、清障、短胜、巩固、融入文化。

**阻力五类**：不懂不愿不习惯，动了奶酪怕吃亏，部门墙高挡了路。

**干系人象限**：高权低_SUPPORT重点说服，低权高支持重点奖励，高权高支持拉成盟友，低权低支持保持通知。

**KPI与OKR辨析**：KPI往下分要考核，OKR自下而上要对齐；KPI算账扣钱追结果，OKR挑战不定输赢。

**BSC四维因果链**：学习成长保后劲，内部流程提效率，客户满意赢口碑，财务结果见真章。

**答题口诀**：五问五答见对应，问题原因加建议；数据案例要落地，术语齐全分到手。
