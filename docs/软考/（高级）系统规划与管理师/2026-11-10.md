## 今日核心概念

### 1. 可行性研究、项目评估、项目决策与项目立项的四者区分

定义：立项管理是项目生命周期的起点，回答"这个项目该不该做、由谁做、做成什么样"这一组问题。教材把它拆成四个边界清晰的环节，任何一个环节缺失或越位，都会导致"论证替代决策"或"评估替代规划"。

关键要点：

1. **四环节定位**
   - 可行性研究：编制方（建设单位或其委托的咨询机构）做的"能不能做、做了值不值"的自我论证，产出《可行性研究报告》。
   - 项目评估：第三方评估机构（或投资决策部门、审计机关）做的"研究做得对不对、结论站不站得住"的独立复核，产出《项目评估报告》。
   - 项目决策：投资决策机构（董事会、投委会、发改委）依据可研与评估结论做的"批不批、怎么批"，《项目建议书》《可行性研究报告》《项目评估报告》三者是决策依据。
   - 项目立项：决策通过后正式批准项目、组建项目团队、下达项目章程，进入实施阶段。
   - 一句话记法：**可研是自证，评估是复审，决策是拍板，立项是开工令。**

2. **划清边界的四条红线**
   - 可研不得自行作出投资决策结论。可研的结论只能是"在假设条件下可行/不可行/需补充论证"，最终是否投资由决策机构定。
   - 评估不得替可研补作业。评估发现数据失真、方案不实，是要求重新编制可研或补充专项论证，不能由评估机构代为修正后再放行。
   - 决策不得跳过评估直接批可研结论。重大投资项目未经过评估就决策，属程序缺失。
   - 立项不得承接未决事项。可研或评估未出具明确结论、遗留重大分歧的，不得进入立项批复。

3. **四类文件的关系**
   - 《项目建议书》：立项的"敲门砖"，说明项目必要性、初步设想、投资匡算与建设条件，内容粗、可研阶段不再重复论证。
   - 《可行性研究报告》：详细论证技术、经济、社会与法律、组织与实施四方面可行性，是决策的主要技术经济依据。
   - 《项目评估报告》：对可研的质量、结论与依据做独立评价，通常包含"同意立项/修改后立项/暂缓/不同意"四档意见。
   - 《项目章程》：项目获批后正式确立项目、授权项目经理、规定目标与约束，是整合管理的起点文件。

4. **考试高频陷阱**
   - 案例问"某单位先做可研、后由同一家咨询公司做评估，是否合规"——**编制与评估应分离**，同一家机构自编自评独立性不足。
   - 案例问"评估报告建议暂缓，项目组仍按原方案开工"——决策未作出即实施，属越权启动。
   - 案例问"可研报告建议采用国产化方案，评估未提及"——评估应覆盖关键性技术路线与重大风险提示的适当性，不能只评数字。

### 2. 可行性研究的两个层次：初步可行性研究与详细可行性研究

定义：可行性研究按深度和目的分为初步可行性研究（机会可行性研究与初步可行性研究）与详细可行性研究两个层次，二者目的不同、深度不同、结论效力也不同。

关键要点：

1. **机会可行性研究（投资机会研究）**
   - 时机：在项目构思阶段、正式立项之前。
   - 目的：从宏观与行业层面识别投资机会，论证"这个方向值不值得投"。
   - 产出：《项目建议书》或初步项目方案，含项目必要性、初步设想、投资规模匡算、主要建设条件。
   - 特点：结论是"机会存在/不存在"，不做精确计算，费用低、周期短。

2. **初步可行性研究**
   - 目的：判断机会在技术与经济上是否具备进一步研究的条件，界定项目范围与下一步工作。
   - 内容：项目目标与范围初步界定、建设方案初步比选（技术路线初选）、投资初步估算（匡算）、效益初步分析、实施条件初步分析、风险初步识别。
   - 产出：《初步可行性研究报告》，通常同时报批项目建议书。
   - 特点：比机会研究细，但尚未进入详细设计深度，不作为最终投资决策的完整依据。

3. **详细可行性研究**
   - 目的：为投资决策提供完整、可靠的技术经济依据，是**设计过程的开始**。
   - 深度要求：需在初步设计（总体设计）基础上展开，涉及系统方案、设备选型、软硬件配置、网络与机房方案、数据方案、集成方案，并对投资进行详细估算。
   - 产出：《可行性研究报告》及其附件（投资估算表、经济效益计算表、风险分析表、招标方案初稿）。
   - 结论效力：是投资决策机关做出立项决策的**主要依据**。

4. **层次关系与衔接**
   - 三层次可归纳为"机会研究看方向 → 初步可研看条件 → 详细可研看方案与账"。
   - 逐层递进、逐层收敛：上一层的结论是下一层的输入；上一层不成立则不再进入下一层，避免沉没成本。
   - 若详细可研结论为不可行，**不得以"已投入咨询费"为由强行立项**。

5. **高频失分点**
   - 详细可研报告只有技术方案与投资估算，**没有经济可行性、社会与法律可行性、组织与实施可行性**，即"三缺一"结构不完整。
   - 把初步可研的匡算数字直接当作详细估算用于决策。
   - 详细可研编制过程中未同步开展初步设计，导致方案与投资估算脱节。

### 3. 详细可行性研究的四方面内容

定义：详细可行性研究必须从技术、经济、社会与法律、组织与实施四个方面对项目进行系统论证，四个方面构成"完整可行"的判定标准，缺一项即为论证不充分。

关键要点：

1. **技术可行性**
   - 考察内容：技术路线是否成熟先进、软硬件与网络方案是否可实现、关键技术与设备是否有成熟供货与实施经验、系统集成与数据迁移路径是否可行、扩展性与前瞻性是否满足规划期要求。
   - 判据要点：技术先进性与适用性要"适度超前但不超预算"，避免为追求先进而抬高投资；须给出备选方案比选结论及选型理由。
   - 常见缺陷：照抄厂商方案书、无备选比选、忽略既有系统复用与重复建设、与企业信息化规划不衔接。

2. **经济可行性**
   - 考察内容：投资估算（建设投资 + 建设期利息 + 流动资金）、成本估算（建设成本与运营成本）、效益测算（经济效益、社会效益）、资金筹措方案、财务评价指标、敏感性分析。
   - 判据要点：成本效益口径必须与效益口径一致（同一收益期、同一折现基准），**收益不得重复计入、口径不得虚高**；必须考虑运营期成本与全生命周期成本。

3. **社会与法律可行性**
   - 考察内容：是否符合国家法律法规与产业政策；数据合规（网络安全、数据安全、个人信息保护）；与既有行政 regulation、审批流程、行业监管要求是否相容；社会效益与社会影响（就业、示范推广、公众服务）；节能环保与绿色集约要求。
   - 判据要点：合规性是**否决性条件**，不通过则一票否决，不参与后续比较。

4. **组织与实施可行性**
   - 考察内容：项目组织与职责分工、现有管理制度与流程是否需要同步调整、人才储备与技能要求、实施能力与经验、外部协作与供应商市场、实施计划与进度可行性、建设条件（场地、资金、审批）。
   - 判据要点：组织与实施能力不足时，应通过"引入外部力量+组织变革+分期实施"降低风险，而不是直接判不可行。

5. **四方面的关系（考点）**
   - 技术是前提，经济是核心，社会与法律是底线，组织与实施是保障。
   - 四者关系是"与"的关系而非"或"，**任何一项不成立都不能得出"项目可行"结论**。
   - 社会与法律可行性具有**否决性**，技术或经济上的高收益不能弥补合规缺失。

### 4. 经济可行性分析：投资估算与财务评价指标

定义：经济可行性分析是在项目边界与评价期确定的前提下，通过投资与成本估算、效益测算和财务评价指标计算，判断项目在财务上是否成立的论证过程。

关键要点：

1. **投资估算的构成**
   - 建设投资：硬件设备费、软件购置与开发费、系统集成与实施费、其他建设费（工程建设其他费、预备费）。
   - 建设期利息：分期建设或建设期占用的资金成本。
   - 流动资金：项目运营初期所需周转资金。
   - 估算方法：生产能力指数法、系数估算法、比例估算法、混合法；精度要求：项目建议书匡算（一般±20%～30%），初步设计概算（一般±10%～15%），施工图预算（一般±5%）。**概算超可研估算即构成重大问题。**

2. **成本口径**
   - 必须区分建设成本与运营成本，必须计算**全生命周期成本**（建设期 + 运营期 + 处置期）。
   - 常见错误：只算建设成本不算运营期成本；漏计通信资费、耗材、电池更换、许可证年费等"长尾运维成本"。

3. **效益口径**
   - 经济效益：直接经济效益（收入、成本节约、产能提升）与间接效益（管理效率、风险降低、决策科学化）。
   - 社会效益：就业、示范、普惠、治理能力提升。
   - **红线**：一是不得把其他独立立项项目的收益计入本项目；二是不得把未扣除转移支付的资金流入计为社会净效益；三是收益不得重复计入（如同一节约既算在业务部门又算在平台）。

4. **核心财务评价指标**
   - 净现值（NPV）：各年净现金流按基准收益率折现后求和，**NPV ≥ 0 表示项目可行**；NPV = 0 为临界状态。**必须注意：净现值随折现率升高而降低**，这是最常考的性质。
   - 内部收益率（IRR）：使 NPV = 0 的折现率，**IRR ≥ 基准收益率（资本成本）项目可行**；IRR 随现金流规模变化而变（规模效应）。
   - 投资回收期：累计净现金流由负转正的时点，分静态与动态；回收期越长风险越大。
   - 年金净流量（ANCF）：年金形式现金流下的等额净收益，用于多方案比较。
   - 折现率（基准收益率）来源：行业基准收益率、资本成本、机会成本、加权平均资本成本。

5. **敏感性分析与风险辨识**
   - 重点考察不确定因素：投资估算（±10%～20%）、运营成本、年收益、产品价格/服务量、折现率、建设进度。
   - 结论要求：指出**临界点（敏感临界值）**与**敏感因素排序**，并对敏感因素提出应对预案（如对投资额超支设置预备费、对收益下滑设置保底条款）。
   - 多方案比选规则：互斥方案比选用净现值法（寿命期不等用年金净流量法或共同年限法），独立方案用净现值率或内部收益率排序，**不能直接用内部收益率排序互斥方案**。

### 5. 项目评估、项目决策与立项评审

定义：项目评估是在可行性研究报告完成后，由独立第三方机构对研究过程与结论进行复核评价的活动；项目决策是投资决策机构依据可研与评估结论作出投资决定；立项评审是决策前的合规与专业把关程序。

关键要点：

1. **项目评估主体与独立性**
   - 主体：独立第三方评估机构、投资决策咨询机构、审计机关、财政评审机构、主管部门组织专家评估组。
   - 独立性要求：编制单位与评估单位应分离；评估人员不得是原可研编制人员；评估应覆盖技术、经济、管理、合规、风险五方面。

2. **项目评估内容五方面**
   - 目标评估：目标是否明确、是否符合上位规划与业务战略、是否必要。
   - 技术评估：技术方案成熟度、选型合理性、与既有系统的关系、实施复杂度。
   - 经济效益评估：收益测算依据是否充分、口径是否一致、有无重复计入与高估、成本是否漏项。
   - 社会效益评估：社会与法律合规、外部性、节能环保、公平可及。
   - 管理评估：组织与实施能力、项目团队、进度与风险、运维与后续保障。
   - 另加**风险评估**：识别风险因素、评价风险等级、核查应对措施。

3. **评估结论四档**
   - 同意立项 / 修改后立项（附整改要求与时限）/ 暂缓（补充论证后重审）/ 不同意立项。
   - 出具"修改后立项"时，整改事项必须**逐项明确责任单位、完成时限与验证方式**，并跟踪闭环。

4. **项目决策**
   - 决策类型：接受、拒绝、推迟（补充信息后再议）。
   - 决策依据完备性检查：立项报告、可研报告、评估报告、投资计划、资金来源证明、用地/能耗等前置审批条件。
   - 决策原则：符合战略与规划、技术经济可行、合规无否决项、风险可承受、资金有保障、方案比选充分。
   - **审批与授权分离**：决策机构只批"做不做、大致怎么做"，具体设计由设计单位承担。

5. **立项评审要点**
   - 评审组织：由投资决策部门或行业主管部门组织，必要时邀请专家、第三方评估机构、财政与审计部门参加。
   - 评审内容：战略与规划符合性、技术方案、经济效益、社会效益、合规性、风险、实施条件。
   - 评审纪律：评审意见须书面记录并随项目文件归档；对未落实整改事项的，评审组应明确"不通过"或"附条件通过并设前置条件"。
   - 常见违规：评审材料不全、时间不足、走形式、以"评审通过"替代决策程序、评审组成员与承建方存在利益关联未回避。

## 案例分析题

**题目**：

X市拟建设"城市生命线综合安全监测预警平台"，覆盖燃气、供水、排水、桥梁四类管网，涉及12个区县、约2800公里管网，计划2026年8月开工、2027年底前建成投运。

2026年3月，市发展改革委委托咨询公司编制可行性研究报告。报告结论为"技术成熟可行、经济效益显著"，主要数据如下：总投资8600万元（硬件设备4600万、软件开发2800万、系统集成与实施700万、第三方测评与安全加固500万）；建设期24个月，运营期5年；运营期年均运维费380万元；投产后每年可减少事故损失及停水停气停路损失约2100万元，第1至第5年净收益分别为1400、1900、2300、2500、2700万元；报告称按8%折现率计算净现值约3900万元，内部收益率18.5%，高于基准收益率10%，投资可行，建议尽快批准立项。

2026年5月，市审计局委托第三方评估机构开展项目评估。评估报告指出：一是可研所引用的管网事故损失数据为2019年统计口径，按2025年同口径测算已下降37%；二是运营期第1年运维费按380万元测算，未包含新建四类管网传感器的通信资费与电池更换费用；三是软件需求清单中约30%的功能与市已建成的"城市综合管理平台"重复；四是项目收益中计入了由建设单位另立项投资的管网改造工程节省额；五是拟建项目团队中仅1名架构师具有同类项目经验。评估结论为"暂缓，要求修改后重新报审"。

然而，项目推进小组在评估结论出具后仍按原方案推进招标前期工作，部分采购需求已发出。

**问题**：

1. 指出本案例在可行性研究、项目评估与立项决策三个环节存在的主要问题（至少列出6条），并分别说明对应的原则或程序要求。

**参考答案**：

#### 第1问：三个环节的主要问题（列10条）

**可行性研究环节（4条）**

1. **收益测算依据陈旧，未做数据更新**：可研引用2019年事故损失口径，未更新至2025年同口径数据。违反"效益测算应有现行、可靠、可核验依据"的要求，属测算依据失真，直接导致效益高估。
2. **运营成本漏项，长期成本测算不足**：只计380万元/年，未含新建传感器通信资费、电池更换、备品备件、许可年费等。违反"成本效益口径一致、必须覆盖全生命周期成本"的要求。
3. **重复建设，未做既有系统复用分析**：软件功能约30%与市已建"城市综合管理平台"重复，可研未作复用论证与投资对比分析。违反"技术可行性须考虑与既有系统的关系、避免重复建设"的要求。
4. **效益归集越界**：将"由建设单位另立项投资的管网改造工程"节省额计入本项目收益。违反"收益不得计入其他独立立项项目的效益、不得重复计入"的红线。

**项目评估环节（3条）**

5. **评估结论已出具但未执行**：评估出具"暂缓、修改后重新报审"意见后，项目推进小组仍按原方案推进招标前期工作并发出采购需求。违反"评估意见应作为决策前置约束、未落实整改不得进入下一程序"的要求。
6. **评估意见的整改闭环机制缺失**：未逐项明确责任单位、整改时限与验证方式，未建立跟踪销号机制。违反"评估出具修改意见时应逐项明确整改要求并跟踪闭环"的要求。
7. **第三方独立性与回避要求存疑**：评估由市审计局委托第三方机构开展，形式上满足独立性，但须核验评估人员与可研编制单位、原承建意向方是否存在关联，若存在须执行回避。此为本案的合规核查点，答题时按"须核查并回避"表述。

**立项决策环节（3条）**

8. **决策程序被架空**：项目推进小组以"评估结论不采纳"的方式实质上绕过了评估与决策程序。违反"决策不得跳过评估直接采信可研结论、重大投资未评估不得决策"的要求。
9. **在决策作出前提前启动实施**：采购需求已发出，属于决策未作出即进入实施，构成越权启动，违反"可研未通过、评估未通过、决策未作出，不得进入立项与实施"的红线。
10. **立项文件要件不完备**：缺少《项目建议书》《项目评估报告》《项目决策批复》等要件，且未附资金来源证明与用地、能耗等前置审批条件，违反"决策依据完备性检查"要求。

#### 第2问：处理路径（6条，标注环节）

1. **冻结实施动作**（立项决策环节）：立即暂停采购需求发布与招标前期工作，明确"评估意见未落实、决策未作出前不得启动实施"，防止事实上的既成事实倒逼决策。
2. **退回修改可研报告**（可行性研究环节）：由原编制单位针对五项评估意见逐项修订——更新事故损失数据至2025年同口径、补全通信与电池更换等运营成本、补充与既有平台的复用/替代比选、剔除他项目收益、补充建设期与运维期成本测算；修订后由原单位技术负责人与财务负责人签署确认。
3. **重新开展独立评估**（项目评估环节）：修订后可研须重新提交第三方评估机构复审，评估重点为修订项是否真实闭环；评估人员与原可研编制人员分离，涉及关联的回避。
4. **经济可行性重算与敏感性分析**（可行性研究环节）：按修正后的现金流重新计算净现值、内部收益率、投资回收期，并对投资额、运营成本、年收益、折现率四个敏感因素做临界点测算，形成"修改后立项/暂缓/不同意"的建议。
5. **优化建设方案以降低重复投资**（可行性研究环节）：将30%重复功能改为调用既有平台能力或对接复用，相应下调软件开发与集成投资估算并同步修订概算，形成"一平台复用、一套数据、一套运维"的建设方案。
6. **补强实施能力并设置前置条件**（可行性研究环节+立项决策环节）：针对架构师经验不足，通过引入具备同类经验的总集成方/外部专家、补充关键岗位招聘与培训、组织专项方案评审来化解；**若评估结论为"修改后立项"，须将上述整改事项逐项明确责任单位、完成时限与验证方式作为立项前置条件，未完成不予开工**。
7. **重新履行决策程序**（立项决策环节）：由市发展改革委或市政府投资决策机构重新组织评审，材料齐备后作出"接受/拒绝/推迟"决策，形成书面批复并下达项目章程。

#### 第3问：净现值与内部收益率计算及判断

**第一步：现金流量表（单位：万元）**

| 年份 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 净现金流 | -8600 | 1400 | 1900 | 2300 | 2500 | 2700 |
| 折现系数（10%） | 1.0000 | 0.9091 | 0.8264 | 0.7513 | 0.6830 | 0.6209 |
| 折现值 | -8600 | 1272.7 | 1570.2 | 1728.0 | 1707.5 | 1676.5 |

**第二步：净现值**

NPV = -8600 + 1400×0.9091 + 1900×0.8264 + 2300×0.7513 + 2500×0.6830 + 2700×0.6209
NPV = -8600 + 1272.7 + 1570.2 + 1728.0 + 1707.5 + 1676.5 = **-645.0万元**（约-644.98万元）

**第三步：内部收益率**

由 NPV = 0 反解：**IRR ≈ 7.30%**（用8%试算：NPV(8%) = -173.8万元 < 0；用7%试算：NPV(7%) ≈ +77.7万元 > 0，故 IRR 介于7%与8%之间，精确值约7.30%）

**第四步：判断结论**

- 净现值 -645万元 < 0，项目在基准收益率10%下**不具备财务可行性**。
- 内部收益率7.30% < 基准收益率10%，同样**不满足立项条件**。
- 结论：**不应按原方案立项**。应退回修改（重算收益成本、消除重复建设、降低投资）后重新论证；若修订后仍不满足，则应暂缓或不予立项。
- 补充说明：按可研报告"8%折现率、净现值约3900万元"的表述复算，实际 NPV(8%) ≈ -173.8万元，**与报告结论相差约4074万元**，说明可研在折现率选取、现金流口径或测算过程上存在严重问题，须全面复核。

**敏感性提示（可直接作为答题采分点）**

- 收益下修37%（采用2025年同口径）：净现值由-645万元降至约 **-3588万元**，项目彻底不可行。
- 年净收益临界值（8600万投资、10%、5年）：**临界年净收益 ≈ 2268.66万元**。本案第1年1400万元远低于临界值，说明现金流入前重后轻，前两年现金流无法覆盖投资，是IRR仅7.3%的根本原因。

#### 第4问：可研自身收益口径的重算与表述问题

**重算结果**

- 按等额年金法：年金现值系数（P/A, 10%, 5）= 3.7908
- NPV = 2100×3.7908 - 8600 = 7960.7 - 8600 = **-639.3万元**（约-639.35万元）
- 内部收益率：2100×(P/A, r, 5) = 8600 → **IRR ≈ 7.05%**
- 结论：NPV < 0、IRR < 10%，**仍不可行**。

**与第3问口径相比存在的表述问题（四条）**

1. **现金流起点错位**：可研口径"每年净收益2100万元"未明确是第1年还是运营期内各年，也未说明第0年投资是一次性投入还是分期；第3问口径明确"第0年一次性投资8600万、第1至第5年净现金流逐年递增"，两者的收益合计差异巨大（第3问5年合计10800万，第4问口径5年合计10500万），且时间分布不同，直接影响现值，必须在可研中以规范现金流量表列示，不能只用"每年净收益"一句话概括。
2. **混淆了"每年减少损失2100万"与"每年净收益2100万"**：题干中2100万元是"减少的事故损失及停水停气停路损失"，属于**效益**，不是扣除运营成本后的净收益；可研把它直接当作净收益参与财务评价，**漏减运营成本380万元/年**，这是口径错误而非表述问题，属实质性测算错误。
3. **折现率与内部收益率的表述不严谨**：报告称"按8%折现率计算净现值约3900万元，内部收益率18.5%"，但内部收益率是使净现值等于0的折现率，与计算净现值所用的折现率是两个不同参数，不应并列使用同一折现率语境；且18.5%与任何口径下的实际值（7.05%～7.30%）相差悬殊，属测算结论失实。
4. **未给出关键评价指标与敏感性的完整呈现**：仅有NPV与IRR两项，且未给投资回收期、年金净流量、现金流累计曲线、敏感因素与临界点，无法判断项目抗风险能力；财务评价章节缺少"总投资收益率"等辅助指标与基准收益率的确定依据说明。

**踩分要点**：

1. **答第1问时按"环节—问题—对应原则"三段式写**，每条问题后必须跟上原则或程序要求的出处（如"决策不得跳过评估""收益不得计入他项目效益""成本须覆盖全生命周期"）。只罗列问题不写对应原则，通常只能拿一半分。
2. **必须点出"评估结论未落实仍推进实施"这一核心矛盾**，这是本案最明显的程序违规点，也是案例题的"题眼"，务必放在第1问前列。
3. **算题的三个数字要写全**：NPV = -645万元、IRR ≈ 7.30%、临界年净收益 ≈ 2268.66万元；第4问 NPV = -639.3万元、IRR ≈ 7.05%。写不出IRR时至少写"IRR介于7%与8%之间且低于10%"，仍可拿计算过程分。
4. **判断结论要落到"不应按原方案立项"**，并写明退回修改/重新评估/重新决策的处理路径，不能只写"经济上不可行"。
5. **可研的"数据陈旧""运营成本漏项""重复建设""收益跨项目归集"四条要逐条对应到技术可行性、经济可行性两个方面的可行性要求**，体现四方面内容（技术、经济、社会与法律、组织与实施）的框架意识。
6. **注意收益口径的偷换**：题干中2100万元是效益（减少损失），不是净收益，可研将其当作净收益是"漏减运营成本"的实质性错误。这一点答出是区分高分的关键，多数考生会直接拿2100万元当净现金流算。
7. **同类可复用结论**：净现值随折现率升高而降低；内部收益率受现金流规模影响；互斥方案不得直接用内部收益率排序；初步可研是详细可研的前置，详细可研是决策的主要技术经济依据。

## 记忆口诀

1. **立项四环定位**：可研自证、评估复审、决策拍板、立项开工令；自编自评不合规，评估未落实不得进。
2. **可研三层递进**：机会看方向、初可看条件、详可看方案与账；逐层收敛，上层不成立不再下探。
3. **详可四方面**：技术是前提、经济是核心、社法是底线、组织是保障；合规不过，一票否决。
4. **估算精度三级**：建议书匡算±20~30%，初设概算±10~15%，施工图预算±5%；概算超可研即重大问题。
5. **财务三指标**：净现值≥0才可行，内部收益率≥基准才行，回收期越长风险越大；净现值随折现率升而降，互斥方案不按内部收益率排序。
6. **收益口径三红线**：不跨他项目、不重复计、不漏运营成本；效益与净收益必须分清。
7. **评估五方面**：目标、技术、经济、社会效益、管理，追加风险；结论四档：同意、改后、暂缓、不同意。
8. **决策三类型**：接受、拒绝、推迟；审批与授权分离，决策只定做不做与大致怎么做。
9. **管理科学常数**：年金现值系数（10%，5年）=3.7908，8600万÷3.7908≈2268.66万——低于此数即不可行。
