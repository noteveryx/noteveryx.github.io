## 今日核心概念

### 1. 外部监督体系与监理的法定定位边界

**定义**：政府信息化项目在建设全周期内，除建设单位与承建单位、监理单位三方合同关系之外，还存在审计机关、财政投资评审中心、纪检监察、人大监督、社会举报与第三方检测评估等多条外部监督线。监理的定位由《建设工程监理规范》与信息系统工程监理相关规范共同确定：监理是受建设单位委托、依据合同对工程质量、进度、投资、变更与验收实施过程监督的第三方技术服务主体。

**关键要点**：

**（1）外部监督六类主体与各自的"专属结论域"**

1. 审计机关：财政资金使用、国有资产损益、领导干部经济责任 → 结论域是"钱是否合规、资产是否真实、责任是否落实"
2. 财政投资评审中心 / 项目评审中心：概算、预算、结算的审核 → 结论域是"价格是否合理、计价是否准确"
3. 纪检监察：廉政与廉洁、"三重一大"决策程序 → 结论域是"程序是否合规、有无利益输送"
4. 人大监督（质询、专项审计委托）：公共投资绩效与民生成效 → 结论域是"钱花得值不值、目标有没有实现"
5. 社会监督与举报：群众与媒体线索 → 结论域是"线索是否属实、是否需要立案核查"
6. 第三方检测与测评机构：技术合规性（等保测评、密评、软件测评、软件产品检测） → 结论域是"技术指标是否达标"，其报告是法定技术依据

**（2）监理的权限三分法（高频考点）**

- 有：调查取证权（调阅资料、旁站见证、平行检验、发通知单、要求整改、提出书面意见）
- 无：认定权（无认定违规、认定损失、认定责任的权力）
- 无：处置权（无处罚权、扣款决定权、行政处理权）
- 有：意见出具权（出具监理通知单、工作联系单、监理月报、专题报告、验收与移交意见），但意见是"专业意见"不是"行政决定"

**（3）四句边界台词（答题可直接引用）**

- 监理只对"合同履行与工程质量"发表专业意见
- 审计只对"财政资金与国有资产"发表监督意见
- 评审中心只对"概算、预算、结算金额"发表审核意见
- 纪检监察只对"廉洁与决策程序"发表监督意见

**（4）监理在配合外部监督时的"四不得"**

1. 不得自行组织审计、不得以"内部专项检查"名义代行审计职能
2. 不得在审计报告、审计确认单上签字背书或代签
3. 不得用审计结论替代合同判定（也不能用监理结论否定审计在资金领域的事实认定）
4. 不得向审计机关提供未经核实的推测性结论、内部草稿与主观评价

**（5）冲突时的原则**：同一事项上，审计机关对"资金与合规"的认定、评审中心对"计价"的认定优先采信；监理对"专业技术质量与过程合规"的专业判断优先采信；两者都不冲突时合并使用形成完整结论；冲突时以"事实与证据"为最终裁决依据，而非以权威层级为依据。

**（6）监理与审计的互补关系**：审计是"事后看账、抽样查证"，监理是"过程在场、逐项见证"。审计查出的问题往往正是监理过程记录能证明或不能证明的"有无履职证据"问题。因此监理的日常过程记录质量直接决定审计时的履职抗辩能力——记录缺失等于监理自认失职。

### 2. 审计发现的转办机制与"双轨整改"闭环

**定义**：审计机关在审计过程中发现的问题线索，通过《审计整改通知书》《审计决定书》《审计移送单》《审计专报》等形式转交被审计单位（建设单位），由建设单位按职责分解至监理、承建单位等责任主体并组织整改。监理对审计转办事项既不能全盘接收、也不能全盘推诿，须按"事实—性质—职权"三重判定进行分类转化。

**关键要点**：

**（1）问题来源七类**：审计发现、财政评审意见、纪检监察移交、巡视巡察反馈、群众举报转办、内部质量自查、上级主管部门检查。其中只有前两类与监理日常履职最直接相关。

**（2）分类转化矩阵（核心，务必背下来）**

| 审计发现性质 | 是否属监理职权 | 监理应采取的动作 |
| --- | --- | --- |
| 承建方未按合同/规范施工，质量缺陷 | 是 | 直接发监理通知单，纳入质量整改闭环，跟踪复核直至销号 |
| 工程量不实、计价错误、超概算 | 部分 | 退回承建方结算申请，重新分项计量审核，出具计量审核意见并书面报建设单位；扣款由建设单位按合同决定 |
| 合同外违规采购、拆分规避招标 | 否 | 书面报建设单位与相关主管部门，监理不作处理结论 |
| 承建方商业贿赂、利益输送 | 否 | 报建设单位，按建设单位要求移交纪检监察，不作定性 |
| 决策程序违规（"三重一大"未集体决策） | 否（但有见证义务） | 出具程序性审查意见与异议记录，报建设单位 |
| 监理自身履职不到位 | 是（反向） | 立即启动自查整改，涉及人员责任的按规定处理并报监理单位，必要时主动回避相关事项 |
| 行业性、系统性、共性问题 | 否 | 报监理单位与行业协会，纳入内部质量审核与经验反馈 |

**（3）双轨并行台账**

- 审计整改台账（审计机关口径）：问题编号、审计定性、整改要求、完成时限、销号结论
- 监理整改台账（合同口径）：问题编号、监理定性、整改措施、验证方法、关闭结论
- 两条台账须做编号映射，四种状态对应关系要能说清：

| 审计口径 | 监理口径 | 说明 |
| --- | --- | --- |
| 已整改并销号 | 整改验证通过并关闭 | 可对应 |
| 已整改未销号 | 整改验证通过待确认 | 监理可先关闭，审计可再销号 |
| 整改中 | 整改中 | 对应 |
| 审计认定为"未整改/整改不彻底" | 监理认为"已整改" | 典型冲突，必须按第 3 个概念处理 |

**（4）闭环六步（答题标准动作链）**

1. 接收转办 → 登记并确认接收范围与时限
2. 核实事实 → 现场复核、比对旁站记录、见证记录、影像资料、计量审核记录，区分"事实是否成立"与"定性能否接受"
3. 分类定性与责任界定 → 按分类转化矩阵判定职权归属（监理能办、需转报、需报备）
4. 发文处置 → 监理通知单（质量问题）/ 工作联系单（过程纠偏）/ 专题报告（重大问题报建设单位）/ 暂停令（严重且具备合同依据时）
5. 跟踪验证 → 对整改措施逐项复核并留存复核证据（影像、记录、复测报告）
6. 销号归档 → 出具监理确认意见，纳入监理档案并与审计台账做编号映射

**（5）四个关键区分（易混点）**

- 审计整改销号 ≠ 监理验收合格（销号是行政闭环，验收是合同履行的技术结论）
- 审计未列入问题 ≠ 监理认可该项目合格（抽样未覆盖不等于无缺陷）
- 监理"未发现" ≠ "未发生"（监理未见证的部位与环节，若无记录一律按无证据处理）
- 监理已发现但未报告 = 自认失职（丧失履职抗辩基础）

**（6）保留异议的正确方式**：监理对审计的定性表述有不同意见的，不在正式报告正文中公开反对，也不得隐瞒。正确做法是：在监理出具的正式文件中只写核实后的事实与依据（"经核查……"），将不同意见写入《监理专题报告》或书面保留意见并报建设单位，由建设单位向审计机关沟通；监理保留"依据不足""定性超出证据范围"的书面表述。

### 3. 审计结论与监理结论的边界与冲突处理

**定义**：同一事项上，审计机关与监理单位可能得出不同结论。冲突处理的正确路径是"先分域、再核证、后定主次、书面留痕"，而不是争论权威大小，也不是简单服从。

**关键要点**：

**（1）冲突四型**

1. **口径冲突**：统计范围不同（是否含税、是否含可选项、是否含运维费）、时间口径不同（以合同签订日还是验收日为准）、数据来源不同（财务账 vs 监理计量台账 vs 系统流水）
2. **事实冲突**：是否发生（监理旁站记录显示完成，审计以未见实物/未见记录否定）、金额冲突、主体冲突（责任在承建方还是监理方）
3. **责任冲突**：审计认定为承建方主责，监理记录显示建设单位变更导致；或审计认定监理未履职，监理有旁站记录反驳
4. **结论冲突**：审计认定为"违规未整改"，监理认定为"已整改并验证通过"

**（2）采信规则五步（写进案例答案的关键流程）**

1. 查合同依据 → 该事项在合同条款、监理规范条款中如何约定，约定优先于习惯理解
2. 查证据链 → 监理旁站记录、见证取样记录、平行检验记录、影像资料、报审表、会议纪要是否形成闭环（谁记录、何时记录、能否对应具体部位与具体时间）
3. 查时序 → 谁先发现、谁先报告、报告后有无处置，处置是否闭合（"知情不报"与"报告后未跟踪"是两种不同的责任）
4. 定主次 → 区分直接责任、主要责任、次要责任、管理责任；区分承建方责任、建设单位责任、监理责任
5. 书面留痕 → 形成《监理意见分歧说明》，列明事实、依据、计算、结论建议，报建设单位；涉及金额的给出明确计算过程

**（3）监理专业意见的固定输出结构（四段式）**："事实—依据—计算—建议"。这是监理意见区别于审计结论、也区别于个人表态的关键形式，也是案例题的踩分结构：

- 事实：经核查的客观情况（做了什么、在什么部位、什么时间、什么数量）
- 依据：合同条款、规范条款、记录编号、影像编号
- 计算：金额、数量、比例的计算过程与公式
- 建议：供建设单位决策的处置建议（返工、扣减、索赔、追责、后续预防措施）

**（4）金额争议的处理纪律**

- 监理不得依据审计结论直接在进度款/结算中扣款（扣款是建设单位的合同权利）
- 监理只出具"计量审核意见 + 质量缺陷处理意见"，由建设单位据此决定扣款
- 监理对有争议部分应采取"无争议先支付、争议部分暂缓"的分离处理建议（若合同允许），避免以争议卡死全部工程款

**（5）举证责任的现实分配**：审计机关对"资金问题"举证；监理单位对"已履职"举证。因此监理的过程记录必须可举证（真实、完整、连续、可辨识签署人、不得倒签）。

### 4. "三重一大"决策与信息化项目合规性审查

**定义**："三重一大"指重大事项决策、重要干部任免、重要资金使用、重大项目安排决策。在信息化项目中，"三重一大"通常由党委会、董事会、院长办公会、总经理办公会等集体决策载体承载。监理对"三重一大"的介入是程序性见证与合规性审查，不是决策本身，也不对决策的必要性、正确性作实体判断。

**关键要点**：

**（1）信息化项目中的"三重一大"事项清单（12项，高频）**

1. 大额信息化建设项目的立项决策
2. 项目建设方案的重大调整或整体重构
3. 承建单位、监理单位的选定与中途更换
4. 超出合同范围的重大功能增减、重大软硬件替换
5. 变更金额超过合同价一定比例（如 10%）或单笔超过一定额度的事项
6. 运维服务的续约、终止与重大变更
7. 数据共享授权、对外数据开放、重要系统上云下线的重大决策
8. 信息化资产处置、报废与移交
9. 运维费用、维保费用的年度预算重大调整
10. 重要岗位人员任免（含项目经理、监理负责人更换的审批）
11. 建设项目专项资金的大额调整与结余处理
12. 与重要合作方的框架协议与长期采购安排

**（2）监理审查三步法**

1. 识别 → 是否属于"三重一大"目录事项，是否达到本单位的金额/事项阈值
2. 核查程序 → 是否经过集体决策载体审议；是否有会议纪要、决议编号、签到表、表决记录；是否为"一把手"个人决定（形同个人决策）
3. 核查留痕 → 决议内容与实际实施内容是否一致；实施时间是否在决议授权范围内；变更是否重新履行决策程序

**（3）违规典型七类（案例答案的高分点）**

1. 先实施后补纪要（倒签会议纪要、倒签日期早于实施日期）
2. 纪要内容与实际实施不符（决议写 A、实施做 B）
3. "以签代决"——只有签字页无讨论记录、无表决结果
4. 化整为零规避集体决策与招标（把一个项目拆成多个低于阈值的包）
5. 以"技术紧急"为由绕开决策程序（紧急不等于免程序，事后仍须补批并说明理由）
6. 变更未重新履行决策程序（重大变更直接实施，仅走合同变更流程）
7. 会议纪要与实际执行时间矛盾（纪要日期晚于采购合同签订日、晚于设备到货日）

**（4）"拆分规避"识别五要素（判定化整为零）**：同一预算年度 + 同一业务目标 + 同一承建方或同一系统 + 连续时间窗内 + 内容实质相同。五个要素同时成立，监理应提出"疑似拆分规避"书面意见并报建设单位。

**（5）监理的程序性审查边界**：监理只能出具"是否按已批准决议实施""决议程序要件是否齐备"的技术性意见，不得对决策的必要性、合理性、可行性作实体评价，不得参与表决，不得代为起草或补签纪要。

**（6）留痕四件套**：决策依据文件（立项批复、可研、方案、测算）+ 集体决策记录（会议纪要/决议及编号）+ 签到与签字记录 + 监理审查记录与异议记录。缺任一件即构成监理履职证据不完整。

### 5. 监理配合审计的证据供给与档案调阅规范

**定义**：审计机关依法对项目实施单位进行审计时，有权调阅与项目有关的会计资料、合同、验收资料、监理资料等。监理单位负有配合义务，但配合义务有边界、有程序、有保密要求，履行方式直接决定监理既能否自证清白又不越权泄密。

**关键要点**：

**（1）证据供给七类（监理能提供的全部范围）**

1. 监理规划文件（监理规划、监理实施细则、监理大纲）
2. 过程记录（四控三一：旁站、巡视、平行检验、见证取样、例会纪要、通知单、工作联系单）
3. 计量与支付审核记录（报审表、计量审核意见、支付审核意见）
4. 变更与签证文件（变更申请、变更通知单、变更价款审核单、签证单）
5. 验收与移交文件（初验意见、终验意见、遗留问题清单、移交清单）
6. 会议与函件（建设、设计、承建、监理四方或五方往来函件）
7. 质量与安全记录（质量事故处理、缺陷台账、复测复验记录）

**（2）调阅流程五步**

1. 接收调阅函 → 核验主体资格（单位名称、公章、法定代表或授权书）、调阅范围、时限
2. 登记造册 → 建立调阅台账，逐项登记文件名称、份数、页数、复制方式、经办人
3. 复制交付 → 一律复制不交原件；原件需现场查看的，做好登记并由对方签字确认
4. 签收回执 → 取得接收人签字或盖章回执，纳入监理档案
5. 归档留存 → 调阅清单与交付副本一并归档，形成完整履职证据链

**（3）不得提供的六类**

1. 未经审核的内部草稿、内部讨论稿、征求意见稿
2. 超出委托范围、涉及其他单位商业秘密的资料
3. 涉及国家秘密与工作秘密的载体（按保密规定处理，不得擅自复制）
4. 未脱敏的个人信息与敏感字段材料（需脱敏的按最小必要提供）
5. 未经第三方授权的检测、测评机构原始工作稿
6. 监理单位内部对个人的绩效评价、人事考核材料（属单位内部管理事项，与项目无关）

**（4）脱敏四原则**：最小必要（只提供审计所需字段）、去标识化（个人信息替换为编号）、可逆可控（映射表由监理单位单独保管，不随材料交付）、留痕可审（提供前记录脱敏处理清单）。

**（5）配合与独立性的平衡**：配合审计不得成为停止日常监理职责的理由。典型违规是"建设单位要求配合审计，监理就停发通知单、停止整改跟踪、暂缓全部计量审核"，导致监理后续在审计中被认定"未履职"或"与承建方串通"。正确做法是：审计事项单独成轨、常规监理事项照常推进，两者以台账映射方式衔接。

**（6）档案权属与配合义务的关系**：监理机构档案的所有权归监理单位；项目档案按合同与《建设工程文件归档规范》向建设单位移交；审计机关调阅属于法定履职行为，监理应予配合。档案移交完成不影响监理配合审计的义务，但涉及原件交付须按移交清单核对签收。

---

### 6. 常考陷阱三条（必须记住的"三不"）

1. **审计发现转办 ≠ 监理责任免除**：审计未列入的部位，若监理本应见证而无记录，审计转办其他事项时一并追责；监理的免责依据只能是"已履职且可举证"，不能是"审计没查我"。
2. **审计结论优先 ≠ 监理结论作废**：审计对资金与合规的认定、监理对专业技术质量与过程合规的认定，适用对象不同，不可互相替代引用；案例中常写"以审计最终认定为准"作为错误答案。
3. **"三重一大"程序瑕疵 ≠ 项目整体无效**：监理只能提出程序性异议与整改建议，不得否定技术成果的可用性；同样，项目成果有效也不能掩盖决策程序违规，程序违规应单独记录并报告。

## 案例分析题

**题目**：

某市"城市大脑与一网统管"二期信息化项目，建设单位为市大数据管理局，承建单位为甲公司，监理单位为乙公司，项目总合同价 12800 万元（软件开发 6200 万元、硬件采购 3100 万元、集成实施 2300 万元、运维服务首年 1200 万元），监理服务费 168 万元。合同约定：监理单位按《建设工程监理规范》GB/T 50319 承担质量、进度、投资三控及合同、信息管理职责；变更累计超过合同价 10% 须报建设单位党委会集体决策；审计机关对项目实施情况有权专项审计。

项目实施期间发生以下情况：

**一、审计发现与转办**

2026 年 8 月，市审计局对项目实施专项审计，出具《审计整改通知书》列出 9 项问题并抄送建设单位。其中：
- 第 3 项：2026 年 3 月开发环境扩容 46 台服务器，单价 2.1 万元，合计 96.6 万元，承建方甲公司凭《工作联系单》报审并已由乙公司监理签认，审计认定"未履行集体决策程序即实施变更"。经查，乙公司监理工程师 3 月 12 日已书面提示建设单位"本项变更累计金额接近合同价 10%，建议提请集体决策"，但建设单位仅回复"先实施后补手续"。
- 第 5 项：承建方提交的 2026 年 6 月《软件开发进度款报审表》金额 780 万元，乙公司监理审核意见为"经复核，本期完成工作量 712.4 万元，扣减未完成模块 67.6 万元，同意支付 712.4 万元"。审计抽查认为已完成工作量为 690 万元，差额 22.4 万元未计量。
- 第 6 项：甲公司与某供应商签订 320 万元数据采集服务采购合同，未履行政府采购程序，审计认定为"违规采购"。
- 第 7 项：乙公司总监张某同时在甲公司担任技术顾问（兼职，有书面协议、有社保但不在甲公司现场办公），未在监理月报中披露。

**二、监理过程情况**

- 项目实施期内乙公司共形成旁站记录 214 份，其中 31 份无影像资料，9 份签署日期早于记录事项发生日期（倒签），其余过程记录均能与部位、日期对应。
- 2026 年 5 月发生 P1 级故障 1 次，导致全市 12 万条办件状态错乱，持续 3 小时 40 分。乙公司当日出具《监理工作联系单》要求承建方整改并复测，但未发《监理通知单》，未向建设单位书面报告，直至审计抽查时才发现。
- 乙公司 2026 年 7 月月报记载："本月光纤链路割接已完成，材料已到位，系统运行正常"，但审计发现该批光缆实际未到货，割接也未实施。
- 乙公司对第 5 项 22.4 万元差额的复核依据，是承建方甲公司提交的《月度工作量确认单》和一份系统截图，未做现场复测。

**三、建设单位要求**

市大数据管理局书面要求乙公司：一是"全力配合审计，逐项书面确认审计认定结论"；二是"在审计结论确定前，暂停签发所有监理通知单和计量审核意见"；三是要求乙公司总监张某回避本项目全部工作。

**四、问题**

1. 请指出审计转办的 9 项问题中，监理单位应当直接处理、应当书面转报、应当履行见证义务而不能自行处理的三类归属，并说明监理对第 3 项变更问题应出具何种监理意见（按"事实—依据—计算—建议"四段式作答要点）。
2. 针对第 5 项 22.4 万元计量差额、审计与监理在完成工作量认定上的差异，监理应如何处理？可否直接按审计认定的 690 万元调整计量？如认为审计结论与监理记录不符，监理应采用何种方式表达？
3. 乙公司在 P1 故障处理、月报失真、总监兼职未披露三方面存在哪些履职问题？应承担什么后果？建设单位要求总监张某回避是否合规？
4. 针对审计发现的"集体决策程序缺失"和"规避政府采购"问题，监理的合规性审查应如何开展？"三重一大"事项的识别标准是什么？"拆分规避"的五个判定要素是什么？
5. 建设单位要求乙公司"逐项书面确认审计认定结论"和"暂停签发监理通知单与计量审核意见"，这两项要求是否妥当？监理应如何应对？乙公司向审计机关提供资料时应遵循什么调阅流程？哪些资料不得提供？

**参考答案**：

**第 1 问**

第一类，监理应当直接处理（属合同与监理职权范围）：第 5 项计量不实所反映的计量审核问题，以及由其衍生的进度款审核问题。监理应复核本期完成工作量，重新出具计量审核意见，按《计量审核意见》扣减未完成部分（712.4 万元调整为 690.6 万元，扣减 21.8 万元，若以审计抽查的 690 万元为准则为 22.4 万元），并对未完成模块发出《监理通知单》要求整改，整改后复测验证。

第二类，监理应当书面转报：第 6 项（320 万元数据采集服务采购未履行政府采购程序），监理无权认定"违规采购"，应书面报建设单位并按建设单位要求转报纪检监察或相关主管部门；第 7 项（总监兼职未披露），监理应向本监理单位书面报告并报建设单位，同时按监理单位规定对总监进行回避与处理。

第三类，监理应当履行见证义务而不能自行处理：第 3 项集体决策程序问题。监理已履行程序性提示义务（三月书面提示），后续仅能做三件事：一是核实并记录事实（决策程序未实际履行、实施先于程序、监理提示记录在案）；二是就"监理提示在前、建设单位决定在后"这一事实作出书面说明，防止事后被认定为监理共同违规；三是就审计对本项变更的定性表述出具意见，意见内容限于事实与依据（即监理已于 3 月 12 日书面提示，建议提请集体决策，建设单位回复先实施后补手续）。

监理意见按四段式撰写：
- 事实：3 月 5 日建设单位签发变更实施指令；3 月 12 日乙公司监理工程师书面提示"本项变更累计金额接近合同价 10%，建议提请集体决策"；3 月 18 日甲公司进场实施并于 3 月 26 日完成扩容；至审计日，乙公司未收到集体决策纪要，仅在 4 月 10 日收到建设单位《情况说明》；变更累计金额 96.6 万元，占合同价 12800 万元的 0.755%，与合同约定的"累计超过合同价 10%"（即 1280 万元）阈值相比未达该触发条件。
- 依据：合同第 24 条变更条款；GB/T 50319 关于监理提出书面意见、报建设单位决策的规定；乙公司 3 月 12 日《监理工作联系单》（编号 2026-03-12-007）；建设单位 3 月 13 日《回复函》；合同第 12 条"涉及本单位重大事项须经集体决策"的表述未在合同中具体化阈值。
- 计算：本项变更金额 96.6 万元 = 46 台 × 2.1 万元/台；占合同价比例 96.6 ÷ 12800 = 0.755%；合同 10% 阈值为 1280 万元，本项未触达该阈值；如以本次 9 项问题合并计算亦未达阈值。同时须说明：本项目变更累计口径为"单项 96.6 万元"还是"全周期累计"，合同未定义，监理不能自行按对自己有利口径计算。
- 建议：一是建议建设单位明确"重大变更"与"集体决策"的量化阈值与累计口径，并在合同变更台账中固化；二是对已发生且不可逆的变更，补履行决策程序并形成纪要（不得倒签），纪要应载明补办原因与实际实施时间；三是建议对"先实施后补手续"的成因开展责任认定，明确建设单位决策责任；四是建议建立"变更触阈值预警"机制，由监理在累计变更达到合同价 5% 时出具预警提示。

注意：监理不得在意见中直接使用"审计认定违规"或"审计认定监理失职"等表述，不得否定审计机关在程序审查方面的关注点，也不得在意见中对决策的必要性作实体评价。

**第 2 问**

不可直接按审计认定的 690 万元调整计量。理由有三：
其一，监理在计量审核中的角色是独立计量、复核与出具意见，审计抽查是监督手段，两者的抽样范围、核对方式、时点不完全一致，审计结论可以作为重要参考和重要依据，但不能自动替代合同计量审核程序；
其二，监理若在审计结论下发前直接按 690 万元调整，将丧失复核取证机会，且此前出具的 712.4 万元审核意见将因未说明理由而被认定失据；
其三，监理对 22.4 万元的复核依据本身不充分——仅有承建方自报的《月度工作量确认单》和一张系统截图，无现场复测、无功能点逐项核验记录，属"以单方确认单作为计量依据"。

正确处理路径：
1. 重新组织计量复核：按功能点清单逐项现场复测，核对开发任务完成记录、缺陷关闭记录、测试用例通过记录、演示记录，形成《计量复核记录》并要求甲公司、监理、建设单位三方签认；
2. 对无法现场复测的历史工作量，采取源代码提交记录审查、版本库提交日志比对、第三方测试报告比对等替代验证方式，并说明验证局限；
3. 出具《监理计量复核意见》，明确监理认定的完成工作量、扣减金额、依据与计算过程；若复核结果与审计抽查值一致，则以复核结果为准并在意见中说明与审计的一致性；若不一致，则在意见中如实载明差异与理由，不回避；
4. 计量分歧部分单独挂账，按合同约定提出"无争议部分先行支付、争议部分暂缓"的处理建议，不以争议卡死全部工程款。

表达差异的方式：出具《监理意见分歧说明》，采用"事实—依据—计算—建议"四段式，列明监理认定的完成工作量、依据的记录编号、计算过程，以及与审计抽查值的差异金额（21.8 万元或 22.4 万元，按复核结论确定）；同时说明监理愿意配合审计就争议项补充取证，但不否定审计机关在其监督职责范围内的认定；对定性表述有不同意见的，采用书面保留方式报建设单位，不在正式监理文件中公开反对，也不得隐瞒。

**第 3 问**

P1 故障处理方面：P1 级故障（全市 12 万条办件状态错乱、持续 3 小时 40 分）属重大质量事件，监理仅发《监理工作联系单》、未发《监理通知单》、未向建设单位书面报告，违反监理规范关于重大质量问题应及时发出监理通知单并报告建设单位的义务。后果：监理未在该事件中有效履职，构成"未有效履职"；审计一旦认定该事件当时未告知建设单位，监理将丧失就该事件的全部履职抗辩基础，且可能被认定为隐瞒问题。正确做法应为：当日发《监理通知单》并抄报建设单位、要求承建方 24 小时内提交原因分析与整改方案、整改后复测验证、纳入月度质量分析与事故台账。

月报失真方面：7 月月报记载"光纤链路割接已完成，材料已到位，系统运行正常"，与审计查明的"光缆未到货、割接未实施"直接矛盾，且未按"重大事项不得虚假记载"要求说明。这是虚假监理文件，直接构成监理文件的真实性问题；同时说明乙公司 214 份旁站记录中 31 份无影像、9 份倒签，已构成记录链条的系统性瑕疵。后果：监理月报作为过程履约的重要证据，一旦被认定失真，其整体证明力将大幅削弱；倒签记录属于不可修复的证据缺陷，相关旁站记录应作为无效证据处理，不得据此主张已履职。

总监兼职未披露方面：张某在甲公司担任技术顾问，虽有书面协议、社保关系不在甲公司现场办公，但未在监理月报中披露，属执业风险与执业信息披露义务的违反；更关键的是构成"独立性与回避"风险——总监作为甲公司的技术顾问，与被监理方存在利益关联，监理意见的独立性受到质疑。后果：乙公司应向建设单位书面报告并主动提出更换总监理工程师或采取回避措施；在张某履职期间的监理意见（尤其计量审核意见）需做独立性复核，必要时重新出具。

建设单位要求总监张某回避是否合规：合规，且方向正确，但处理方式不完整。要求回避本身符合《建设工程监理规范》关于总监理工程师不得与被监理单位存在利害关系、存在利害关系应当回避的要求。但不能"回避本项目全部工作"而无人接手——回避须由乙公司另行指派具备相应资格与能力的总监理工程师或由建设单位依法委托具备相应资质的监理单位承担，并完成监理工作交接与资料移交，形成书面交接记录；同时对张某已签署的监理文件应由新任总监复核确认，必要时重新签发。回避不能免除乙公司对既往履职瑕疵的责任。

**第 4 问**

监理开展合规性审查的做法：
1. 编制本项目《三重一大事项识别清单》，按建设单位党委会、董事会等决策载体及其议事规则，列明需集体决策的事项类型与金额阈值，报建设单位确认后固化在监理规划中；
2. 在实施方案、变更指令、采购启动、合同签订、到货验收、割接上线等关键节点设置"决策文件核验"检查项：核对决策载体名称、审议日期、决议编号、签到表、表决结果；
3. 核验时序：决策日期必须早于（或至少不晚于并有合理解释）实施日期；采购合同签订日、设备到货日、系统割接日均应晚于决策日期；
4. 核验内容一致性：决议标的、数量、金额与实际实施是否一致，不一致的按"决议与实施不符"单独记录；
5. 形成审查记录并出具意见：合规的记入监理月报；存在瑕疵的出具《监理工作联系单》要求补正并说明理由；对涉嫌规避的，出具《监理专题报告》报建设单位，同时抄报审计与纪检监察线索的移交由建设单位决定，监理不作定性。

"三重一大"事项识别标准：分两层判定。第一层是事项属性——是否属于重大事项决策、重要干部任免、重要资金使用、重大项目安排决策这四类之一，在信息化项目中表现为立项、重大方案调整、承建与监理单位选定与更换、超阈值变更、运维续约与终止、数据授权与开放、重要系统上下线、信息化资产处置、超预算重大调整等。第二层是阈值判定——按建设单位《"三重一大"决策制度》或议事规则规定的金额标准与事项清单逐项比对；监理只能依据建设单位书面提供的制度文本和授权清单判定，无制度文本支撑时不得自行拟定阈值，应书面要求建设单位提供。

"拆分规避"的五个判定要素：
1. 同一预算年度
2. 同一业务目标（服务于同一个建设目标或同一业务场景）
3. 同一承建方或同一系统（同一供应商，或同一软件系统/同一集成范围）
4. 连续时间窗内（通常按同一项目周期或同一年度内连续发生）
5. 内容实质相同（标的、用途、技术路线、交付物实质一致）
五要素同时成立时，监理应提出"疑似拆分规避集体决策与采购程序"的书面意见并报建设单位，同时说明该意见为程序性提示、不含违规定性，由建设单位与相关主管部门认定。

**第 5 问**

两项要求均不妥当。

"逐项书面确认审计认定结论"不妥当。理由：监理是受委托提供专业意见的第三方，不具备对审计监督结论作出确认或背书的职权；审计结论涉及对被审计单位的责任认定，超出监理合同与执业范围；若监理逐项签字确认，则形成监理与审计共同认定的外观，可能被认定为"以监理确认替代审计认定"，若日后审计结论被撤销，监理将承担连带的专业责任风险，且监理作为被监督对象参与确认监督结论，违反独立性原则。正确做法是：监理在审计指定期限内就每一项问题出具《监理核查意见》，内容包括"经核查，监理过程记录显示的事实与依据"，对监理记录能够证明的事项如实确认，对监理记录不能证明的事项明确说明"监理无过程记录，不作确认"，对定性表述有不同意见的以书面保留方式说明，全文报建设单位，由建设单位与审计机关沟通。监理不得在审计确认单、审计决定书或任何以审计机关名义出具的文件上签字。

"暂停签发监理通知单与计量审核意见"更不妥当，且违反监理法定职责。理由有三：一是监理的三控职责与签发通知单、进行计量审核是合同与规范确定的持续性义务，不因外部审计而中止；二是暂停将直接造成监理在审计期内的履职空白，一旦审计发现其他问题，监理将无法自证"已履职"，可能被认定为未履职甚至与承建方串通；三是工程款审核与质量整改停滞会直接损害项目进度与承建方权益，形成新的争议与索赔风险。正确做法是：审计事项与常规监理事项双轨并行——审计转办事项单独建立台账、逐项闭环；常规监理事项（质量通知单、计量审核、变更审核、旁站见证）按计划照常推进；确有实质冲突的（如争议款项计量），按"无争议部分照常审核、争议部分单独挂账并书面说明"处理，不整体暂停。

调阅流程五步：
1. 接收调阅函并核验：核验单位名称、公章、法定代表或授权委托书、调阅事项与范围、时限要求；
2. 登记造册：建立调阅台账，逐项登记文件名称、份数、页数、编号、复制方式、经办人与时间；
3. 复制交付：一律提供复制件，不交原件；原件需现场查看的登记后由调阅方签字确认；电子件需注明来源与完整路径；
4. 签收回执：取得接收人签字或盖章的回执，纳入监理档案；
5. 归档留存：调阅清单、交付副本、交接记录一并归档，形成完整履职证据链。

不得提供的六类资料：
1. 未经审核的内部草稿、内部讨论稿与征求意见稿
2. 超出委托范围且涉及其他单位商业秘密的资料
3. 涉及国家秘密与工作秘密的载体（须按保密规定处理，不得擅自复制提供）
4. 未脱敏的个人信息与敏感字段材料（按最小必要、去标识化、可逆可控、留痕可审四原则处理）
5. 未经检测、测评机构授权的原始工作稿
6. 监理单位内部对个人的绩效考核、人事考核材料

**踩分要点**：

1. **权限边界必答**：第 1、3、5 问的核心得分点是"监理有调查取证权与意见出具权，无认定权、无处置权"，凡出现"监理应认定审计认定违规""监理应直接扣款""监理应配合审计确认结论"的作答，一律扣分。
2. **四段式必须成文**：第 1 问监理意见、第 2 问分歧说明，均须按"事实—依据—计算—建议"四段写，缺"计算"段或缺"依据"编号（记录编号/函件编号）扣分。
3. **计算要给数字**：96.6 万元 = 46 × 2.1；占比 96.6 ÷ 12800 = 0.755%；10% 阈值 1280 万元；计量差额按复核结论给出 21.8 万元或 22.4 万元，并说明口径（监理复核值 vs 审计抽查值）。只写"金额有差异"不给计算过程不得分。
4. **四不得要显性引用**：不得自行认定违规、不得代签审计文件、不得以审计结论替代合同判定、不得提供未经核实的推测性结论。这四项要能在答案中找到明确对应句。
5. **双轨不断线**：第 5 问必须明确"审计事项单独成轨、常规监理事项照常推进"，只答"应当配合审计"而不写"不得停止履职"的不得分。
6. **程序性审查边界**：第 4 问不能出现监理对"三重一大"决策的必要性、合理性作实体评价，不能出现监理参与表决或代拟纪要。
7. **证据链自证意识**：第 3 问必须点明倒签记录不可修复、虚假月报导致整体证明力削弱、P1 故障未发通知单未报告构成未有效履职并丧失抗辩基础。回避必须同时说明"须有人接手并做书面交接"。
8. **脱敏四原则与不提供清单**：第 5 问只答"要保密"不给具体清单不得分。
9. **禁止虚构数据**：不得引用题干未给出的审计抽查比例、监理费金额以外的数据（如不得自行编造旁站影像份数、测试通过率）。需要补充数据时明确写"题干未给出，应通过复核取证获得"。
10. **答题结构**：分问作答、每问先给结论（应当如何）再给理由与依据，结论前置可显著提高得分效率。

## 记忆口诀

1. **外部监督五方结论域**：审计管钱、评审管价、纪检管廉、人大管值、第三方管标；监理只管"合同履行与工程质量"这最后一亩三分地。
2. **监理权限三分**：调查取证权有、认定权没有、处置权没有；能出意见不能定性质，能发通知不能罚款。
3. **监理四不得**：不自查冒充审计、不代签审计文件、不拿审计结论替合同判定、不递未经核实的推测。
4. **冲突采信原则**：审计在钱与合规上优先、监理在技术与过程上优先；最终看事实与证据，不看谁的帽子大。
5. **审计转办三分类**：质量缺陷自己办、计价问题退回复核、廉洁与决策程序只转报；自己履职问题照样自查自纠。
6. **双轨台账六状态**：审计销号不等于监理验收，审计没查不等于监理认可；两条台账编号必须映射。
7. **闭环六步**：接收、核实、分类、发文、验证、销号归档，一步都不能少。
8. **保留异议三不**：不在正式报告公开反对、不隐瞒、不自行对外沟通；只写事实与依据，意见走专题报告书面报送。
9. **四段式意见**：事实、依据、计算、建议——缺一段就是"表态"不是"意见"。
10. **监理意见三分**：审计钱上优先、评审价上优先、监理技术上优先；冲突以事实证据裁决，不以权威层级裁决。
11. **先分域再核证后定主次**：合同依据、证据链、时序、主次、留痕，五步走。
12. **计量分离处理**：无争议先付、争议暂缓；监理只出计量审核意见，扣款权在建设单位。
13. **记录即抗辩**：旁站、见证、平行检验、影像，签不倒签、真实完整连续；记录缺失等于自认失职。
14. **知情不报＝自认失职**：报告后未跟踪与知情不报是两种责任，都跑不掉。
15. **三重一大四项**：重大事项决策、重要干部任免、重要资金使用、重大项目安排决策。
16. **合规性审查三步**：识别事项属性、核查集体决策要件（载体+日期+编号+签到+表决）、核查实施留痕与一致性。
17. **纪要时序硬规则**：决策日期必须早于实施日期；纪要晚于采购合同签订日、晚于到货日，一律记"决议与实施不符"。
18. **拆分规避五要素**：同年度、同目标、同承建方或同系统、连续时间、内容实质相同；五项齐了才提"疑似"，只提程序性意见不定性。
19. **监理边界话术**：只对合同履行与工程质量发表专业意见；不参与表决、不代拟纪要、不作实体评价。
20. **配合审计五步**：核验调阅函、登记造册、复制不交原件、签收回执、归档留存。
21. **不提供六类**：内部草稿、超范围商密、涉密载体、未脱敏个人信息、无授权第三方工作稿、内部人事考核材料。
22. **脱敏四原则**：最小必要、去标识化、可逆可控、留痕可审；映射表自己留、不随材料交。
23. **双轨不断线**：审计事项单独成轨，通知单、计量审核照常签发；整体暂停等于自证未履职。
24. **P1 故障处置链**：当日发通知单并抄报建设单位、限期提交原因分析与整改方案、整改后复测验证、纳入月报质量分析与事故台账。
25. **虚假月报代价**：一份失真月报，拉低全部监理文件证明力；倒签记录不可修复，视同无效证据。
26. **回避四要件**：存在利害关系必须回避、由监理单位指派接替人员、完成书面工作交接与资料移交、既往监理意见复核确认。
27. **回避不减责**：换人不等于乙公司免责，既往履职瑕疵由监理单位承担。
28. **案例答题三步**：结论前置、分问作答、数字说话；没有依据编号的"事实"等于无效。
29. **两个不得混淆**：监理不是审计、监理不是评审；专业意见不是监督结论，核验报告不是审计认定。
30. **一句话总纲**：审计查账、监理在场；账靠记录证，在靠证据立。
